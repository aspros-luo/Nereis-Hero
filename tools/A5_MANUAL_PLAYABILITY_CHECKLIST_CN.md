# A5 实机可玩性验收清单

> 目标：在静态地形检查与 22 个房间运行时 smoke test 通过后，验证真实操作下的跳跃、落地、镜头、路线回环与软锁风险。
>
> 当前基线（2026-10-22）：静态几何扫描 240 platforms / 70 solid blocks / 16 floor gaps；Hero 弹道近似模型 240/240 可达；Godot 运行时 smoke test 444 PASS / 0 FAIL。以上均不代替本清单的人工试玩结果。

## 验收规则

- 在仓库根目录打开对应独立场景；使用项目当前默认输入，不临时修改主角移动参数。
- 每条用例记录：通过 / 失败 / 不适用；失败时附房间 ID、起点、目标平台、尝试次数及截图或短视频。
- 目标平台连续尝试 5 次仍无法抵达，记为失败并记录起跳点与落点；不要为了让用例通过而调整 Hero 参数。
- 如果跌落后不能返回，先记录是否属于设计的一次性落差；若没有明确出口/重生恢复方案，按软锁风险处理。
- R06 从高位出生是该独立测试场景的特例，不代表正常主线必须从高位进入。

## A. 基础移动与碰撞

| ID | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| A5-M01 | R01 | 从出生点左右移动、原地跳跃、从平台边缘起跳并落回地面 | 不穿地、不被残骸卡死；松开方向键后停止符合当前操控预期 |
| A5-M02 | R01 | 从起点向右跨过地面缺口，再返回起点 | 缺口确实需要跳跃；往返均可完成，无隐藏碰撞墙 |
| A5-M03 | R02/R03 | 连续通过水平平台与地面缺口 | 起跳窗口清楚；不要求像素级精确起跳 |
| A5-M04 | R04/R08 | 从地面、残骸边缘及低平台起跳 | 残骸碰撞与可见矩形一致；没有被不可见角落勾住 |
| A5-M05 | R07/R09/R14/R19/R22 | 在小房间内跳跃、转身并回到入口附近 | 落脚空间足够；不会因房间太窄而无法掉头或返回 |

## B. 纵向路线与真实跳跃

| ID | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| A5-M06 | R05 | 从底部连续向上攀登，再沿可用路线返回较低平台 | 主要上升路线可达；失败落点不会直接把玩家锁死 |
| A5-M07 | R06 | 从高位出生点沿平台下降，尝试在中途停留并改变方向 | 下落路径可辨认；平台不会把角色弹出边界；能到达设计的底部区域 |
| A5-M08 | R10 | 分别尝试下层路线与上层路线 | 两条路线都能完成；上层是可选风险路线而非意外必经死路 |
| A5-M09 | R13 | 从起始平台一路攀升，逐个平台验证侧向支路，再安全下降 | 主攀登路线与侧支路均可通过实际跳跃抵达；镜头不会遮住关键落点 |
| A5-M10 | R16 | 从起点探索竖向平台与侧向平台组，尝试反向返回 | 平台连接不依赖弹道模型的理想化边缘擦碰；返回路线可用 |
| A5-M11 | R17 | 检查上下层和竖井路线，尝试从下层返回 | 主路线可达；没有落到地图外或被封闭平台围困 |

## C. 摄像机与房间边界

| ID | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| A5-M12 | R02/R10 | 走到房间左右两端并多次反向移动 | 镜头平滑跟随；不越过房间边界露出场景外区域 |
| A5-M13 | R05/R06/R13/R16/R17 | 从房间底部走到顶部（或从顶部下降到底部） | 镜头上下跟随，角色和落点保持可读；顶部/底部不出现明显错误夹边 |
| A5-M14 | R13 | 在每个屏幕高度交界处停留、跳跃、回落 | 镜头平滑不会造成跳跃落点难以判断；关键平台不会长期被 HUD 遮挡 |
| A5-M15 | 所有高房间 | 贴近左右墙、顶部与底部边界跳跃 | 不穿越边界；相机限制与实体边界一致，不出现角色可见但无法操作的区域 |

## D. 回环、路线选择与软锁

| ID | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| A5-M16 | R03/R18/R19 | 分别走地面路线和低位路线；尝试从低位回接 | 两条路线都能抵达预定回接点；捷径确实改变回程路线 |
| A5-M17 | R10/R15/R20 | 从高位路线进入并尝试回到较低路线 | 单向落差符合设计；不误把普通平台做成不可返回的单向陷阱 |
| A5-M18 | R16 | 验证绞盘房的探索路线和返回路径 | 在正式机关接入前，房间几何本身不造成软锁；C04 的逻辑解锁仍按全局连接契约处理 |
| A5-M19 | R21/R22 | 从默认出生点探索侧翼与隐秘区域，再回到入口 | 可选支路不阻断主路线；若依赖后期能力，入口应可识别且不误导为普通跳跃 |
| A5-M20 | 全部房间 | 故意跳下每个明显的低位区域，测试返回、重生或退出 | 每个下落点都有可返回路线、明确的一次性出口或可验证的恢复方案；不存在无法退出的软锁 |
