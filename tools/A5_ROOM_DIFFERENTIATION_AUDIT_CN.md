# A5 全部 22 个房间：空间差异与探索职责审计

> 审计范围：`feature/story-map-progression` 分支的 A5-R01 至 A5-R22。
> 依据：`tools/a5_room_design_contract.json`、`scripts/levels/greybox_world_region.gd`、`scenes/a5_rooms/README.md` 和 `tools/METROIDVANIA_LEVEL_DESIGN_RULES_CN.md`。
> 本轮是源代码与布局定义审计，不声称完成 Godot 实机测试。平台弹道近似可达不等于真实操作体验合格。
> 保护约束：不修改世界级拓扑；保留 C04、C08、C09 语义与埋旗共鸣路线；暂不扩展 A5 以外区域。

## 1. 审计结论

**当前 A5 的主要问题是空间布局模板复用过多，设计说明与几何实现之间存在落差。** 房间具有不同 ID、尺寸或平台数量，并不自动构成不同的关卡体验。

源代码中的重复模式：

- 多个 2×1 横向房间采用沿 X 轴推进、平台高度在约 60–170px 之间规律变化的等间距阶梯。
- R05 与 R06 使用相同的 15 级、约 75px 高差的蛇形阶梯，只是平台顺序反转。
- R07、R09、R14、R19、R22 都是 1×1、5 个平台，主要区别写在用途说明里，几何仍然是短距离、规律间隔的横向跳台。
- R02/R03/R04/R08/R11/R15 的横向平台数量、步幅和高度变化高度相似；R18 也仍是相近的横向序列。
- R10、R13、R16、R17、R21 平台数量较多，但平台数量本身无法证明路线分支、回环或风险选择真实成立。
- R20 作为 C09 出口测试空间，仍采用常规短平台序列；应以出口落点、接近路径与安全返回为主，不应为了差异而破坏 C09 契约。

## 2. 逐房间审计表

判定含义：
- **保留并精修**：主要职责清楚，空间应围绕该职责做有针对性的设计。
- **结构重做**：当前几何和其他房间太相似，或无法仅凭空间体现职责。
- **专项验证**：设计方向有差异，但需要验证分支、回程、观察目标或实际玩法是否成立。

| 房间 | 当前职责 | 审计判定 | 必须体现的空间差异 / 后续动作 |
|---|---|---|---|
| R01 | C08 高位入口、进入战场 | 保留并精修 | 入口落脚区、首次战壕视线与进入主路线的低风险教学；不应只是五块阶梯平台。 |
| R02 | 断墙观察与长路线 | 结构重做 | 改成视线主导的宽窄节奏：先有可观察远景的稳定落脚点，再以局部断墙/缺口改变路线；不要重复匀速阶梯。 |
| R03 | 战壕岔口、地面与补给支路 | 结构重做 | 必须有真正的路线分叉、两条路径的空间差异与回接关系；单条阶梯无法体现“岔口”。 |
| R04 | 弹坑战斗、交叉火线 | 结构重做 | 以弹坑低洼、掩体遮挡、跨越危险区和不同高度的战斗站位组织空间；避免均匀排列的跳台。敌人尚未加入时先定义遭遇站位占位区。 |
| R05 | 信号塔攀登、俯瞰路线 | 结构重做 | 不再只是重复蛇形阶梯；加入塔内外轮换、观察平台、短横向支路或可辨认的中途落脚层。 |
| R06 | 塌陷坡道下降、回到战壕 | 结构重做 | 不得只把 R05 倒序。采用下降路线的节奏：宽阔断层、可选择的安全落点、落差与回退平台；区分可控下降与危险捷径。 |
| R07 | 战地医疗所、休息与线索 | 保留并精修 | 主要可走地面应安全、可停留；用隔间/掩体/调查位组织空间，避免强迫玩家在休息房里连续跳平台。 |
| R08 | 军需堡垒战斗与补给奖励 | 结构重做 | 应有入口暴露区、掩体战斗区和战后可达的补给区；空间顺序需体现“夺取”而非普通横向通道。 |
| R09 | 侧向藏库、可选材料 | 结构重做 | 重点是入口发现、狭窄进入、奖励落点和返回路径；房间可以很短，但必须区别于普通 5 平台房。 |
| R10 | 双层城墙平台挑战、风险路线 | 专项验证 | 现有高差与上层回折需要验证是否形成两种有效路线、是否能安全返回；检查避免只是一条超长斜向阶梯。 |
| R11 | 炮桥机关、节奏通行 | 结构重做 | 以机关作用范围、等待区、跨越窗口和安全观察位组织；即使机关暂未实现，灰盒也要能看出“等待—通过”的节奏。 |
| R12 | 指挥庭院枢纽、休息与分流 | 保留并精修 | 宽阔中心需真正承担分流，至少让玩家从中心辨认不同出口方向；避免把多个平台排成普通走廊。 |
| R13 | 箭楼垂直地标、远景观察 | 专项验证 | 主攀登线与旁侧观察台要形成真实侧向分支；中段观察台应展示路线信息，且回到主塔的路径要可读。 |
| R14 | 隐藏指挥记录、叙事密室 | 结构重做 | 入口前的发现线索、进入后的安静调查空间和离开路径是重点；不应要求玩家在密室内继续进行普通平台跳跃。 |
| R15 | 堡垒高墙、俯瞰地下维护区并回接主路 | 结构重做 | 需要表现高墙边缘、向下观察的开口/竖井和通往主路线的明确出口；避免与 R02 的长平台排列重合。 |
| R16 | 绞盘竖井、从 A5 远端开启 C04 | 专项验证 | 保留 C04 契约，但必须形成可理解的攀登/操作平台、机关停留区与返回路线；不能让 C04 变成离开 A5 的必经门。 |
| R17 | 地下维护竖井、升降机连接 | 专项验证 | 现有斜向阶梯要改为可辨识的竖井分层、升降机井口、侧向维修平台和上下层回环；不能只是更高更长的阶梯。 |
| R18 | 蓄水沟绕行、规避高风险战壕 | 结构重做 | 低位路线应提供与上层不同的风险和视线：低顶、积水沟、窄处与安全地面交替；需要与上层主路有明确入口/回接。 |
| R19 | 地下回接战壕、改变回程 | 结构重做 | 核心是“从地下打开回连”的路线功能；应有远端开启点、门/破墙占位、回到熟悉安全路线的空间反馈，而非普通跳台。 |
| R20 | C09 高位出口 | 保留并精修 | 优先保障 C09 的出口接近、上层落点、门触发安全距离和返回可达性；房间可以短，但空间应围绕出口和高位边缘设计。 |
| R21 | 后期能力支路、可选强化 | 专项验证 | 软门槛应可见、暂不可达且能被记住；用独特障碍/高差明确能力用途，获得能力后可返回，不能只是斜向阶梯。 |
| R22 | 隐秘观察室、终局相关异象 | 结构重做 | 通过入口隐蔽性、安静的观察站位、远景或异常视觉焦点构成空间；平台跳跃不应喧宾夺主，并要定义进入/退出方式。 |

## 3. 优先级与实施顺序

### P0：先消除模板重复
1. R02、R03、R04、R08、R11、R15、R18：从统一横向阶梯模板改成分别服务观察、分叉、战斗、夺取、机关、高墙、低位绕行的空间。
2. R05 与 R06：取消镜像式体验，分别设计“攀升观察”和“有控制的危险下降”。
3. R07、R09、R14、R19、R22：小房间按安全、藏物、叙事、回连、隐藏观察五种不同功能重做空间语法。

### P1：验证多层与分支是否真实
- R10：双层风险路线。
- R12：实际分流枢纽。
- R13：主塔与观察支路。
- R16：绞盘操作、回退与 C04 连接。
- R17：维护竖井与升降机层。
- R21：能力门槛、远景目标与回访路线。

### P2：精修入口与出口契约
- R01：C08 高位进入。
- R20：C09 高位离开。
- 同时复核 R15/R16/R20 之间的房间路线关系，但不修改世界级连接端点与解锁语义。

## 4. 每间房间必须新增的设计数据

在正式修改几何前，每间房间的设计说明必须明确：

1. 主功能（仅一个主要类别）。
2. 空间轮廓（例如：宽—窄—宽、竖井、环形平台、分层庭院、低位沟渠）。
3. 玩家必须作出的路线决策。
4. 可见目标或环境引导。
5. 是否有软门槛；首次可见位置与回访路线是什么。
6. 若为空房间，目的必须明确为氛围、伏笔、节奏缓冲或远景。
7. 入口、出口和返回路线；任何单向落差都要记录退出/恢复方案。
8. 与相邻房间的差异点。

## 5. 验收规则

- 两间房间若尺寸、平台排列、路线决策和主要职责都相近，必须重做至少一间。
- 不允许仅通过平台坐标微调、平台数量增加或改名字判定“已差异化”。
- 通道房也必须通过转向、视线、层级或路线选择承担明确作用。
- 所有捷径必须改变实际路线或明显降低回程成本，并尽可能接回休息点/已知安全路线。
- 软门槛需有可见目标、可推断线索、能力来源和返回路径。
- 保留既有 C04、C08、C09 和埋旗共鸣桥契约；修改前先明确记录影响。
- 静态几何与弹道模型只作为预检查；最终仍需 Godot 运行时和人工跳跃、镜头、回环与软锁验收。
