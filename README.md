# Nereis Hero

A 2D Soulslike action RPG set in the Nereis universe.

## Vision

A dark fantasy / cosmic horror action RPG told from the hero's perspective. The game explores the conflict between survival, faith, memory, and humanity.

## Current Phase

Vertical Slice 001 — project foundation and first playable combat prototype.

## Engine

Godot 4.x.

## Repository

This repository is developed iteratively through small, reviewable commits. Gameplay, narrative, art direction, and technical architecture will evolve together.
