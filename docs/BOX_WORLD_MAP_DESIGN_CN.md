# 箱庭地图结构设计与验收（中文）

## 当前判断

2026-10-11 的实际试玩中，玩家持续向右移动即可抵达「凡人之墓」。这不是测试方法错误，而是当前灰盒地图的真实体验问题：多数主线出口位于场景右侧，各区域又普遍采用单层横向地面，因此“世界拓扑中存在回环”与“玩家在游玩时感受到箱庭”并不等价。

当前已加入正常游戏内的世界路线图（按 M 打开／关闭），并将区域节点从单排流程重新排布为分层、偏环状的空间图，让 A0–A12 的主线、回环及可选 A11 在空间关系上可见。它是辅助，不是箱庭结构本身的替代品。

首轮物理路线改造：A2 通往 A3 的出口已移至东侧树冠高台（约 x=2240、y=380），并补上连续上升的平台链；玩家需要观察并攀上高路，而不是一路沿地面向右。A2 的地面钟墓异常入口仍独立保留，避免主线与秘密入口争抢同一出口。该改动与 F10 导航已同步，尚待 Godot 实机确认跳跃与交互。

## 设计原则

1. **主线可读，但不等于单向走廊。** 首次推进可以有明确方向；地图必须在不同高度、分支入口与地标之间提供空间选择。
2. **回环必须可走。** A3–A4–A1、A3–A6–A5、中层与王国深层捷径不能只存在于文档或状态标记里。
3. **捷径改变玩家对旧地图的理解。** 首次路过时从远处看见、但暂时无法使用的门／升降机，应在另一侧开启；回程时明显缩短距离。
4. **垂直层次有用途。** 上层应连接捷径、远程观察点或风险更高的近路；下层应连接水道、监牢、王墓和深层遗迹，而不是只装饰背景。
5. **地标先于任务箭头。** 钟塔、被删去的街、排水闸、王室铭文与大圣堂应帮助玩家记住方向。F10 指引只用于验收，不能成为正常游玩的必要条件。
6. **A11 与隐藏区域保持可选。** 普通路线可以抵达王座区和「凡人之墓」；探索 A11 应提供改变世界观理解的证据，而不是成为所有结局的硬性门槛。
7. **灵视改变旧空间的可读性。** 高鸣响应揭示同一地点的异常入口或路径，不应只是凭空出现一个与既有空间无关的奖励房。

## 世界连接关系

- **边境环路：** A1 ↔ A2 ↔ A3 ↔ A4 ↔ A1。A4 还应能通过已开启的水道／补给通道连向 A7、A8、A9。
- **中层环路：** A3 ↔ A5 ↔ A6 ↔ A3。C10 钟塔落差应能从 A6 回到 A3，实际走过后明显缩短回程。
- **王国深层环路：** A4 ↔ A8 ↔ A9 ↔ A4。各门需要在正确的一侧开启，并保存状态。
- **主线：** A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12。
- **深层支线：** A8 经 C15 或 A10 经 C19 进入 A11；A11 可继续探索 H08，但不阻塞普通主线。
- **异常支线：** 当前正式地图基线为 H01–H08；开发分支中的 H09 是待复核候选，不计入已确认区划。隐藏区域应从既有地标进入，并保留可信的回程路线。

## 下一轮物理地图改造

优先改造 A2、A3、A4、A6、A8、A9 的实际空间表达：

- 让主线、捷径和隐藏入口分布于上层平台、下沉通道与中段分支；不要让所有目标都能从同一条地面直线抵达。
- 主线仍要有可读方向，但在关键区域加入高路、低路和侧路的选择；至少一条路线应连接到旧区域的不同入口。
- 用建筑轮廓、楼梯、井道、排水管、钟塔与可见但封闭的门来暗示跨层连接。
- 让同一张地图存在清楚的主路、可选高路和回程捷径；不同路径应在风险、距离或线索上有差异。
- 修改出口位置前，必须同步更新出生点、F10 导航目标坐标、平台跳跃可达性和交互提示间距。
- 不改变剧情门槛或存档字段，除非自然探索回归证明现有路线设计本身有问题。

## 障碍、出口可读性与条件探索（新增规范）

### 灰盒阶段：连接必须一眼可辨

- **障碍物要有功能。** 可碰撞物只用于平台跳跃、战斗掩体、危险地形或明确的路径封锁；纯粹用于营造气氛的废墟、根须、尸体、柱子应优先作为背景绘制，不能无意义地挤压可走空间。
- **主路线保持干净。** 出口附近、跳跃落点、NPC 交互点和休整点要保留足够的净空。不要把装饰平台、敌人碰撞体和 E 交互范围堆在同一小片区域。
- **所有出口都要有空间语言。** 门洞、破墙、井口、梯子、绳索、落差或明显的光／雾方向至少应提供一种远距离可辨认的形状。不能只依赖靠近后才出现的 E 提示。
- **开发期不隐藏连接。** Debug 构建中，普通出口、捷径和灵视入口需要用醒目的方向标记和目标区域标签标出来；有条件限制的路径还应标出“条件未满足”。正式版再按剧情与探索条件隐藏提示或入口。
- **不要把 Debug 标记当成正式美术。** 它只帮助设计者验证入口位置、路线方向、跳跃空间和区域连接；正式版必须由建筑剪影、环境光、声音和可读的地形轮廓接手。

本轮已在灰盒共享场景中加入 Debug 专用的出口／捷径／灵视入口标记，并为 A2、A3、A4、A5、A8、A9 的常见条件捷径补充“幽灵出口”标记；只在 Debug 构建绘制。当前仍需在 Godot 实机确认标记层级、文本裁切及不同窗口尺寸表现，并继续审计其余区域的条件出口，不能误认为已全部覆盖。

箱庭结构复核的执行记录见 [《箱庭地图结构复核与整改记录》](./BOX_WORLD_STRUCTURE_REAUDIT_CN.md)。本轮先整改 A3：C05 地下水库入口移至抬高的管线栈道，C16 旧升降机移至东侧高台，并同步修改回程出生点与静态合同。该调整尚待执行静态校验和 Godot 实机验收。

### 临时候选内容：H09「崖下实验窟」（待地图复核，不视为已冻结设定）

> 说明：H09 的代码来自此前将一个示例过早实现。它目前只是开发分支中的候选内容，不代表用户已确认该区域、疯狂神职人员、实验体或脐带碎片属于最终地图／剧情。基础箱庭网络复核完成后，再决定保留、改造、迁移或移除。不得用 H09 增加官方地图完成度，也不得把它作为普通主线或结局的必要条件。

当前实现包含 A6 特殊敌人、村庄回访后显现的入口、H09 独立场景和可拾取物。- H09 的候选遗物现只验证可选区域拾取与持久记录，不再写入隐藏真相锚点，也不会改变「烈火天罚」或其他结局条件。旧存档中曾由 H09 写入的临时脐带来源会在读档时移除并保存修正；脐带概念未来是否采用、由什么探索来源承载，留待正式剧情设计决定。
这些仅用于说明候选内容目前在代码中的位置，不能反向视为已经确定的剧情需求。地图复核阶段暂不围绕该路线继续增加敌人、道具或结局条件。

### 本轮降低平台阻挡感与美术细化

- 灰盒平台改为单向碰撞：主角可从平台下方跳穿，减少平台侧面和底面造成的无意义阻挡；村庄屋顶路线同样处理。
- 平台视觉厚度收窄，增加顶部边缘光与底边阴影，让可站立面更清楚，同时减少厚重方块感。
- 村庄加入低雾、暖色窗光与地面裂纹；蜂巢状态变化、疯狂神职人员和古神实验体的专属美术属于 H09 候选方案的一部分，最终是否保留待地图复核。
- 上述碰撞与美术修改尚未经过 Godot 实机验证；若单向碰撞在当前玩家移动状态或特殊地形中出现问题，需以实际试玩为准调整。

### 条件隐藏路线的通用设计约束

无论最终是否保留 H09，条件路线都应遵循“**既有事件 → 旧地点变化 → 环境反馈 → 可选探索 → 有意义的发现**”，而不是凭空生成奖励房。

- 触发事件必须来自已经成立的游戏事实，并在存档中持久化。
- 入口最好改变玩家熟悉的旧空间，让玩家意识到“这里发生了变化”，而非单纯出现任务箭头。
- 环境提示可以来自声音、光影、灵视、NPC 反应或既有道具，但不能只依赖靠近后弹出的 E 提示。
- 可选路线应扩展世界理解或探索能力，不应堵住普通主线；奖励与结局的关系必须独立评估。
- 每条候选路线都应记录触发事实 ID、回访区域、入口显现条件、前后视觉变化、提示方式、返回路径、奖励 ID、结局影响和错过后的主线行为。
- 以上是通用设计标准，不代表 H09 的具体事件、角色、洞穴或脐带奖励已经获得确认。

### 重要状态必须分开

- **未发现：** 玩家尚未注意到异常，正式版不显示明确入口提示。
- **已感知：** 通过鸣响、声音或道具反应注意到异常，但入口可能尚未开启。
- **已开启：** 满足条件后，入口的实体状态改变。
- **已进入：** 玩家实际进入过该区域。
- **已取得关键物：** 奖励已被取得，作为结局条件来源独立记录。

不能用一个布尔值同时代表以上所有状态。灵视入口、物理捷径和剧情回访事件也不应共用一个模糊的“已解锁”标记。

## 验收标准

- 只按右方向不应成为唯一有效的地图阅读方式；主线可以通关，但玩家能从视觉地标看见分支和跨层入口。
- 从 A3 实际走通 A4，再通过回环回到 A1 或旧城区。
- 从 A6 实际走通 C10 回到 A3，能够明显感受到回程被缩短。
- 从 A8／A9 走通至少一条通往 A4 的王国深层回环。
- 进入新区域后，出生点与出口方向一致；回程捷径不会把角色放在门、NPC 或敌人碰撞体内。
- A11 可以被错过而不妨碍普通结局；发现它的玩家能够通过 C15/C19 理解其与教会实验和古神遗迹的关系。
- 以自然探索而非 F10 传送完成上述验收。世界路线图可用于理解关系，但不能作为“路线已实际走通”的证据。
