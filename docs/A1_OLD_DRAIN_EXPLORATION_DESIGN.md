# A1 旧排水通道 / 下水道探索设计约束

状态：设计约束已确认；尚未作为运行时地图实现。  
适用项目：Nereis-Hero（Godot 4.6.1）  
关联入口：A1「封闭的排水通道」/「旧排水通道」与 A3「废弃城区」、A4「下水道、沉积大厅与旧水库」。

## 设计目标

借鉴《空洞骑士》开局向下进入遗忘十字路的探索节奏，不复制其具体地图：

- 让玩家主动向下进入地下空间，利用落差、竖井、短平台和弯折通道建立“地下比地面更深、更古老”的空间感。
- 首次进入后可以探索一小段路程，观察环境、处理少量低威胁小怪，并发现至少一个明确但暂时无法通过的后续通路。
- 用门、塌方、锈蚀闸门、缺少操作机构或暂时无法跨越的地形阻止继续推进；阻断应当有清楚的视觉/交互反馈，不能让玩家误以为碰撞坏了或路线不存在。
- 让玩家记住阻断点，形成以后获得条件/找到另一侧机关后返回的动机；本段不要求玩家立即解锁能力，也不强迫战斗。
- 下水道是可探索的支路/早期地下区域，不应在首次进入时直接把玩家送进完整的 A3/A4 主体流程。

## 建议的首次探索节奏

1. **入口与下降**：从旧排水口进入，经过短距离下行/落差，提供安全落脚区；避免一进门就坠落受伤或落入敌人攻击范围。
2. **第一段横向通道**：空间较窄，出现污水痕迹、旧砖、锈蚀管线和不连续的水声。用环境引导玩家继续前进，不需要文字教程。
3. **轻量遭遇**：安排少量老鼠等低威胁小怪，优先单只或两只分散出现；让玩家能选择绕开、观察或战斗。不要把狭窄通道堆成连续战斗走廊。
4. **小型探索回报**：放置可调查的环境细节或普通拾取物，回报以探索感/世界信息为主，不新增制作系统，也不使用会直接泄露隐藏线索性质的物品标签。
5. **第一次明确阻断**：玩家能看见门后、落差另一侧或继续向下的空间，但被关闭闸门、坍塌结构或缺少操作机构挡住。互动/检查应明确反馈“目前无法继续”，但不提前揭露完整剧情答案。
6. **安全回退**：入口到阻断点之间应有可读的回程路线；避免回程被敌人卡住、角色落入无法跳出的坑、或死亡恢复点落在门触发区内。

## 敌人与战斗边界

- 初次探索以老鼠/小型爬行生物为主，定位为环境威胁和基础战斗练习，不应在本段引入精英怪或 Boss。
- 敌人数量以“少量、分散、能看清彼此位置”为准；暂定一至三只总量作为灰盒首轮测试起点，实际数量以战斗空间和玩家测试为准。
- 敌人应使用现有敌人系统的可复用接口；若现有项目没有合适的鼠类敌人，再新增轻量敌人实现，不为本段引入独立战斗框架。
- 敌人不能堵死唯一回程通道，也不能在主角出生时立即激活并造成不可避免的先手伤害。

## 阻断与后续连通

- 第一次阻断应当是“可见、可理解、可记住”的空间阻断，而非不可见的逻辑条件。
- 首选一个主阻断点；可以有短小侧室或高低差探索，但暂不做多层复杂迷宫。
- 暂时封锁不等于永久断路：后续应能从另一侧开门、找到操作机构或通过既定进程条件回访。
- 不在本设计稿中预先决定阻断后方究竟连接 A3、A4 或其他子区域；先对齐当前世界拓扑与现有 C24/C05 连接契约后再落到具体门和出生点。

## 明确保护的既有逻辑

在用户进一步确认入口和地图连通方案前，不改动以下运行时行为：

- A1 的 `city_cut` / C24 旧排水通道入口身份、村庄防卫完成前的封堵状态与当前目标场景。
- H01 井口：`res://scenes/hidden_well.tscn`、`required_resonance = 12`。
- 崖壁洞窟：`returned_to_village_after_mad_cleric` 进程条件与 `res://scenes/cliff_cave_experiment.tscn` 目标场景。
- 不改变其他地图连接的方向、解锁条件、出生点或存档字段。

## 验收条件

- 首次进入能安全下行，玩家能理解可走区域和当前阻断点。
- 至少有一段非战斗探索空间；老鼠等小怪数量少、威胁低、可被逐个处理。
- 阻断有明确视觉/交互反馈，玩家不会因碰撞异常而卡住。
- 回程可达，不会被敌人、地形或交互范围封死。
- 不改变 H01 井口和崖壁洞窟逻辑；不意外打开 C24/C05 或绕过既有进程门槛。
- 文档/静态检查通过后，再进入 Godot 场景实现与实际运行验收；本文件本身不代表运行时已验收。
