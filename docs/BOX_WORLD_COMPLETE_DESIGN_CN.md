## 0. 本文的用途与边界

本文是当前 A0–A13、H01–H08 地图设计的统一访问入口，汇总区域职能、主路线、宏观连接、捷径、回环、隐藏区域和建议时长，供后续开发与验收使用。

它描述的是**当前地图设计基线**，不是声称所有地图都已完成。拓扑文件中的连接只有在实体门、碰撞、平台、出生点、存档状态与实际操作都通过 Godot 验收后，才可标记为完成。

H09「崖下实验窟」目前仍是临时候选内容，不计入正式地图规模，不属于已确认世界观，也不得作为任何结局的强制条件。

## 1. 游戏时长目标：规划值而非已确认的历史承诺

目前没有找到用户明确确认过的《Nereis-Hero》总游玩时长数字。此前出现过的“20–30 小时”是另一轮文字冒险设计中的建议，不能冒充本动作游戏的原始承诺。

为判断当前地图的内容量，先采用以下**可调整的制作目标**：

- 首次通关一个结局：约 **18–24 小时**。
- 首轮较完整探索（多数捷径与隐藏区域已发现）：约 **22–28 小时**。
- 三结局与高完成度内容：约 **30–40 小时**，依赖结局分歧、支线、战斗挑战和多周目变化是否真正落地。

这些是制作规划区间，不是实测时长。实际时长受战斗难度、玩家熟练度、探索习惯、死亡次数、剧情文本量和回访路线影响。

### 1.1 首轮通关时长拆分

| 内容类型 | 建议区间 | 主要构成 |
|---|---:|---|
| 首次探索与导航 | 6–9 小时 | 13 个主要区域、空间识别、寻找出口、阅读环境线索 |
| 战斗与 Boss | 5–8 小时 | 普通遭遇、精英敌人、区域战斗、Boss 学习与重试 |
| 剧情与环境叙事 | 2–4 小时 | 短对话、物品描述、教会/王国/古神/外神线索 |
| 回访、捷径与解谜 | 3–5 小时 | 开门、绕行、灵视路线、回到旧区、收集关键证据 |
| **总计（体验重叠前的规划口径）** | **16–26 小时** | 各项会互相重叠；制作目标以首结局约 18–24 小时为中心 |

不能通过拉长空跑距离、堆高敌人血量或重复同一条走廊来凑时长。时长应由多路径探索、战斗学习、捷径解锁、隐藏空间与叙事发现自然产生。

### 1.2 当前内容量是否足够？

**有潜力支撑 18–24 小时，但目前不能判定已经满足。** 当前有 13 个主探索区域（A0–A12）、8 个正式隐藏区域（H01–H08），A13 是抽象终局层；总计 21 个主要/隐藏场景区域，不包含候选 H09。

若主区域平均只有 15–20 分钟、隐藏区域只有 3–5 分钟，整体会明显偏短。要达到目标，主区域应各有清晰的空间主题、至少一个可记忆的战斗/探索事件、可选支路或回访价值；隐藏区域应有差异化体验，而非统一的短奖励房。Boss 数量、完整剧情分支和多结局复玩量尚需在后续内容设计中落实，因此当前地图数量本身不足以保证目标时长。

### 2.2 连接图的文字表达

主推进方向（仅用于初次引导，不代表世界是线性的）：

`A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12`

A4 不是旁边的单独支线，而是应通过 A3 下水道入口、A1 水闸/井道、A7 监牢补给道、A8 王墓中层水道和 A9 王室排水道连接多个层级的地下枢纽。A11 是可从王墓或圣堂秘密进入的深层区域。A13 根据结局状态承接不同终局入口。

**地图验收不能只看主推进链。** 重点是玩家在解锁后能否从 A3/A4/A9 等枢纽改走另一条路线，且能感知这条路线为何存在。

## 4. 三条已登记的宏观回环

### L01 边境环路：A1—A2—A3—A4—A1

- **体验目标：** 早期从村庄出发，经过森林和城区进入地下枢纽，最终从老井/水闸回到熟悉的村庄。
- **关键开启：** 从 A4 打开下水道检查口（C05）；打开水闸与村庄井道出口（C06）。
- **设计价值：** 让玩家理解地下水系贯穿地表聚落，老井不只是背景物件。
- **验收风险：** C06 不应与 H01 的隐藏入口混淆；回程不能将角色送到错误高度或直接触发隐藏门。

### L02 中层环路：A3—A5—A6—A3

- **体验目标：** 城区进入战场，再进入修道院，最后从钟塔落差回到城区另一层。
- **关键开启：** 从 A6 打开钟塔落差 C10。
- **设计价值：** 让玩家在旧区域获得明显捷径，改变对城区空间的理解。
- **验收风险：** 高位门必须从高路抵达；回程落点必须在可站立的上层平台，不能落在门下的地面。

### L03 王国深层环路：A4—A8—A9—A4

- **体验目标：** 由地下水系进入王墓，再通向王城外环，最后从王室排水道返回旧水库。
- **关键开启：** 从 A7 到达 A8 后开启 C07；从 A9 开启 C23。
- **设计价值：** 把监牢、王墓、王城和水利系统编织成一套空间，而不是各自独立的主题关卡。
- **验收风险：** C12 低位补给道、C07 中层王墓水道和 C23 高位王室排水必须在空间上明显区分。

三条是目前明确登记的宏观回环，不是数量上限。实机探索若仍然主要依赖原路返回，必须补充真正有用的交叉连接。

### 5.1 隐藏区通用规则

每个 H 区都要分别验证：未发现、感知异常、入口显现、入口开启、已进入、已获得线索/奖励、次级出口解锁。不能用一个布尔状态代表所有阶段。

- 灵视/鸣响负责揭示异常，但不要把所有秘密都做成同一种视觉特效。
- 入口必须有环境提示；玩家可在合理范围内推断“这里有问题”。
- 隐藏区域应有安全回程。次级出口只能在目标区域已合理抵达后开启，避免无意绕过主线。
- 线索与奖励需要持久化，避免切图、死亡或读档导致重复领取/状态丢失。
- H08 的当前拓扑条件涉及 `physical_union_complete`。这与共享世界观文档中“亲密关系与调查进度是不同维度”的约束存在设计张力。不得未经专项设计就让单一亲密事件成为另一游戏的结局硬门槛；若该事件保留为 Hero 结局条件，必须明确这是 Hero 自身的结局合同，并重新核对跨项目因果。
- H09 暂不列入正式隐藏区，不得用它补足数量或时长。

## 6. 箱式空间的构建原则

### 6.1 每个区域不是一条横向走廊

主要区域至少应结合以下三项中的两项：主通路、不同高度路线、支路/局部回环、隐藏入口、捷径出口、回访奖励。枢纽区域必须具备多个有意义的去向，而不是只有多扇门但门后仍然都是线性走廊。

### 6.2 不同高度必须有空间理由

- A2：树冠高路与地面钟墓。
- A3：地面街道、抬高管线、钟塔落差返回层、东侧升降机高台。
- A4：地面水库、低位监牢补给道、中层王墓水道、高位王室排水。
- A5–A7：战场破损高墙、修道院钟塔、监牢竖井与低路。
- A8–A9：王墓中层、王城屋顶与王室排水系统。
- A10–A12：圣堂上层、外环屋顶、内城侧门与王座进路。

高度路线必须通过可见平台、地形轮廓或地标提示玩家理解，不能靠不可见的空气墙来制造路线限制。

### 6.3 捷径的通过条件

一条捷径只有在下列至少一项成立时才算有效：

1. 明显缩短两个已探索区域之间的回访路程；
2. 把之前分离的区域层级连接起来；
3. 让玩家从新方向抵达已知地标；
4. 解锁一个枢纽的另一侧，形成可验证的闭环。

### 6.4 回访的内容条件

每次重要回访至少提供一个合理的新理由：新出口、灵视可见物、之前打不开的门、新敌人状态、物品描述/环境证据、支线人物变化或捷径。不能让玩家为了补时长而反复穿越没有变化的路线。

## 7. 区域内容密度与战斗配置建议

当前脚本已有部分区域遭遇与隐藏区敌人配置，但敌人配置并不等于完整战斗设计。每个主区域应至少规划：

- 一个可记忆的战斗节奏变化（伏击、狭窄地形、垂直战斗、远近敌人组合等）；
- 一种可辨识的环境威胁或空间压力；
- 一处可选探索收益；
- 一条能让玩家在解锁后重新理解地图的连接或回访价值（非每区强制，但枢纽区必须具备）；
- 对应的休整点与死亡回归路径。

Boss/精英配置应按区域主题区分。不能让所有区域都只是普通敌人重复刷出；也不应只为延长时长而提高敌人生命值。Boss 总数、完整 Boss 阶段与每个结局的专属遭遇，须在后续战斗内容矩阵中单独定稿。

## 8. 剧情如何嵌入地图而不破坏探索

地图先于大规模剧情填充完成，但空间设计应为叙事留出位置：

- A0：身体被当作实验对象、逃脱、记忆断裂；不要在序章解释全部教会真相。
- A1：村民有独立生活与动机；蜜忒的日常表象要真实，不把村庄所有人写成完全知情的邪教徒。
- A2–A4：以道路、管线、井、水库和异常声响暗示古老结构早于现存王国设施。
- A5–A7：通过战场、修道院与监牢展示王国扩张、教会纪律和研究活动留下的痕迹。
- A8–A10：王室铭文、圣堂设施和被删去的名字逐步揭示信仰权力与历史修订。
- A11：让玩家看到教会研究与古神遗留的证据，但不要把古神、外神、王国信仰混为同一种力量。
- A12–A13：由玩家此前探索与结局状态决定最终解释，不要在单一线性对话中讲完所有真相。
- H01–H08：优先使用环境变化、物品描述、声音、空间矛盾和少量文本，而不是每个隐藏房间都放一段长解释。

剧情时长应来自玩家主动拼合碎片的过程，不是大量不可跳过的长对话。Hero 不知道蜜忒真实身份这一认知限制必须持续遵守；玩家掌握的线索不自动等于 Hero 已经理解真相。

### 拓扑
- [ ] A0–A12 主区域的出口、方向与解锁条件一致。

- [ ] L01/L02/L03 在游戏中实际走通；若体验仍线性，继续改图。
- [ ] H01–H08 均可发现、进入、返回；次级出口按条件开启。

### 空间与交互
- [ ] 高位门只能从对应平台路线抵达。
- [ ] 每条门连接的进入与回程出生点都在可站立平台。
- [ ] 出生点不重叠门、隐藏入口、休整点或其他 E 交互焦点。
- [ ] 地面、低位、中层、高位路线在视觉和玩法上可辨。
- [ ] 角色死亡、重生、切图、读档后门状态与奖励状态正确。

- [ ] 关键枢纽有多个有意义的出口。
- [ ] 每条捷径确实减少路程或改变路线选择。
- [ ] 回访至少能发现一项新内容或新选择。
- [ ] 隐藏区域有差异化体验，不是统一的奖励小房间。
- [ ] 战斗难度与休整点分布有节奏；不以空跑或血量膨胀凑时长。

### 实机与时长
- [ ] 在 Godot 4.6.x 中实际跑通每条连接。

- [ ] 至少收集一轮完整首结局通关数据，再修正 18–24 小时目标。
- [ ] 所有结局与主要隐藏内容完成后，再评估 30–40 小时的高完成度目标。

## 10. 当前结论与下一步

当前设计已经有箱式世界的基础：多枢纽、9 条捷径定义、3 条显式宏观回环和 8 个正式隐藏区。但地图是否完整、是否好玩、是否满足目标时长，都尚未通过实机验证。

下一步顺序：

1. 完成 A2–A4 空间、门交互、回程出生点与 L01 验收。
2. 复核 A5–A8 中层路线和 L02，确保不是单线推进。
3. 复核 A9–A12 外环、圣堂、内城与 L03。
4. 对 H01–H08 逐一验收灵视、返回、次级出口和状态持久化。
5. 依据真实可玩路径调整地图，而不是只修改连接计数。
6. 地图验收通过后，再填充区域剧情、Boss 与支线，并通过试玩数据校准时长。

**地图的完成标准不是“所有区域都有名字”，而是玩家能在脑中逐渐建立一张互联世界地图，并因新能力、捷径和灵视发现而不断重新理解它。**
