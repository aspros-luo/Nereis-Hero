## 2. 北门回程净距

- A1 北门交互点：`x=2440`。
- A2 返回 A1 的出生点：`x=2310`。
- `village_poi.gd` 的交互半径：`110`。
- 水平净距：`2440 - 2310 = 130`，比交互半径多 20 px。

因此当前静态坐标没有把回程出生点直接放入北门 POI 的交互半径内。该结果只证明源码坐标符合约定；角色碰撞体、输入焦点和相机表现仍须运行时检查。

## 4. 本轮实现

更新 `tools/validate_graybox_scene_wiring.py`，增加主线静态断言，防止以后重构时意外破坏：
- A0 必须在三名守卫倒下后才开放出口；
- 序章完成状态在离开 A0 前写入；
- 防卫事件必须包含 3 + 4 的波次推进、胜利标记和返回村庄；
- 防卫失败流程重置计数并重新开始；
- 北门首进防卫、胜利后进入 A2 的条件分支仍存在；
- A2 返回 A1 的出生点应与北门交互半径保持净距。

同时清理验证器输出中的旧描述：终局入口使用共享结局评估器，而不是旧的“physical union”条件。
