# 主角能力与技能总设计 / Hero Ability & Technique Design

> 状态 / Status: **能力机制已接入源码；Godot 实机验收与数值调校待完成 / Mechanics implemented in source; runtime acceptance pending****
>
> 本文先定义“主角最终能做什么”，不决定能力在哪张地图、哪段剧情中解锁。剧情分配属于后续独立阶段。
>
> This document defines the protagonist's intended capability set before assigning any unlock to a level, quest, boss, or story beat.

## 设计原则 / Design principles

1. **少而有辨识度**：核心武器维持长剑与短刃；成长以动作能力、探索能力、战技异变和关键道具为主，不做庞大技能树。
2. **先完整实现，再安排解锁**：开发/验证阶段可通过临时 Debug 覆盖访问所有能力；正式流程仍必须遵循解锁记录。
3. **能力与剧情分离**：技能配置不硬编码某个地图或章节；地图只负责在合适的时机授予能力或提供理解条件。
4. **隐藏数值，明确反馈**：共鸣、人性、古神/外神接触与异常负荷不进入正式 HUD；能力动作、音效、敌人反应和环境变化必须让玩家感受到差异。
5. **不允许测试污染正式存档**：Debug 全解锁默认只在当前运行会话生效，不写入正式解锁记录；需要存档迁移或剧情解锁的测试必须另行明确执行。
6. **数值是起始值，不是平衡结论**：攻击倍率、消耗、时长与判定窗口需在 Godot 实机验证后调整。

## 一、基础战斗 / Core combat

### 首版特殊战技 / First-pass special techniques

- **断罪斩 / Judgment Slash**：长剑绑定战技；单次重击，耐力消耗 20，初始伤害倍率 1.6，起手约 0.35 秒，命中窗口约 0.14 秒。通过现有攻击判定与受击硬直制造失衡，不引入完整姿态破坏条。
- **残月连斩 / Crescent Combo**：短刃绑定战技；三次独立攻击判定，耐力消耗 16，每段初始倍率 0.65，判定时间约为动作开始后的 0.08 / 0.23 / 0.38 秒。每一段都可独立落空。
- **余响 / Eldritch Echo**：独立按键古神能力；耐力消耗 28，冷却 8 秒，短暂聚势后对 185 像素内的普通敌人施加短硬直；Boss 的控制时长限制在约 0.12–0.15 秒。首版不增加独立资源条、持续领域或触手自动攻击。
- **输入**：F 使用当前武器的绑定战技；R 使用余响；Q 切换武器；J/鼠标左键普通攻击；K/Shift 闪避。L 目前保留为旧拔刀斩原型的兼容输入，后续在能力/剧情迁移时再决定是否退役。
- **Debug**：F3 全局世界状态面板；F4 主角面板；F5 开启本次运行的全部主角能力/战技覆盖，并生成临时钩爪锚点、隐藏痕迹与标记攀爬墙；F6 恢复 HP/体力、清理能力临时状态与冷却并关闭命中框。G 钩爪、W 攀墙、Space 蹬墙跳、V 共鸣视野、PageUp/PageDown 选择拔刀形态。覆盖不得写入正式解锁或剧情存档。
- **范围边界**：当前阶段先完成主角能力机制和 Debug 测试入口；格挡/弹反若未纳入能力清单，不作为本轮阻塞项。快速冲刺、魔女时间、钩爪、墙攀与共鸣视野的正常流程解锁点留到后续剧情地图阶段。


| 动作 | 当前/目标规则 | 状态 |
|---|---|---|
| 长剑普通攻击 | 3 段连击；中距离、较大判定、末段重击；较高单击伤害与控制 | 已有实现，待实测 |
| 短刃普通攻击 | 4 段连击；贴身、快速、较低单击伤害、较低体力开销 | 已有实现，待实测 |
| 武器切换 | Q；长剑/短刃切换；攻击、闪避、受击期间禁止切换 | 已有实现，待实测 |
| 旧拔刀斩原型 | L；暂时保留兼容，不作为首版正式战技设计基准 | 兼容保留；待后续迁移/退役决策 |
| 普通闪避 | K 或 Shift；短距离位移与无敌帧；前 0.075 秒精准闪避，成功后下一次命中伤害 +35% | 已实现代码，待实测 |
| 受击/死亡/重生 | 受击硬直、击退、死亡反馈；死亡后重置当前遭遇而不撤销已取得的剧情能力 | 部分实现，待回归 |

## 二、移动与防御能力 / Mobility & defense

| 能力 | 设计目标 | 输入建议 | 解锁记录 | 状态 |
|---|---|---|---|---|
| 普通跳跃 | 基础地面跳与短暂土狼时间；无需解锁 | Space / Up | 无 | 已有实现，待实测 |
| 二段跳 | 空中仅追加一次跳跃；落地重置；不可无限连跳 | 空中再次按 Space / Up | `double_jump` | 已有判定接入，尚无正式授予点 |
| 极速冲刺 | 与普通闪避分离；水平快速位移，不提供闪避无敌帧；体力 24、持续 0.16 秒、冷却 1.10 秒 | X | `quick_dash` | 已接入原型；待实测 |
| 精准闪避 / 魔女时间 | 精准闪避前 0.075 秒成功回避后触发约 2.4 秒敌方 delta 缩放；主角不被同步拖慢 | K / Shift 普通闪避 | `witch_time` | 源码已实现，待 Godot 实测 |
| 钩爪 | 只连接 `grapple_anchors` 组；碰撞阻挡，支持超时/到达/目标丢失和 G 手动取消 | G | `grapple` | 源码已实现，待 Godot 实测 |
| 墙面攀附/蹬墙 | 只作用于 `wall_climb_surfaces`；W 攀爬、松开 W 滑落、Space 蹬墙跳 | W / Space | `wall_climb` | 源码已实现，待 Godot 实测 |

### 移动能力的边界

- 普通闪避负责短时规避并提供无敌窗口；极速冲刺使用独立的 X 输入，负责快速水平位移，不提供无敌窗口，并有自己的体力成本与冷却。
- 精准闪避必须通过攻击判定窗口验证，不应单纯按下闪避就触发。
- 钩爪第一版只认锚点标记，不允许任意墙面吸附。
- 墙面攀附与钩爪是两种不同的关卡能力，不能互相替代。
- 所有关键路径能力最终都必须有主线可获得方式；支线可以提供额外变体，但不能因为玩家漏读文本就永久堵死主线。

## 三、旧拔刀斩原型 / Legacy iaijutsu prototype

L 键与血色、深渊、黑色天际拔刀斩目前仍保留在代码中，主要用于兼容旧存档与已有实验效果。用户已明确拔刀斩最初只是举例，并非最终特殊战技方案，因此这组旧招式不视为首版已确认的正式战技路线。

- 新的首版正式战技以 F 触发：长剑断罪斩、短刃残月连斩。
- 新的古神能力以 R 触发：余响。
- 旧拔刀斩代码暂不删除，避免一次性破坏旧存档/现有流程；待新战技稳定、故事授予点迁移后，再决定如何退役或重新设计其异化路线。
- 旧异化数值只代表遗留原型，不作为新战技的平衡基准。

## 四、主角能力 Debug 覆盖 / Protagonist ability debug override

Debug 覆盖只在当前 Hero 实例与当前运行会话生效。F5 可测试所有已经接入源码的主角能力，包括二段跳、快速冲刺、魔女时间、钩爪、攀墙/蹬墙跳、共鸣视野、长剑/短刃战技与四种拔刀形态；临时锚点/隐藏痕迹/标记墙不会写入场景文件或存档。机制是否最终通过，仍以 Godot 实机验收为准。

- F3：全局世界状态面板；F4：主角本地面板；F5：当前会话全部能力覆盖；F6：资源/状态重置。
- G：钩爪（再次按下取消）；W：攀墙（松开后滑落）；Space：蹬墙跳；V：共鸣视野；X：快速冲刺。
- PageUp/PageDown：F5 开启时在四种拔刀形态间切换；按 L 执行形态测试。
- 原有测试剧场使用 F10/F11/F12；这些快捷键在主角输入层之外处理。
- 覆盖只保存在内存中，不调用存档解锁方法；关闭覆盖后，角色立即重新遵循正式能力解锁记录。
- 调试面板显示当前动作、余响冷却和覆盖状态。正式 HUD 不显示隐藏剧情数值，也不增加新的资源条。

### 验收

- [ ] 开启覆盖后，长剑 F 使用断罪斩、短刃 F 使用残月连斩、R 使用余响。
- [ ] 关闭覆盖后，未正式解锁的战技无法使用。
- [ ] 重启游戏后，覆盖不会保留。
- [ ] F5/F6 不会保存战技解锁、材料、成就或剧情路线。
- [ ] 开启 F5 覆盖后按 X 可冲刺；关闭覆盖且没有正式解锁时，X 不会启动冲刺。
- [ ] 冲刺消耗 24 体力、持续约 0.16 秒，不产生无敌帧，冷却约 1.10 秒；这些数值需实测后再调校。
- [ ] 受击、菜单输入锁、死亡重生和休息恢复不会留下冲刺状态或缓存动作。
- [ ] Debug 不绕过受击打断、死亡、菜单输入锁或场景切换。

## 五、统一能力验收矩阵 / Shared validation matrix

每项主动能力都必须验证以下项目：

1. **输入**：地面、空中、攻击中、受击中、菜单打开时输入是否正确。
2. **状态机**：是否能被打断；打断后是否恢复正常；是否存在动作卡死。
3. **资源**：体力/生命扣除时机、资源不足时行为、资源不会低于合法范围。
4. **判定**：距离、方向、碰撞框、无敌帧、攻击窗口与敌人反馈。
5. **组合**：跳跃→空中攻击、闪避→反击、冲刺→攻击、钩爪→落地/攻击、攀墙→蹬墙跳。
6. **死亡/场景切换**：临时状态清空；正式解锁保留；Debug 覆盖按设计恢复。
7. **存档**：只保存正式解锁；不保存临时 Debug 覆盖。
8. **反馈**：动画、特效、音效、命中反馈、Debug 日志与玩家可感知差异。
9. **回归**：长剑与短刃、Boss 战、村庄交互、暂停/菜单输入锁均不被新能力破坏。

## 六、开发顺序 / Implementation order

1. 完成断罪斩、残月连斩与余响的基础输入、资源、判定和受击反馈。
2. 使用 F4/F5/F6 执行主角调试与战技回归；用 X 验证快速冲刺，并确认 Debug 不污染正式存档。
3. 在基础战技通过运行测试后，再选择一项人类战技设计异化形态；不同时开发全部变体。
4. 再决定能力的剧情授予点、地图用途、Boss 门槛、支线变体和结局差异。
5. 完成 Godot 实机验收并校准能力手感后，再决定二段跳、钩爪、攀墙、共鸣视野等能力的剧情授予点与地图路径；本阶段不新增剧情/关卡内容。

> **当前状态声明：** 本文包含能力设计基线与本轮特殊战技规格，不代表所有能力已完成。断罪斩、残月连斩、余响已提交首轮代码；静态结构检查已通过，但当前执行环境没有 Godot 可执行程序，尚未完成 Godot 运行测试。不能把静态检查视为运行通过。
