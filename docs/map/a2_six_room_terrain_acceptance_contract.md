# A2 雾林与钟墓：六房间并行地形设计合同

分支：`feature/story-map-progression`

> 本文是地形实现与验收合同，不替代 Canva 原稿。六个房间必须并行设计；每个房间的地形、碰撞、入口方向和回环都必须能在 Godot 编辑器中直接看见、选中和修改。禁止把主要地形改为运行时脚本生成。

## 全区硬约束

- A1 的后山/森林入口进入 A2 后，出生点必须在 R01，而不是区域中段或 R05。
- R01 是真正的分流枢纽：地表主路通往钟墓方向；树根/枝干形成向上的树冠路线；向下路线通向钟墓坑道。
- 地形完成前不加敌人、NPC 或战斗遭遇。
- C03、C04、H02 及 WorldState 的跨区状态合同不可因房间改造而丢失。
- 内部连接必须形成可走的空间路径；地图拓扑上的连线不能代替碰撞与实际通行。
- 所有 StaticBody2D / CollisionShape2D / 可视地形必须作为 .tscn 中的编辑器节点保存。
- 平台的横向间距、垂直落差按现有主角运动参数进行实机验证；静态脚本检查不能宣称跳跃可达。

## 参考图约束（Canva A2 v0.1）

以用户提供的《NEREIS-HERO A2 雾林与钟墓区域内部地形草图》为方向：地面林间十字路口是分流点；古代钟墓必须有垂直三层结构（上层墓坎 / 中层墓室 / 下层墓窑）；树冠层与根系跳线属于可选上层探索；安全落脚点与机制交互点需要留出空间。先完成地形和高差，不放敌人，不定战斗数值。此参考图是空间关系草图，不应被误读为单一横向平台路线。

## 六房间并行设计目标

| 房间 | 地形职责 | 必须存在的路径关系 | 验收重点 |
|---|---|---|---|
| R01 林间岔路 | A1 入场后的空间枢纽 | 西侧入口；地表向东推进；树根向上接 R02；下行通向钟墓外环 | 入场点明确，至少两条可辨认探索方向；不能走几步就抵达出口 |
| R02 树冠与共鸣桥 | 高位探索与可见目标 | 从 R01 上攀；断桥两侧有视觉联系；高位路径可回接林地/朝圣高路 | 高低层分明，跨越间距可验证；不能只是等距阶梯 |
| R03 钟墓上环 | 钟墓入口与上层环路 | 从林地/高路抵达；上环绕过钟室；存在向 R04 下坠的入口与回看地标 | 至少一条上环路径和一条下行路径；落差可辨认 |
| R04 钟墓坑底 | 深坑着陆、下层探索与回程 | 从 R03 落下；坑底有安全落脚区；侧向石沿连接可攀回的路线 | 不能只是一个小平台；着陆空间与回程路线分开，避免软锁 |
| R05 旧朝圣高路 | 跨区高路、捷径与回接 | 接林地远端；高路能向钟墓上环回接；保留 C04 的高位捷径合同 | 不能变成单向长走廊；捷径开通前后路线长度确实改变 |
| R06 东侧沟壑 | 深落差、底层通路与远端出口 | 高路/树冠能看到沟壑目标；上层和下层路径存在有意义的落差；保留远端区域出口 | 检查落下后是否可返回/是否为有意单向落差；所有着陆点有碰撞 |

## 房间入口与区域合同

- 进入 A2 的首次出生点固定为 R01 西侧入口。
- 进入房间必须指定入口标记；不能以一个区域级出生点代替六个房间的入口状态。
- 由房间间转场进入时，保存目标房间 ID 和入口 ID；回到 A2 时优先恢复合法的房间入口/存档位置。
- C03/C04/H02 仍然由原有区域/世界状态合同控制，房间内连接不得伪造跨区出口。
- 若本轮仍采用父场景装配六个房间，必须明确这只是编辑器可见的区域地形装配，不得标记为“独立房间转场已完成”。

## 当前实现状态（诚实边界）

六个 .tscn 已作为可编辑场景实例放在 A2 父场景中，平台使用局部坐标。当前控制器仍将它们装配在同一个 `ash_forest.tscn` 区域中；独立房间切换、每个房间的入口标记与实机可达性仍需完成和验收。当前平台计数校验只证明场景节点存在，不证明地形设计已达标。
