# 地图门槛与回程验收矩阵 / Map Gate & Return Acceptance Matrix

> 状态：静态验收合同；尚未代表 Godot 4.6.x 实机通过。  
> Status: static acceptance contract; not yet a passing Godot 4.6.x runtime test.

本表把宏观拓扑、灰盒场景和灵视隐藏入口转成可重复的走图测试。任何代码修复后，至少重跑对应场景、主线通路和存档恢复用例。不要因静态脚本通过而将引擎验收标为通过。

## 4. 异常来源顺序与旧存档 / Source order & legacy saves

- R01 → R08 的来源 ID 必须唯一；重复调查不能重复发放鸣响或接触度增量。
- R01 必须解锁现有的 `resonance_sight` 能力；若旧存档已有 R01 来源但缺少该能力，允许一次交互修复能力与最低状态。
- R04 / R05 / R06 采用古神接触度下限，不能因玩家错过序章线索或跳过可选区域而永久锁死后续门槛。
- R07 的外神接触度下限受外神共鸣故事事实约束；单纯调查镜街来源不能替代剧情事实。
- R08 与外神共鸣剧情的触发顺序必须互换测试：先触发剧情再调查 R08，以及先调查 R08 再触发剧情，最终外神接触度都应达到 18。
- 旧存档缺少 `discovered_hidden_regions`、`opened_hidden_paths` 或 `entered_hidden_regions` 时，读取不应报错；缺失字段按空集合恢复。

## 5. 出生点、死亡与交互焦点 / Spawn, death, and interaction focus

每个入口至少做以下往返测试：

1. 从父区域进入隐藏区，确认出生在远离入口交互半径的位置，不会落地就重复触发 E。
2. 从隐藏区返回父区域，确认出生侧和方向正确；不应在门、敌人或致命碰撞体内部。
3. 已开启捷径后，死亡回到检查点，再次经过门时仍可使用；未开启的门不应因死亡自动开放。
4. 同一位置若有 NPC、出口门、异常调查点或隐藏入口，只有最高优先级且可用的交互对象显示 E 提示；不可交互的对象不应抢占焦点。
5. 切换场景后清除临时灵视、暂停和输入锁状态；永久通路与调查记录保留。
6. 在每个隐藏区执行一次保存 → 退出 → 继续游戏，确认恢复场景和出生侧有效。
