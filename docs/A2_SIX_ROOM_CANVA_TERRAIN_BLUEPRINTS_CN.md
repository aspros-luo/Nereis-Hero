## 1. 全区空间合同

- 玩家从 A1 北门进入 A2 后，必须落在 **R01 林间岔路**，不能出生在 R02、R03 或地图中段。
- R01 是 A2 的第一个空间枢纽：地面主路继续向前通往钟墓方向；向上攀爬进入树冠路线。两条路线应在视觉上同时可读，但不可把树冠高路画成唯一主路。
- 六个房间对应当前源码场景：
  - R01 a2_r01_forest_crossroads.tscn
  - R02 a2_r02_canopy_bridge.tscn
  - R03 a2_r03_bell_tomb_gallery.tscn
  - R04 a2_r04_crypt_landing.tscn
  - R05 a2_r05_old_pilgrim_highroad.tscn
  - R06 a2_r06_eastern_ravine.tscn
- 房间连接必须体现空间连续性：进入门与离开门靠近相应边界 / 高差；跨房间门不能只存在于拓扑表中。
- A2 的区域身份是“雾林、树冠与古代钟墓”。使用树根拱架、雾中剪影、旧朝圣石构、钟墓的巨大垂直空腔形成可记忆地标。
- 必须保留主路可通行性、可选高路、向下落差与回程攀爬路径；鸣响桥是回访奖励，不得成为普通流程的强制门槛。
- 设计稿需标注地面、单向平台、实体墙 / 天花板、落差坑、入口 / 出口、可选路径、软门 / 远景目标、回程路线和环境叙事锚点。不要标敌人、NPC、战斗数值。

## 2. 六张独立房间图

### A2-R01｜林间岔路（入口枢纽）

**入口合同：** 西侧入口连接 A1 北门；A1 → A2 必须进入此房间。

**主空间：**
- 下层连续地面为安全主路，向东延伸到钟墓方向。
- 中段安排一个明显的树根分叉：地面路线继续向前；上方路线由错落树根 / 石沿攀升。
- 高处设置安全观察平台，让玩家看见树冠轮廓与钟墓的远景；远景可见不代表当前立即可达。
- 预留一处可从远处看见、初期无法直接抵达的树冠目标；不要用无意义的连续小平台填满空间。
- 地面和上层之间要有至少一个自然回落点，失败后能回到主路，不造成软锁。

**路线标签：** A1 入口 / 地面主路 → R03 钟墓方向 / 上层攀爬 → R02 树冠路线 / 可见但暂不可达的远景目标。

**环境叙事锚点：** 被砍断后又长回石缝的树根；与道路方向不一致的旧朝圣路石标。

### A2-R02｜树冠与断桥

**职责：** 承接 R01 的上层攀爬，形成有风险但可选的树冠探索线。

**主空间：**
- 用高低交错的粗树枝、断桥两端与垂落藤根构成明显的垂直节奏，不画成同高度横向平台串。
- 断桥应从远处可见；初次经过时可通过正常跳跃到达另一侧，或保留鸣响后固定的局部桥体作为回访捷径，具体能力门槛以现有合同为准。
- 下方应能看见雾林地面或钟墓外缘，强化高度感；至少一个位置允许安全落回下层路线。
- 出口应回接 R01 / 钟墓外围的合理高位落点，不能让树冠支路变成单向死路。

**环境叙事锚点：** 树皮上嵌入的旧石钉；断桥另一侧被雨水磨平、却仍朝向钟墓的朝圣刻痕。

### A2-R03｜古代钟墓上环

**职责：** 让玩家第一次读懂钟墓是一个垂直三层结构，而不是普通地面洞穴。

**主空间：**
- 以一个巨大竖向钟墓空腔作为主地标，安排上环、中层石廊与下方深坑的可视关系。
- 入口平台应能看见更深层，但不能从入口直接跳过中层探索。
- 上环有一条较安全的环绕路线；至少一段狭窄石沿 / 断口让玩家主动观察跳跃距离。
- 预留一条通往 R05 旧朝圣高路的高位连接，以及一条向 R04 坑底下行的明确落差路径。
- 钟体 / 钟锤的视觉方向应与环境线索形成矛盾感，但不要用大段文字解释。

**环境叙事锚点：** 没有钟锤磨痕却被磨亮的钟壁；被拆除的石棺基座与年代不一致的修补石材。

### A2-R04｜钟墓坑底与回程石沿

**职责：** 落差探索空间。允许玩家主动下坠进入深处，但必须提供清楚、可读的回程路线。

**主空间：**
- 坑底应有足够宽的落脚区，能让玩家停下来辨认环境；避免入口落点直接落进不可返回的坑。
- 通过东西两侧错层石沿构成三层垂直结构，平台之间的高度差应与当前主角跳跃能力相容。
- 下层主路与上行回程路线应明显区分；回程不应依赖像素级跳跃或隐藏的无提示墙跳。
- 设置一个被水线 / 沉积物标记的深层边界，暗示更深处仍有空间，但不要在此阶段添加敌人。
- 与 R03 的落差连接必须明确；与 R06 的深层 / 东侧路径连接需遵守全区连接合同。

**环境叙事锚点：** 水位线高于现有排水口；棺床被拖向墙内却没有对应出口。

### A2-R05｜旧朝圣高路

**职责：** 让玩家从高处回望雾林与钟墓，并形成一条区别于地面主路的跨区路线。

**主空间：**
- 高路以旧石桥、崩塌祭台与高位石沿形成宽窄变化；避免重复 R02 的树枝语言。
- 路线应有一段宽阔观察区与一段谨慎通过的窄路。
- 保留 C04 高位落点 / 捷径的空间位置，但实体门与出生点须按连接合同核对。
- 高路要能回接主区域，不得以一个不可返回的远端门结束；关键出口不能绕过主线剧情门槛。
- 让玩家从此处看见钟墓上环的轮廓，建立区域内部方位感。

**环境叙事锚点：** 石碑上的朝圣人数被反复刮改；只留下脚印却没有回程脚印的祭台。

### A2-R06｜东侧沟壑

**职责：** 构成 A2 东侧的地形边界、上下双路线和通往远端连接的空间准备。

**主空间：**
- 上层是可辨认的森林 / 石沿路线；下方是一处明显深于普通地面的沟壑，能看见下层落脚平台。
- 沟壑底部必须提供可读的回程台阶或明确的单向落差设计；不要把小平台放成无法判断是否可跳的密集梯子。
- 远端出口对应 C03 的实际落点合同；图上应标出门内安全站立区和进入后的行进方向。
- 远景可展示雾中更深的森林轮廓，但不擅自把保留的未来入口接通。
- 与 R01/R02 的上层路线形成视觉呼应，与 R04 的深层落差形成高低对照。

**环境叙事锚点：** 沟底有被冲刷到高处的钟绳纤维；石壁上旧地图的路线线条在裂缝前突然中止。

## 3. Canva 绘制规格

- 每个房间独立一份 Canva 设计，不把六个房间塞进同一张超长画布。
- 每张图使用横向 16:9 或宽幅画布，标注房间 ID、入口 / 出口、推荐行进方向和层高关系。
- 视觉主图画实际侧视地形；另用简短图例说明：实体地面、单向平台、墙体、落差坑、隐藏通道、能力门、鸣响桥、检查点预留位置。
- 画面重点是可用于 Godot 的可玩空间形状与路线关系，不是宣传海报或纯氛围插画。
- 所有路线必须能映射回当前 Godot 场景节点；不能只用线条表达“这里可以过去”而不画出实际落脚面。
- 设计完成后逐张核对源码场景、区域拓扑、入口出生侧、回程落点与角色跳跃包络。静态核对通过不等于 Godot 实机验收通过。
