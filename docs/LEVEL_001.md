# Level 001 — Village Outskirts

The first playable space is a horizontal path through the village outskirts.

## Route

**Awakening → Old Hunter → Checkpoint → Cultist → Ash Gate → Ashen Knight**

The level is intentionally linear for the first vertical slice. Its purpose is to validate movement, combat, one narrative beat, a checkpoint loop, and a first boss encounter before branching exploration is introduced.

## Encounter pacing

- 320: Hero awakening
- 680: Old Hunter
- 980: Checkpoint
- 1400: Cultist encounter
- 1800: Ash Gate
- 2080: Ashen Knight

## Acceptance

The player should be able to travel through the entire space without a scene transition.

The camera should reveal new space as the Hero moves right.

The checkpoint should remain active after it is reached.

Defeating the Cultist opens the Ash Gate.

Defeating the Ashen Knight ends the first combat arc and reveals a fragment of the Hero's missing memory.
