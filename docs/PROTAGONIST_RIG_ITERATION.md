# 主角分层骨骼迭代记录 / Hero Cutout Rig Iteration

## 本次改动 / Changes

- 主开发分支：`feature/protagonist-system`。
- 更新 `scripts/player/hero_skeleton_visual.gd`，继续使用现有 `Skeleton2D` / `Bone2D` 分层骨骼，不另起第二套角色显示系统。
- 攻击姿势增加三段差异化的手臂、武器与躯干旋转曲线；起手蓄力与挥击阶段有更明显的姿态区分。
- 保留脚底锚点和左右翻转规则；长剑/短刃仍由同一武器骨骼切换纹理。
- 增加中英双语注释，明确分层图集共用 192x224 画布的定位假设。

## 正反方评审 / Pro-con review

**正方 / Pro**
- 使用已有 SVG 部件与骨骼层级，改动范围小，便于迭代。
- 不影响攻击伤害、碰撞框或资源扣除；动画仅控制视觉骨骼。
- 三段攻击有不同的姿态节奏，能更好配合现有三段连击。

**反方 / Con**
- 当前是 rigid cutout rig（刚性分层骨骼），不是蒙皮骨骼；关节处仍可能露缝或出现肢体穿插。
- 旋转曲线基于现有状态的 attack_progress 推导，未接入逐段 combo_step 专属动画时间，因此仍需实机微调。
- 缺少实际运行截图与帧级观测，不能声称视觉已验收。
