# A1 后山多峰路线拓扑草案

> 状态：拓扑草案；未分配正式 A/C/H 编号，未实现运行时场景。  
> 分支：development  
> 目的：把多峰山路从气氛描述推进为可审计的节点、连接、回环、门槛与失败恢复合同。  
> 约束：不擅自决定山顶连接哪个 A 主线区域；不把金正救援事件塞进本图；不把隐藏神职人员遭遇当作主线必经点。

## 1. 当前审计发现与设计边界

- 世界拓扑基线目前定义 A0–A13，并把 A1 定义为边境村庄。后山在总体地图中是否独立成为 A 区域尚未决策，因此本草案先把后山作为 A1 相关的局部子区域，不提前增加正式区域编号。
- 世界状态中已经存在 `double_jump`、`grapple`、`resonance_sight` 等能力 ID，也存在库存与持久化隐藏路径标记；但仅有 ID 不代表能力已在实际流程中按时发放，也不代表已有火焰伤害抗性接入点。
- 世界拓扑已有需要抓钩的其他探索门合同。因此，本路线的决定是**不依赖抓钩**，而不是宣称项目不存在抓钩能力。若后续确认抓钩已在别处成为稳定、可复用的核心能力，再另行评估是否给后山提供可选捷径。
- 二段跳的实际获取节点仍待审计，但这不限制后山设计能力门槛：后山可以在玩家尚未取得二段跳时提前开放，并在高台等明确位置形成硬性能力门槛。玩家抵达门槛后无法继续，须返回探索其他区域并在取得能力后回访。实现前仍要确认门槛可读、可记忆、可回访，不形成无提示软锁。
- `resonance_sight` 的解锁时点与当前隐藏目标规则仍待验证。隐藏封印可以先按“感知能力候选条件”设计，但实现前必须验证；若能力来得太晚，则改用既有探索中取得的线索/印记，不为单扇门新造收集系统。

## 2. 局部节点图

节点 ID 仅用于本设计文档，不等于正式地图区域编号。

| 节点 | 功能 | 主要空间形态 | 风险与回报 |
|---|---|---|---|
| BM-00 山脚入口 | 入口、地形教学 | 宽岩路、低矮树根与安全平台 | 低风险；先读懂山体轮廓 |
| BM-10 第一峰脚 | 首次空中敌人遭遇 | 有承托的坡道、宽平台 | 单只鹰类或蜂群，不与精确跳跃叠加 |
| BM-20 第一断谷 | 第一次吊桥跨峰 | 吊桥、桥头稳定落脚区 | 暴露感强；破损段应有明显预警和可恢复落点 |
| BM-30 环山旧道 | 绕峰推进、空间记忆 | 沿岩壁横向延伸的栈道/旧路 | 能回望吊桥和山脚，避免重复背景迷路 |
| BM-40 高位岩架 | 二段跳硬门槛与高位探索 | 明显高于普通跳跃极限的岩台、上层通路 | 未取得二段跳时在此明确止步；取得后回访可继续上攀，并获得高位奖励/捷径 |
| BM-50 第二峰交通枢纽 | 多条路线汇合 | 山脊、第二座吊桥或岩壁横道 | 让玩家辨认龙峰方向，建立地标 |
| BM-60 上层火路分岔 | 隐藏神职人员支线入口 | 主路与侧向火焰通道分开 | 火路非主线必经；斗篷降低伤害但不免疫 |
| BM-70 龙峰前庭 | Boss 战前读招与补给窗口 | 开阔岩台、明确退路 | 远景/声音提示飞龙；战斗区与窄平台分离 |
| BM-80 飞龙战场 | 山顶 Boss | 宽阔、可辨识的战斗场地 | 火焰覆盖、蓄力与安全窗口必须清晰 |
| BM-H1 隐藏封印 | 支线入口条件验证点 | 焦黑符号、旧祭坛或异常岩壁 | 斗篷负责通过火路；感知/印记负责发现封印 |
| BM-H2 神职人员遭遇 | 独立可选遭遇空间 | 与攀登主路隔离的战斗房间 | 独立出生/复活与返回合同，不把玩家重生到火焰触发区 |

## 3. 连接与流程合同

1. **BM-00 → BM-10 → BM-20**：首次进入以可读路线为主，但不保证所有路段都能立即通过。玩家可以提前到达后山；若遇到二段跳硬门槛，应能看清上层目标与无法继续的原因，并有安全退路返回其他区域。
2. **BM-20 → BM-30 → BM-50**：吊桥负责跨越断谷，环山旧道负责绕峰。两者承担不同空间功能，不要把所有路线都做成连续跳台。
3. **BM-30 → BM-40 ⇢ BM-50**：BM-40 是刻意设置的二段跳硬门槛，未取得能力时不能穿过；箭头表示取得二段跳后回访可继续。门槛附近需有安全回撤路线、清晰的高台轮廓和可记忆的地标。不得用看不见的空气墙阻挡玩家。
4. **BM-50 → BM-60 → BM-70 → BM-80**：主线始终朝龙峰可读推进。火路分岔在视觉上可辨认，但不应堵住前往龙峰的常规路线。
5. **BM-60 → BM-H1 → BM-H2**：可选支线需要斗篷通过火路，并满足第二个发现/交互条件。门开启状态持久化；离开场景或死亡不能要求玩家重复完成整段火路才能再次进入已开启的支线。
6. **回环候选：BM-50 开启山脊旧闸/落桥 → BM-10 或 BM-20 的安全侧**。这是本图最值得保留的一条捷径：首次绕行仍有探索价值，开启后回程明显缩短。具体落点必须在灰盒里验证，不允许捷径出口贴着门触发区或落在无承托地面。
7. **BM-80 的外部连接暂缓**：到达飞龙战场后，究竟连接新的 A 主线区域、回到已知区域，还是暂时作为终点，须由全局主线拓扑审计决定。本草案不虚构连接编号。

## 4. 双重门槛与可恢复性

### 火焰斗篷

- 获取事件在另一张地图：主角救下金正的性命后由金正赠予。本图不规定该地图的地理位置、事件顺序或剧情细节。
- 建议先把效果设计为火焰伤害减免，而非免疫；40% 只是待测试的初始平衡值。
- 火路应采用有节奏的伤害判定、清晰的火焰预警与安全停留点。若不带斗篷，玩家应能识别危险并回头，不得被单向地形困住。

### 隐藏封印

- 首选复用项目已有的隐藏路径持久化能力，不另造门状态体系。
- 感知能力必须在实际进度中可获得、可操作，并且符合现有隐藏目标判定规则；未验证前不写成已确认依赖。
- 没有第二条件时，环境仍要提示“此处有异常”，但不能直接显示任务清单或把隐藏门伪装成失灵交互。
- 隐藏 Boss 战失败后，重生点应位于独立战斗空间的安全检查点；返回后可从安全侧重新进入，不把玩家送进火焰持续伤害区。

## 5. 敌人与平台公平性

- 鹰类、杀人蜂优先放在有足够落脚空间的区域，攻击前摇与飞行轨迹可读。
- 狮鹫定位为中后段精英威胁，至少给出稳定战斗平台；不要在窄吊桥上同时放置高击退敌人和高精度跳跃。
- 吊桥的危险来自暴露、断裂感和敌人接近，而不是隐藏碰撞或不公平击退。
- 二段跳可以作为真正的区域推进门槛，而不只是可选奖励：玩家可先探索后山低层，在明确高台处止步，待其他区域取得二段跳后回来继续。门槛前后必须提供清楚的空间提示与安全回撤。
- 飞龙战场必须能读懂火焰覆盖区域和安全窗口。斗篷降低失误代价，不替代闪避机制。

## 6. 实施顺序与验收门槛

### 进入灰盒前必须完成

- [ ] 从实际流程确认二段跳解锁位置与首次进入后山时的可用性。
- [ ] 审计 `resonance_sight` 的发放节点、隐藏目标实现方式和持久化标记；若条件不合适，选择已有线索/印记作为替代。
- [ ] 审计库存物品与受击/火焰伤害计算链，确定斗篷能否用现有架构实现被动效果。
- [ ] 决定后山入口在 A1 中的实际位置，但不改变 A1 既有井口、旧排水口、教堂和崖壁洞窟逻辑。
- [ ] 全局拓扑审计前不分配山顶正式 A/C 编号。

### 灰盒完成后的验收

- [ ] 从入口连续走通至飞龙战场，不跳过任何连接节点；再从山顶按设计回程完整返回。
- [ ] 验证未取得二段跳时玩家可以抵达能力门槛、识别阻挡并安全回撤；取得二段跳后回访可继续通过，且不会出现其他意外阻断。
- [ ] 验证火路在无斗篷、有斗篷两种状态下的风险、退出与死亡恢复。
- [ ] 验证隐藏封印未满足条件、满足条件但未开启、已开启并离场/死亡后再次返回三种状态。
- [ ] 验证捷径开启前后路线长度确实有差异，且双向出生点都有承托、与门触发区保持安全距离。
- [ ] 验证空中敌人击退、吊桥边缘、落差恢复、检查点和 Boss 失败回程。
- [ ] 运行完整连接拓扑与场景验收；没有实际运行的项目明确标为未验证。

## 7. 当前明确不做

- 不为后山单独开发抓钩。
- 不假设玩家首次抵达后山时已经拥有二段跳；允许后山出现明确的二段跳硬门槛，要求玩家回访。
- 不把火焰斗篷做成免疫。
- 不把隐藏神职人员遭遇设为主线门槛。
- 不在全局地图审计前决定飞龙峰顶的 A 区域连接。
- 不在文档阶段提前写入实际场景坐标或声称运行时测试通过。
