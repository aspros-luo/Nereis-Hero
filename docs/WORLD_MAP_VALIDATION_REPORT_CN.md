## 1. 审查结论

目前的世界地图在**宏观连通性上成立**：14 个主要区域通过当前规划的 23 条区域连接全部连通，没有孤立区域。A3 废弃城区、A4 下水道与旧水库、A9 王城外环具有较高的连接度，适合承担多入口与回环；A0 作为单入口序章、A13 作为终局分支也合理。

但不能将当前总图称为“已经实机验证通过的完整游戏地图”。A2–A12 的主路线灰盒已接入；H01–H08 均已有灰盒场景与专用灵视入口代码，A11 的 C15 / C19 两条替代入口与 H08 结局出口也已接线。H08 出口复用现有结局评估器，并且只有身体交融状态成立时才显示。独立 A13 场景仍未建立，全部区域的 Godot 跑图也仍待执行。因此当前状态是：**拓扑静态通过，H01–H08 / C15 / C19 代码接线已完成一轮，实际关卡连通与运行时行为待验证。**

## 3. 仓库现状检查

### 3.1 当前场景与完整地图的差距

仓库当前含有开场、村庄 Hub、村庄墓园、古代研究实验室、室内 / 路线场景和若干导演测试场景。它们是现阶段实际存在的场景资产，但不能直接等同于 A0–A13 的完整区域实现。

- A0 开场与 A1 村庄可作为现有基线继续使用。
- 村庄墓园和古代研究实验室可以为 A2 / A11 的部分叙事提供参考，但当前不应把它们直接认定为完整的钟墓或深层研究区。
- A2–A12 的主线灰盒和 H01–H08 隐藏区域灰盒均已加入，场景路径与 WorldState 继续游戏映射对齐。A8 的 C15 入口需要 R01 / R06 来源、鸣响 55 与古神接触度 2；A10 的 C19 入口需要 R07 来源、鸣响 68、外神接触度 12 和外神共鸣标记。A11 中 R08 将鸣响目标提高到 78，并把外神接触度增加 6；H08 进一步检查三处前置异常与两类接触度。H02–H06 现有独立场景、入口符号和远侧捷径代码，已纳入静态接线检查。独立 A13 场景仍未制作。当前区域均为空间灰盒，敌人编排、Boss、检查点细化和最终美术尚未完成。
- A0 到 A1 当前以场景转换承接。设计文档中的“山腹逃生道”可以在未来通过独立场景 / 通道加强连续感，不要求所有地图放进一个巨型场景。

### 3.2 灵视 / 鸣响系统已有基础

仓库中已存在以下机制：

- WorldState.hero_resonance：0–100 的隐藏鸣响值，并参与存档。
- ancient_exposure、outer_exposure：区分古神残留与外神影响的接触度。
- resonance_sight_active：灵视当前是否处于激活状态。
- 主角已有 resonance_sight 能力 ID。
- scripts/systems/resonance_hidden_target.gd：可根据鸣响值、两类接触度，以及灵视是否激活，显现隐藏目标。
- 目前主角灵视一次激活为 4.5 秒，消耗 10 点体力，冷却 6 秒。

这意味着应该扩展既有系统，而不是重新发明一个独立的“隐藏地图管理器”。

这一轮已补上首条实现链，但尚未在 Godot 4.6.x 中运行验收：

- `WorldState.mark_ancient_residue_awakened()` 在序章把鸣响提升到至少 12、古神接触度提升到至少 1；旧存档迁移继续保留这个最低值。

## 4. 需要修订的地图规则

### 规则 A：所有连接都要有方向

“区域 X 连接区域 Y”还不够。正式制作前，每条边都需注明：进入方向（单向 / 双向）、初次经过是否开放、需要鸣响 / 剧情 / 机关还是已有能力、从对侧是否能打开、开启状态是否保存、是否可能绕过主线关键事件、死亡后返回是否要重新经过同一遭遇。

### 规则 B：隐藏支路不能破坏进程

隐藏入口可以让玩家提前发现后期区域的轮廓，但从隐藏区通向主线后期地图的出口应从对侧锁住，或需要已经发生的世界状态。早发现可以奖励见识和物品，不能让玩家意外跳过必须发生的关键事件。

### 规则 C：鸣响是感知门槛，不是自动传送

玩家需要激活现有的灵视能力，并靠近地图里的异常点。鸣响达到门槛后，异常空间才显现；玩家随后主动调查并固定开启通路。显现效果结束不应使已永久开启的通道重新关闭。

### 规则 D：可读的空间线索早于隐藏通路

低鸣响时也应存在可供观察的细微不协调，例如影子方向不一致、钟声先于动作、墙面结构重复或水面反射出不存在的楼梯。高鸣响让这些线索变得可辨认，但不必用 UI 直接提示“这里是隐藏地图”。

## 6. 当前验收结论

**可以作为设计基准继续推进；还不能标记为“地图已实机验证”。**

当前最合理的下一步是进入 Godot 4.6.x 实机验收：先跑通 A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12 主路，再测试 A4 检修闸回环、H01 双侧井门、H02–H06 远侧捷径、H07 的外神剧情门槛、C15 / C19 两条 A11 入口、H08 的前置证据与终局出口，以及 A12 的结局评估器跳转。已额外对源码中的回访出生点与旧存档异常来源修复逻辑做静态检查；实机验收仍未执行，在通过之前不把任何灰盒标为已验证。接下来可持续做场景内路径几何、交互位置与检查点的静态排查，继续保护已冻结的战斗与角色基线。
