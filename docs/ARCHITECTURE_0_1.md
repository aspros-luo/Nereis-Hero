# Architecture 0.1

## Layering

- Player systems: hero controller and state.
- Debug systems: isolated debug visualization.
- Lore systems: world knowledge and narrative state.
- World systems: maps and gameplay spaces.

## Principles

- Keep Godot 4.6.1 compatibility.
- Avoid coupling lore progression with UI.
- Keep debug tools removable.
- Prefer incremental stabilization before feature expansion.

## Phase 0.1 Goal

Create a stable foundation for later combat, world, and narrative expansion.
