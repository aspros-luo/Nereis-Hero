# A2 子区域拓扑与空间验收合同（V1）

> 状态：设计合同；尚未完成 Godot 实机空间验收。  
> 适用分支：`feature/story-map-progression`。  
> 范围：只定义 A2 的子区域、连接、回环与空间可读性；不定稿 NPC、道具、敌人配置或钟声/朝圣路的核心秘密。

## 1. 本轮决策边界

本文件依据现有 `tools/world_map_topology.json`、`scripts/levels/greybox_world_region.gd`、`scenes/ash_forest.tscn` 和 `docs/NARRATIVE_PRESENTATION_AUDIT_AND_MIGRATION_CN.md`，将已选择的 D1–D4 转成可审查的空间合同。

- **D1：C04 与 H02 出口** — C04 是 A2–A5 的主要高路捷径。H02 默认只负责隐藏探索与返回 A2；其 A5 次级出口暂缓，不在本轮认定为已从运行时代码移除。若未来要恢复，必须证明它有独立的空间、玩法或探索价值，而不是重复 C04。
- **D2：高低路线关系** — 至少有一个地面观察点能让玩家将树冠高路与地面钟墓理解为同一片空间。此为视觉/空间可读性要求，不揭示新的剧情真相。
- **D3：钟墓入口门槛** — 钟墓外圈和普通坑底探索不增加共鸣门槛。H02 保留其已有的隐藏入口条件，不得将两种门槛混为一谈。
- **D4：常驻 NPC** — 本轮不新增 A2 常驻 NPC；先完成空间拓扑。未来如需角色，须由明确的空间/事件职责支撑。

## 2. 子区域职责

| ID | 名称 | 层级 | 空间职责 | 必须满足 |
|---|---|---|---|---|
| A2-S01 | 雾林地面 | 地面 | A1 地面入口、方向识别、地面主路与路线分叉 | 从 A1 落在地面；玩家不读目标弹窗也能辨认主路与上层路线的大致方向 |
| A2-S02 | 钟墓外圈 | 地面 | 普通侧路、绕行、坑底入口 | 可从地面主路发现；不受 H02 的共鸣条件限制 |
| A2-S03 | 钟墓坑底 | 低位 | 低位探索、H02 入口所在的关联空间 | 从外圈进入并能合理返回；H02 是可选支路，不是 C03 主线前置 |
| A2-S04 | 树冠栈道 | 上层 | C03 通往 A3 的双向高位主连接 | A3 返回 A2 后仍落在树冠高度；与地面钟墓至少在一处建立可读的视觉联系 |
| A2-S05 | 旧朝圣高路 | 上层 | C04 的 A2 侧接近段 | 初始时 C04 锁定；抵达 A5 后从远端开启，门与出生点均位于受支撑的高位平台 |

子区域可以是连续空间中的不同地形段，不要求每个子区域单独加载场景。新增子区域必须先证明现有五区无法表达其独立空间职责。

## 3. 区域内部连接

| ID | 起点 → 终点 | 初始状态 | 设计合同 | 验收重点 |
|---|---|---|---|---|
| SC007 | S01 ↔ S02 | 开放 | 地面主路至钟墓外圈 | 入口可读、无隐藏门槛 |
| SC008 | S02 ↔ S03 | 开放 | 外圈至坑底的高差连接 | 拓扑标记为双向；必须验证实际攀回可达。若是单向落差，则修正合同或设计替代回路 |
| SC009 | S01 ↔ S04 | 开放 | 地面至树冠层的主要爬升路线 | 上行和回返都必须有实际可达路径，不能只把平台链标成双向 |
| SC010 | S04 ↔ S05 | 开放 | 树冠栈道延伸至旧朝圣高路接近段 | 不代表 C04 已开启；C04 的锁定与远端开启规则保持独立 |
| SC011 | S02 ↔ S04 | 锁定 | 候选复用现有 `A2_BELLGRAVE_CANOPY_CROSSING`（鸣响值 20 + 灵视），先核对桥体端点是否真的连接 S02 与 S04 | 不新增未经证实的绳桥机关；先验证真实端点与持久化状态 |

**重要：** `travel: both` 只是设计数据，不是物理可达性的证据。尤其 SC008 的坑底回返与 SC009 的上下层双向移动，必须通过实机平台、碰撞、攀爬/跳跃能力验证。

## 4. 跨区域入口与出口合同

### C02：A1 ↔ A2

- A1 → A2 的落点位于 A2-S01 地面主路。
- A2 → A1 的返回仍使用地面路径，不要求玩家经过树冠层。
- 村庄防卫解锁条件沿用现有设计，不在本轮修改。

### C03：A2-S04 ↔ A3-S04

- 双向高位连接。
- A2 侧门、A3 侧门与两端出生点均需落在实际有碰撞承托的平台上。
- 从 A3 返回 A2 后保留树冠高度；不得静默落到 A2 地面。
- 不得要求先进入 H02。

### C04：A2-S05 ↔ A5-S03

- 初始锁定，由 A5 侧开启。
- 开启后 A2 侧回程门持久存在；两端出生点均位于高位承托平台。
- C04 是 A2–A5 的主要旧朝圣高路捷径。
- H02 不应默认再提供一条功能重复的 A5 出口。

### H02：A2-S03 ↔ 倒响钟室

- 保留现有隐藏区域身份、共鸣阈值、视域要求与持久开启行为；本轮不改阈值。
- 普通钟墓外圈/坑底的探索不应被 H02 的门槛阻挡。
- 进入后可返回 A2，且 H02 不是 C03 的前置条件。
- 拓扑中旧有的 H02 → A5 次级出口标记为延期审议。当前文档不声称该出口已从运行时场景移除；在后续实施时需专门核对场景门、出生点与保存状态。

## 5. 回环设计合同

### L-A2-01：地面—树冠回环（建议新增的空间闭环）

`S01 → S02 → SC011 → S04 → S01`

- 初次探索时，SC011 锁定；主路仍可通过 SC009 推进。现有代码已有 `A2_BELLGRAVE_CANOPY_CROSSING`（x=1380..1610、y=328、鸣响值 20、灵视），但尚未证明它连接 S02 与 S04，因此它只是优先核对的候选，不可直接认定为已完成这条回环。
- 若现有局部共鸣路线的实际端点确实覆盖 S02 与 S04，则优先复用该路线形成回环；否则先修正拓扑或设计新的连接方案，不要继续引用当前运行时不存在的 `opened_forest_rope_bridge` 状态。
- 这条回环应降低重复攀爬成本，而不是成为主线唯一通路。
- 目前它是待核实的回环合同。当前拓扑还存在 SC068（S01↔S04 的升降机合同），但 `elevators` 数组为空；必须先判定 SC068 是另一条独立路线、未来备选还是重复定义，再决定最终实现。

### L-A2-02：A2—A3 树冠往返（已有拓扑合同）

`A2-S04 ↔ C03 ↔ A3-S04`

- 主要价值是保持高位往返，不让玩家返回时跌落到地面。
- 该连接与 L-A2-01 分工不同：前者连接区域，后者连接 A2 内部高低层。

### L-A2-03：A2—A5 旧朝圣高路（后期回环）

`A2-S05 ↔ C04 ↔ A5-S03`

- 玩家首次经过时能够辨认高路的延伸，但不能提前穿过锁定门。
- 在 A5 远端开启后，路径变为双向，提供跨区捷径。
- 不与 H02 的出口重复。

## 6. 空间可读性与叙事边界

1. 至少一个地面视点能看见树冠高路的一部分、支撑结构或通往高层的明显方向提示。
2. 至少一个高层视点能确认下方存在钟墓/地面探索区域，但不需要显示其全部内容。
3. 入口、出口、休整点和关键高差处应避免把出生点直接放入门触发器、敌人重叠区或无承托落差。
4. 玩家不需要依赖首次进入弹窗，才能理解主路大致方向；环境几何和地标应提供基础导航。
5. 本轮只规定玩家可观察的空间事实，不规定异常钟声的原因、朝圣路的真实用途或 H02 的核心秘密。
6. 不因子区域显得空旷而自动添加 NPC、日志、敌人或道具。

## 7. 已发现的拓扑—运行时差异

- 旧 SC011 使用的 `opened_forest_rope_bridge` 在当前灰盒控制器中没有运行时引用，不能作为已实现状态使用。
- 当前代码已有 `A2_BELLGRAVE_CANOPY_CROSSING`，阈值为鸣响值 20、要求灵视且持久开启；其实际平台端点是否属于 S02↔S04 仍待核对。
- SC068 描述 S01↔S04 的实体升降机，但 `elevators` 数组为空。SC009 已描述同一对区域的双向爬升，因此需要明确升降机是独立替代路线、未来备选还是冗余连接。
- H02 的旧拓扑数据曾定义 A5 次级出口；本轮只将该出口标为延期决策，尚未声称运行时门或场景出口已删除。
- 现有 A2 局部共鸣路线开启时仍会调用叙事弹窗。是否迁移该弹窗属于后续叙事呈现审计，本轮空间合同不改写其文本，也不把弹窗当作路线存在的证据。

## 8. 实机验收清单

- [ ] 从 A1 进入 A2，出生在地面主路；反向返回 A1 仍落在地面主路。
- [ ] SC007 可双向通过，普通钟墓探索不要求共鸣值或视域。
- [ ] SC008 的坑底入口清晰，回返在物理上可行；如不可行，修正连接合同。
- [ ] SC009 从地面到树冠及树冠返回地面均有真实路线。
- [ ] SC011 未开启时不阻断主路；开启后从两端可重复使用，保存/重进后状态一致。
- [ ] 至少一处地面视点与一处高层视点能让玩家建立高低路线的空间联系。
- [ ] C03 往返后均位于受支撑的树冠/屋顶平台，不掉到地面。
- [ ] C04 未解锁时不可穿过；从 A5 开启后 A2 侧门持久开放，双端出生点均有承托。
- [ ] H02 可选、可返回 A2，不阻断 C03；本轮不增加新的 A5 出口。
- [ ] 检查目标提示是否过度提前说明探索方向，但不在此轮改写核心秘密。

以上清单只有在实际运行 Godot 场景、验证碰撞与转场后才能勾选。静态拓扑合同通过不等于实机验收通过。
