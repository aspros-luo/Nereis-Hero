## 1. 本轮完成项

H02–H06 现在不是只有设计条目：每个区域都有独立的 .tscn 文件，并复用统一灰盒控制器，拥有自己的标题、平台布局、环境地标和入口视觉符号。

| ID | 父区域 / 入口锚点 | 场景文件 | 鸣响门槛 | 接触度门槛 | 进入后返回 |
|---|---|---|---:|---|---|
| H02 倒响钟室 | A2 雾林 / 钟墓 | `scenes/hidden_bell_chamber.tscn` | 18 | 无额外要求 | A2；后期可从 A5 钟塔侧返回 |
| H03 被删去的第三街 | A3 废弃城区 | `scenes/erased_third_street.tscn` | 28 | 无额外要求 | A3；后期可从 A9 旧服务门返回 |
| H04 水面背后的楼梯 | A4 旧水库 | `scenes/reflected_stairwell.tscn` | 36 | 古神接触度 ≥ 1 | A4；后期可从 A8 王墓侧门返回 |
| H05 无声钟室 | A6 修道院钟塔 | `scenes/silent_bell_room.tscn` | 42 | 古神接触度 ≥ 1 | A6；后期开启钟塔落差后连回 A3 |

## 2. 各入口与返回捷径

### H02 — 倒响钟室

- A2 的钟墓入口 `H02` 需要鸣响 18。
- 抵达 A5 后，如果 H02 已开启，旧钟塔侧门出现。
- 在 A5 侧门按 E 后写入 `opened_old_bell_tower_connection`；第二次互动进入 H02。
- H02 通往 A5 的远端门只有在该标记存在后才可用。

### H03 — 被删去的第三街

- A3 旧市场入口 `H03` 需要鸣响 28。
- 抵达 A9 后，只有在 H03 已开启时才出现旧服务门。
- 在 A9 侧门按 E 后写入 `opened_old_service_door`；第二次互动进入 H03。
- H03 返回 A9 的远端门在旧服务门被打开前保持锁闭。

### H04 — 水面背后的楼梯

- A4 旧水库入口 `H04` 需要鸣响 36 和古神接触度 1。
- 到达 A8 后，H04 已开启才会显现王墓侧门。
- A8 的一次性开门标记是 `opened_royal_tomb_side_door`。
- H04 通过反射中的干燥阶梯构成独立空间，不要求玩家在 4.5 秒灵视窗口内完成平台跳跃。

### H05 — 无声钟室

- A6 钟塔入口 `H05` 需要鸣响 42 和古神接触度 1。
- H05 已开启后，A6 可使用钟塔落差通道返回 A3；首次开门记录 `opened_bell_tower_drop`。
- 这个出口不绕过主线，因为玩家必须先走过 A5 抵达 A6。
- A3 侧只有在 H05 已开启且钟塔落差已打开后，才出现重新进入 H05 的门。

### H06 — 王名抹除廊

- A8 王墓入口 `H06` 需要鸣响 55、古神接触度 2，并记录 `anomaly_bell_retiming` 与 `anomaly_erased_street_sign`。
- 这要求玩家曾在早期区域识别两个不同异常，而不是只靠刷高鸣响。
- 抵达 A9 后，只有 H06 已开启才出现王室运输侧门；开门标记为 `opened_royal_transport_side_door`。
- H06 返回 A9 的远端门只有这个标记存在后才可用。

## 3. 持久化规则

所有入口复用 `resonance_secret_gate.gd`；所有门复用 `interaction_door.gd`。

- 隐藏路径 ID 与区域 ID 分开记录。H02–H06 的入口路径 ID 就是 H02–H06；区域记录 ID 也为对应 H ID。
- 第一次调查成功后保存发现 / 开启状态。后续从另一侧进入时，`_on_exit_interacted` 会补记同一隐藏区域的进入状态，而不会创建新 ID。
- 远端捷径使用独立的一次性标记。路径开放与远端门开启是两个状态，避免玩家仅凭鸣响值提前跳关。
- Scene resume mappings 已加入五个 location ID；场景恢复仍须在 Godot 中实测。

## 4. 入口视觉符号

每个隐藏入口都有独立的符号，而不是所有入口都画成一块泛用发光石头：

- H02：钟体和错向回声弧线。
- H03：缺失第三方向的街牌。
- H04：现实与倒影方向相反的阶梯。
- H05：没有投下影子的钟塔窗。
- H06：被凿除姓名的铭文。

父区域中的视觉伏笔在低鸣响时仍然存在；入口符号只有灵视满足条件后才明显显现。

## 5. 静态一致性检查结果

通过远程文件的跨文件静态检查：

- 14 个主区域、23 条宏观连接和 8 个隐藏子区仍保持一致。
- H02–H06 的五个场景均有正确的 `region_id`、`location_id`、场景标题和 WorldState 恢复映射。
- 五个门 ID、五个专属入口符号、五套远端捷径标记都能在代码中找到。
- 22 个规划节点在所有预期门槛打开后仍全部可达，普通主线路径仍可不经过隐藏地图抵达 A12。

这是代码与机器可读拓扑的静态检查，不是运行 Godot 或运行 Python 验证器的结果。
