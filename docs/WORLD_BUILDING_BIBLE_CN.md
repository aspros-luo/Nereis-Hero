# Nereis Hero — 世界观总档案（中文）

> 状态：持续维护中的世界观权威汇总 / 2026-10-29
> 适用项目：仅 Nereis-Hero；若涉及 Nereis-Lullaby 或跨作品设定，必须明确标注。
> 工作分支：`feature/story-map-progression`
> 本文目的：汇总已确认世界观、人物边界、未定问题、文档冲突与变更记录，防止跨对话遗忘或把候选方案误写成正史。
> 维护规则：用户最新明确确认的设定优先。助手提出的方案、示例和推断，除非用户明确采纳，否则不得升级为正史。

## 1. 设定状态标记

- **【已确认】** 用户明确确认或已被权威设计规则确认的事实。
- **【候选】** 可以讨论的设计方向，不代表正式设定。
- **【待定】** 尚无结论，不可自行补全。
- **【冲突待裁定】** 不同现存文档记载不一致，必须保留冲突并向用户核对，不能静默选择一方。
- **【已废止】** 已被用户后续决策明确替代的旧方案；保留记录以便追溯。

任何新增剧情、NPC 身份、教派名称、历史事件、道具因果或结局流程，都必须先标明状态。

## 2. 世界的叙事原则

### 2.1 多线并行，而非两位神统领一切【已确认】

- 世界由多条能够独立成立、偶尔交叉的个人与社会故事组成。
- 古神与外神相关真相属于隐藏深层内容，不是所有人物、地区、信仰、骑士和事件的共同答案。
- 个人利益、信仰与誓约、王国与地方秩序、地区历史、人际关系、组织内部冲突，都可以有自己的动机、过程与结局。
- 一条故事即使不连接古神或外神，也应有独立价值；不要求每个 NPC、物品、遗迹都成为主线伏笔。
- 不同信仰可以独立存在，不预设它们最终属于同一体系或秘密组织。
- 玩家应先看见人的行为、日常与局部事实，再通过隐藏区域、跨地点证据与独立验证，逐步理解更深层的联系。
- 神祇相关线索不应在早期普通对话中频繁直接点名古神、外神、媒介或降临仪式。
- 线索可以隐晦，但必须能在后续证据出现后回溯验证；不能只是没有可验证含义的谜语。

### 2.2 小人物叙事方法【已确认】

每条人物或事件线应区分：
1. 真实发生了什么（作者侧事实）。
2. 人物实际知道什么。
3. 人物认为发生了什么（可能误解）。
4. 玩家在当前进度能合理推断什么。

人物先作为一个有日常、目标、利益、偏见、关系与后果的人成立，再判断其是否与世界级线索相交。不能先把人物设计成“线索传递工具”，再补一个表面生活。

### 2.3 信仰、身份与知识权限【已确认】

- 公开身份、实际组织归属、个人信仰、对隐藏真相的认知、是否参与异常事件，是不同维度。
- 骑士不必属于主教会；门徒不必知道信仰背后的真相；组织成员不必掌握组织全部计划。
- 不得仅凭祈祷、护符、服饰、标记或相似说法，就推断人物属于某个秘密阵营。
- 新增信仰或骑士组织时，必须先设计其日常实践、社会功能、成员差异与内部矛盾，不得只为隐藏主线临时创建。
- 金正是否属于某种信仰、门徒群体、骑士组织或其他势力，目前【待定】；不可提前绑定身份。

### 2.4 地图先承担叙事：区域职责与人物迭代【已确认的工作方法】

- 讨论地图时，必须同时写明**区域编号与区域名称**，不能只写“A2”“R01”等代号。这样用户可以直接构想该地应该承担的叙事职责。
- 设计顺序采用“全局地图叙事骨架 → 区域职责 → 人物与生活关系 → 事件/物品/环境证据 → 交叉审查 → 实机验证”。这是迭代顺序，不是要求先把所有地图做完才设计人物。
- 全局阶段先明确每个区域的独特体验、表层故事、空间表达、人的活动痕迹、探索价值与隐藏层次；不要求立刻画完所有房间地形。
- 再把人物放进真实的空间、工作、资源、危险与社会关系中；已有明确人物经历也可以反过来影响地点设计。
- 不把 NPC 预先写成世界观讲解者，也不把地图做成仅供放置敌人、道具和对话的空壳。
- 先设计可被普通玩家理解的表层故事，再用可回溯验证的证据支持更深层解释。错过隐藏内容时，区域与主线仍应有完整体验。
- 地形、房间连接、捷径、垂直关系与视觉地标都要有实际探索或叙事价值；不为了“复杂”而制造无意义通道或平台。
- 进入 Godot 实作时，地形必须由场景中可见的节点构成，不用运行时脚本生成地图地形；地图叙事设计最终需要在实际场景与可玩路线中成立。

## 3. 宇宙层面的已确认事实

### 3.1 古神【已确认】

- 古神是这颗星球原本存在的旧日支配者，目前长眠。
- 教会发现了古神尸体或遗骸，并研究其血液、毛发、皮肤等材料，涉及人体变异与武器研发等方向。
- 教会内部存在不同派系，但仍属于同一个教会组织。
- 掌权派希望利用古神力量巩固权力、震慑周边敌人；学术派希望获取更先进的知识。
- 两派可能为研究资源、保护与权力而合作，同时争执研究成果的用途。
- 教会成员不自动知道样本的真实来源、完整用途或全部后果。
- 古神研究与外神仪式不能被擅自写成同一项计划。

### 3.2 外神【已确认】

- 外神来自这颗星球之外，与古神性质不同。
- 外神是活动且不可理解的存在；不能用普通人类的征服、毁灭或入侵动机解释它。
- 外神只是一时兴起想来这个星球看看，但目前暂时无法来到这里。
- 蜜忒是外神选中的代言人/媒介，但她像纯洁的羔羊，不感知外神，也不是明知故犯的操纵者。
- 外神会精神影响蜜忒周围的人。部分人接触未知知识、窥见一点神识后，把体验误认为神迹，并开始研究让外神降临的仪式，逐渐形成另一种类似中世纪宗教的信仰。
- 与外神相关的人群包括蜜忒、村庄以及邪教核心人物，但各人认知不同；核心人物知道得较多，也不代表掌握全部真相。
- 不得把所有信仰者、村民、骑士或门徒都归入外神相关群体；必须有具体证据与人物因果支持。
- 不得擅自断言古神与外神之间存在确定联系。

### 3.3 王国衰败【已确认边界；原因待定】

- 王国正在衰败，但根本原因尚未定案。
- 不得擅自归因于外神、战争、王位继承、教会阴谋或其他单一原因。
- 衰败不意味着所有军队都弱。王都、禁卫与核心地区仍可能保持强大力量。
- 地方失序、资源分散、道路废弃、制度执行落差等只是可用来表现衰败的候选方式，不是已经确认的根因。

## 4. 核心人物设定

### 4.1 蜜忒【已确认】

- 纯真、好奇、情感真诚；她的纯真不是伪装。
- 她不知道自己与外神的真实联系，不应被写成有意识策划灾难的反派。
- 她的重要性应在回看时逐渐显现；早中期不应过度曝光或成为世界观讲解者。
- 她的日常生活本身要成立，不是每次出现都为了推进隐藏主线。
- 人物关系或亲密内容不应直接成为结局判定的数值条件；具体结局规则以结局条件权威文档为准。

### 4.2 金正【已确认核心性格；履历待定】

- 核心原则：利益优先。
- 聪明、善于观察和说服、能屈能伸、有自信；对强者有现实主义式尊重，对弱者缺少道德负担。
- 可以帮助、利用、欺骗、背叛或伤害主角及其他人，取决于利益、风险、筹码和局势。
- 可以真诚地在某一刻帮助主角，也可以之后为了自身利益背叛主角；帮助不证明他是好人。
- 不得在后续揭示中把他翻案为“其实一直是好人”，也不要用悲惨身世替其行为免责。
- 他的确切出身、首次登场、行动顺序、是否永久敌对、是否会死、最终命运仍【待定】。
- 他是否属于某个信仰、门徒群体、骑士组织或其他阵营仍【待定】。不得仅为让他连接隐藏线而指定身份。

### 4.3 外来朝圣骑士【已确认性格方向；身份细节待定】

- 正义感强、真诚、豪迈、直率、重视骑士礼仪、自来熟、严重路痴。
- 实力不弱，但对危险的判断偶尔过于乐观；他的迷路与笨拙不能把他降格为纯粹笑料。
- 他是穿行于破败世界中的另一个人，不是主角导师或世界观百科全书。
- 他应先有独立的旅途、信念与选择，再决定是否与隐藏线交叉。
- 姓名、朝圣目的地、朝圣原因、所属信仰/组织、路线与最终命运均【待定】。

### 4.4 其他 NPC【待设计】

- 已有核心 NPC 设计池中的候选原型仍是候选，不自动视为正式角色。
- 地区 NPC、功能 NPC 与普通世界 NPC 都应有各自的生活与动机。
- 不要让每个 NPC 都成为任务发布者、神祇线索提供者或同一阴谋的工具。

## 5. 三个结局：当前世界观含义

> 结局的程序条件、关键道具状态和特殊事件判定，必须以 `docs/ENDING_CONDITION_DESIGN_CN.md` 为准。本节只记录世界观含义，不替代程序合同。

### 5.1 凡人之墓【已确认】

- 主角没有发现完整的世界真相。
- 结局本质是政治权力交替；统治者更换不等于理解古神或外神。
- 主线应能在玩家不收集隐藏真相的情况下完成。

### 5.2 永恒乐园【已确认世界观含义；流程细节需核对】

- 这是知晓完整真相后走向的结局。
- 相关人物心甘情愿地完成外神的“恶趣味”，可类比《EVA》人类补完计划。
- 外神仍未真正降临；世界走向意识化，星球或王国失去原有物质形态。
- 不应简化成传统意义的胜利结局。

### 5.3 烈火天罚【已确认世界观含义；流程细节需核对】

- 已确认设计包含杀死 100 名教徒与杀死蜜忒的条件；细节和实际条件映射以权威结局文档为准。
- 外神已准备降临，但蜜忒作为媒介被杀，降临过程被烈火打断。
- 降临被打断不代表主角击败或消灭外神；外神仍然存在。
- 王国覆灭，所有人牺牲。
- 具体关键道具的交付/使用顺序、杀敌条件和剧情事件之间的关系，仍需在流程表中核对，不能自行补全。

## 6. 叙事线索的多线结构

以下是组织工作用的类别，不是既定势力清单，也不要求所有类别都在每个区域出现：

1. 个人利益与生存：交易、欺骗、欠债、临时合作、背叛、逃亡。
2. 信仰、誓约与朝圣：日常教义、守誓、教派习俗、信念冲突、失去信仰。
3. 王国与地方秩序：征召、税赋、道路、地方权力、军政命令落差。
4. 地区历史与普通人的旧事：迁徙、旧战场、工匠记录、家庭遗物、失踪者。
5. 制度与组织内部矛盾：资源争夺、职位冲突、命令隐瞒、理念分歧。
6. 人际关系与道德选择：互助、嫉妒、承诺、亏欠、怯懦、勇气、牺牲。
7. 古神遗骸与教会研究：隐藏深层线，早期只露出局部行政、研究或军备痕迹。
8. 外神影响与仪式：隐藏深层线，早期痕迹可有普通解释，必须通过多处独立证据逐渐显现。
9. 结局与玩家认知：不同探索深度、证据和行动导向不同结局。

各线可以互不相干、偶然交叉、共享历史背景或存在可验证的因果关系。必须说明是哪一种；相似符号或相近年代本身不足以证明关联。

## 7. 区域地图叙事方向记录

### 7.1 世界主轴：边远村庄、旧朝圣之路与战后废墟【用户明确确认的空间设想】

- **A1「边远村庄」**：位于王国边远地带的小村庄。
- **A2「雾林与钟墓」**：原先朝圣之路通往村庄一带的长途道路所经过的森林区域。战争结束、城区荒废之后，这一带逐渐出现森林；蜜忒的小村庄位于森林中，邪教活动区域则在更深处。A2 按既有地图设计是独立探索区域；旧朝圣道路在 A2 内已不可作为通往 A5 的连续主路使用，玩家必须先经 A3「废弃城区」才能继续抵达 A5「朝圣之路与战场」。
- **A3「废弃城区」**：因战火毁灭、战争结束后逐渐荒废的城区。
- **A5「朝圣之路与战场」**：继续深入的旧朝圣之路与原来的战场区域。
- 用户的整体空间设想是：从 A1「边远村庄」进入 A2「雾林与钟墓」，再通过 A3「废弃城区」才能继续抵达 A5「朝圣之路与战场」。A2 不是短小的过场森林，而是独立探索区域，承载旧道路、战后自然环境、蜜忒的小村庄与更深处邪教区域。
- **朝圣之路的原始用途【已确认】**：王国过去为连接各城镇、村落修建的公共主路，方便日常交通、贸易与宗教朝圣。它不仅是宗教路线，也是王国的交通与经济基础设施。
- **A2 内旧朝圣道路的现状【已确认】**：这条道路在 A2 内已经不可用，不能从 A2 直接沿旧路抵达 A5。当前可通行的主线必须先通过 A3「废弃城区」，再前往 A5「朝圣之路与战场」。旧路仍可作为历史景观与环境叙事素材，但不能被设计成绕过 A3 的可通行捷径。
- 这记录的是世界地理与历史景观的总体设想，不代表玩家必须以单一线性顺序完成所有区域，也不代表已确定具体战争名称、战争起因、城区名称、朝圣教义、朝圣者身份或森林形成的精确时间线。
- A2 内部的钟墓与各房间如何嵌入这条旧路线，仍需逐区讨论；不能仅凭“钟墓”名称推断墓主身份、年代或与战争的具体关系。
- 不得由“战争结束后城区荒废并出现森林”进一步擅自推断王国整体衰败的根本原因。
