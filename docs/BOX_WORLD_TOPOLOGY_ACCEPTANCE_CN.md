# 箱式世界地图拓扑验收与缺口清单

> 日期：2026-10-12  
> 状态：设计审计基线；未通过 Godot 实机验收  
> 分支：development

## 1. 不可妥协的地图原则

本项目的世界地图必须是**箱式互联地图**，不能退化成从 A0 一路走到 A12、只在主路旁挂几个支线的线性关卡串。

验收时必须同时满足：

1. **多路径**：主要枢纽在解锁后应有至少两个有效去向；关键区域之间应存在不同路线，而非只有一条正确道路。
2. **回环**：玩家应能绕回已探索区域、从另一侧接近地标，或通过解锁门/升降机/落差捷径缩短路程。
3. **捷径有意义**：捷径必须实际减少回访路程、连接不同高度/层级或打开枢纽的另一侧；仅把两个线性场景连接起来不算充分。
4. **回访有收益**：回到旧区域时，应因新能力、灵视阈值、开启的门、隐藏线索或新路线而产生新选择。
5. **隐藏区域不是死胡同**：H 区域必须可安全返回父区域；设计有次级出口时，必须明确其解锁条件、状态持久化与是否允许提前绕过主线。
6. **空间层级可读**：地面、屋顶、栈台、下水道、王室排水道等路线应在高度、入口位置与回程出生点上清楚区分。
7. **结构与实机分开验收**：拓扑图能证明的是设计连接；只有 Godot 中实际走通、碰撞正确、状态持久化后，才算可玩地图完成。

## 2. 当前拓扑数据快照

当前 `tools/world_map_topology.json` 包含：

- 主区域：A0–A13，共 14 个区域。A13 是终局异象层；A0–A12 是主要探索与终局前地图。
- 宏观连接：24 条，其中 10 条 main、9 条 shortcut、1 条 underground_route、2 条 secret、2 条 ending。
- 正式隐藏区域：H01–H08，共 8 个；H09 是临时候选区域，不应默认纳入正式地图或结局硬门槛。
- 显式登记的宏观环路：3 条（L01 边境环路、L02 中层环路、L03 王国深层环路）。

这些数字证明当前设计**不只是单一路径**，并且已经记录了一批捷径和回环；但它们不能证明所有连接都能在游戏里正常使用，也不能单凭连接数量证明地图已经达到《黑暗之魂1》式箱庭体验。

## 3. 当前结构判断

### 已有基础

- A1、A3、A4、A8、A9 等区域具备多条连接，承担枢纽作用。
- C04、C06、C07、C10、C12、C16、C18、C23、C24 被定义为捷径。
- L01、L02、L03 明确记录了边境、中层和王国深层的宏观回环。
- H01–H08 各自记录父区域、灵视阈值、返回父区域和可选次级出口。

### 尚不能判定完成的部分

- A2–A4 的实体门、平台、碰撞和回程出生点尚需在 Godot 中验证。
- A5–A8 需要确认战场高路、钟塔落差、监牢低路与王墓中层通道能形成玩家实际感知到的交叉连接，而非仅在数据表里相连。
- A9–A12 需要确认屋顶入口、圣堂、内城侧门与王室排水道形成有意义的回访路线。
- H01–H08 的灵视显现、入口交互、进入/返回、次级出口、奖励与状态持久化均未完成实机验收。
- 当前记录的三条宏观环路是最低限度的已登记环路，不代表地图只能有三条；如果实际探索仍然呈现“单向推进—原路折返”，就必须补强连接或调整空间布局。

## 4. 箱式地图的验收门槛

每个区域按以下维度逐项记录，不允许用“拓扑连通”替代实际通过：

| 维度 | 通过条件 |
|---|---|
| 多出口 | 除明确的序章/终局例外外，关键区域具有两个或更多有意义的出口或连接 |
| 环路 | 解锁后能构成实际可走通的闭环，且不依赖未实现的剧情假设 |
| 捷径 | 开启后显著减少旧路线距离，或连接此前分离的高度/区域层级 |
| 回访 | 至少存在一个合理的新路线、新奖励、新线索或新交互动机 |
| 隐藏区 | 灵视条件可达、入口可交互、可安全返回，状态不会因切图/死亡/读档丢失 |
| 出生点 | 进入与返回都落在可站立的平台上，不重叠门触发区，不把角色送到错误高度 |
| 状态持久化 | 开门、解锁、一次性奖励与区域进度在离开、返回和死亡恢复后保持一致 |
| 实机验证 | Godot 4.6.x 中逐条走通并记录结果；静态检查不能标记为实机通过 |

## 5. 执行顺序

1. 先完成 A2–A4 首个闭环切片的空间和交互验收。
2. 再审计 A5–A8，重点确认中层路线不是单线走廊。
3. 再审计 A9–A12，重点确认外环、圣堂、内城和王室排水道能形成有效回访。
4. 逐个验证 H01–H08，H09 继续保持候选状态。
5. 如果实机探索仍然线性，优先调整地图连接、捷径出口和层级布局；不要靠增加地图数量或添加无意义支线来掩盖问题。
6. 只有主路、回环、捷径、回访和隐藏区域全部通过后，才将地图标记为完成，并进入大规模区域剧情填充。

## 6. 当前结论

**当前结论：拓扑设计已有箱式结构基础，但世界地图尚不能判定为完整或验收通过。**

它已经有 24 条连接、9 条捷径定义、3 条显式环路和 8 个正式隐藏区域；下一步不是继续堆数字，而是验证这些连接在实际场景中是否构成可理解、可走通、可回访的多路径网络。若实机结果仍像线性关卡，必须继续改地图，不能以当前拓扑数据宣告完成。
