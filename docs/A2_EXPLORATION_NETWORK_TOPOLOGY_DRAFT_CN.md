# A2 探索网络拓扑草案（空间先于平台）

> **权威性说明（2026-10-24）：** 本文是历史方案/审计资料；若与当前 A2 房间架构或入口规则冲突，以 docs/maps/A2_DESIGN_BASELINE_CN.md 为准。本文中的旧实现描述不代表当前代码状态或实机验收通过。

状态：设计草案，尚未落实为可玩的最终地形。此文档是为避免再次把 A2 做成横向平台长图而建立的施工约束。

## 1. 设计原则

A2 的空间应该像一张由多个房间/场景构成的连续区域地图。图中的连线代表可探索通道，不是单纯的跳跃平台链。玩家应在多个节点间做方向选择，遇到死路、回头、通过不同高度重返旧空间，并逐渐发现 A3、A5、H02 的方向。

- 入口在西侧，A3 的 C03 主线出口在远端东侧树冠。
- A5 的 C04 是远端解锁的高路捷径，不得成为初次进入的直接出口。
- H02 位于下层，属于可选内容，不得成为 C03 的前置条件。
- 上层、地面层、下层必须在实际碰撞地形中连通。
- 死路是有意的探索结构，不是遗漏的出口；应有环境线索，但不应都奖励关键道具。
- 地图应允许玩家在同一个大区域中跨多个 Godot 场景；场景切换不能让空间方向感突然重置。

## 2. 节点网络（建议版）

                                             |
                                      [树冠西支路]
                                             |
A1 -> [雾林入口] <----回返----> [中央林地节点] ----> [钟墓外圈] ----> [钟墓外缘死路]
             |                       |                  |   \
             |                       |                  |    \ 下行
             |                       |                  |     v
             |                       |                  | [钟墓深层] ---> H02 可选
             |                       |                  |      |
             |                       |                  +<-----+ 回返竖井/坡道
             |                       |
             |                       +----> [树根裂隙] ---> [中层残廊]
             |                                     ^            |
             |                                     |            +--> 短死路
             |                                     |
             +----> [树冠爬升] ---> [树冠主廊] ----+----> [东侧高桥]
                                      |                       |
                                      |                       v
                                      +--> [朝圣高路]    [东部远端节点] ---> C03 -> A3
                                               |

上图是逻辑草案，不是最终地形坐标。它明确要求地面探索、树冠高路、钟墓深层和东侧沟壑互相有空间关系；每个节点后续需细化成可玩房间/通道并标注是否在同一场景内。

## 3. 必须实现的探索行为

1. **入口分叉**：玩家在入口附近可以选择地面绕行或寻找上层入口，不应一眼看到直达 C03 的平台链。
2. **可见但暂不可达**：从地面至少能观察到树冠/残桥的部分结构，但第一次无法从最短直线抵达出口。
3. **有意义的死路**：钟墓外圈、树冠支路或残廊至少有两处非主线死路；回头路线必须安全、清晰。
4. **下层回返**：进入钟墓深层后有可探索支路，并通过坡道、竖井台阶或另一个出口回到外圈；不得只靠自杀/重载脱困。
5. **高低两路并行**：东部沟壑有树冠路线和低位绕行，两条路线在远端重汇；低位路线不是一条孤立的平行直线。
6. **回到熟悉空间**：至少一条上层或下层通道重新接入之前走过的节点，使玩家能识别“我回到了刚才那个地方的另一侧/下面”。
7. **远端出口**：C03 位于探索网络的东侧远端；C04 保持远端解锁的高位捷径；H02 保持可选。
8. **场景切换连续性**：若钟墓深层、树冠延伸段或东沟低路拆成单独 `.tscn`，必须记录门/坠落/爬升的入口方向、返回出生点和承托平台。

## 4. 场景拆分候选

| 逻辑空间 | 初步建议 | 拆分依据 |
|---|---|---|
| 雾林入口 + 中央林地节点 | 可先在同一场景 | 建立初始方向感，避免过早频繁切场景 |
| 钟墓外圈 | 视实际宽度，可独立场景 | 多向分叉、坑口与上层视线关系 |
| 钟墓深层 | 独立场景候选 | 独立低位空间、回返竖井、H02 可选支路 |
| 树冠主廊 + 朝圣高路 | 可在同一大场景或两个连续场景 | 取决于视野、镜头和加载需求；C04 门是空间捷径而非任意传送 |
| 东部沟壑上缘/低路 | 同一场景优先；若拆分需保持坠落连续感 | 高低路线交错和低位回返 |
| 东侧远端节点 + C03 | 与树冠延伸段连续或通过有明确地标的场景转换 | 出口应是探索结果，不是长图尽头 |

场景拆分最终需要结合真实地形、镜头和 Godot 加载机制决定，不能仅凭表格预先锁死。

## 5. 与当前拓扑数据的差距

当前拓扑里 A2 的 SC 连接主要登记了入口—钟墓外圈、坑底下探、入口—树冠、树冠—朝圣高路、东沟下探与远端汇合。它还没有把上述全部探索行为细化成充分的分叉、死路、树根裂隙回接、钟墓深层回返通道等完整实现合同。

因此不能仅靠现有的 SC007–SC073 编号就宣布 A2 的探索网络完成。后续要先将本草案拆成可追踪的子区域连接合同，再修改灰盒地形，并逐条做静态与实机验收。

## 6. 完成标准

A2 通过灰盒验收的条件不是“平台很多”，而是玩家可以：
- 在多个方向间做选择；
- 走进死路并自然回头；
- 从不同高度重新进入熟悉空间；
- 通过下层探索找到回返路径；
- 发现上层与低位路线在远端重汇；
- 最终通过 C03 到达 A3；
- 在后续阶段从 A5 解锁并使用 C04；
- 可以忽略 H02 而不影响主线通行。
