## 三个 A2 回环的验收定义

### L-A：雾林入口—树冠—钟墓外圈—雾林入口
- 从地面入口能辨认树冠路线和钟墓轮廓。
- 普通路线与上层路线在至少一个可读的节点交汇；不是只能单向跳上去的孤立平台。
- 复用现有 A2_BELLGRAVE_CANOPY_CROSSING 前，必须在运行时核对桥体的实际端点与开启条件；不能仅凭局部路线名字认定回环成立。

### L-B：钟墓外圈—坑底—林下绕行—外露钟楼肋架—钟墓外圈
- 检查 x=860..1060 的钟墓断口：下落时确实进入 y=775 的坑底。
- 验证两侧 y=695/728 的错层台阶能让角色跳回地面；记录从坑底返回时的跳跃次数与失败点。
- 验证坑底的后续绕行路线能重新接入中层，而不是死路或必须自杀回程。
- H02 入口必须可选、可返回，不能成为 C03 的前置。

### L-C：东侧上层残桥—沟壑下层绕行—东端高路
- 从西侧能看见东侧残桥轮廓。
- 分别走上层路线与较低路线，确认两者在东端重新汇合。
- C03 出口只能从远端承托平台进入；不得从地面直线绕过高路设计。
- 从 A3 返回时应落在 A2 树冠层，不得落入地面或门触发范围。

## Godot 实机验收步骤

1. 在本地检出 feature/story-map-progression 最新提交，启动 Godot 4.6.1。
2. 先运行现有静态验证脚本：
   - python3 tools/validate_world_map_topology.py
   - python3 tools/validate_spatial_route_contracts.py
   - python3 tools/validate_graybox_scene_wiring.py
3. 启动项目并进入 A2，从 A1 地面入口开始，完整走一次“地面→树冠→钟墓→坑底→回到中层→东侧双路线→C03→A3→C03 返回 A2”。
4. 另测 C04：首次锁定不可通过；在 A5 开启后从两侧往返；重进 A2 后仍保持开放。
5. 另测 H02：未满足条件时入口不可用；满足条件后可进入并返回；未探索 H02 时仍能正常抵达 C03。
6. 观察角色是否穿地、卡墙、悬空出生、自动触发相邻门；记录失败坐标和录屏，再修复后重测。

## 通过条件

- 三个回环都能由玩家实际走通，而不是只存在于文档或拓扑 JSON。
- 所有入口、出口和回程出生点均有实体承托。
- 普通跳跃能稳定通过关键间距；失败跳跃不能依赖像素级精准操作。
- C03、C04、H02 的既有职责和解锁语义不变。
- 通过完整路线验收后，才开始添加东侧专属敌人、调查点与奖励，避免在错误地形上返工。
