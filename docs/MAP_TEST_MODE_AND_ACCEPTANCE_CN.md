# 地图测试模式与文字对齐清单

> 适用分支：development  
> 目的：在不清除、不覆盖现有正式存档的前提下，直接验收完整地图与剧情探索路径。  
> 当前状态：地图测试面板已接入代码；必须在本地 Godot 4.6.x 实机确认快捷键、传送和存档保护。

## 最新实测反馈与箱庭地图改进

2026-10-11 的一次最简流程测试中，玩家持续向右移动并抵达了「凡人之墓」结局。该结果证明主线具备可通关路径，但**不能证明所有区域都已访问，也不能证明箱庭结构已经成立**。当前 A11 是可选深层研究区，正常抵达王座区不要求先进入 A11；若未进入 A11，不应直接视为主线故障。

这次反馈也暴露出灰盒阶段的体验问题：多数主线出口位于场景右侧，玩家可以把不同区域理解为一串横向关卡。不能把这种体验问题归咎于测试方式。后续验收必须分别验证：

- 主线是否可通关；
- 回环与捷径是否真实可走、是否缩短回程；
- 玩家是否能理解区域之间的上下层、近路与远路关系；
- A11、隐藏区域与回访路线是否能被发现，但不会强制阻塞普通结局。

### 玩家可见的世界路线图

最新开发版新增正常游戏内的世界路线图：按 **M** 打开，按 **M** 或 **Esc** 关闭。它显示 A0–A12 的区域关系、主线与箱庭回环；已发现的隐藏区域会以紫色节点出现。虚线代表设计中的回环／捷径，部分需要先从另一侧开启，因此地图显示连接不代表该门当前已经打开。路线图不会传送主角、解锁门或修改剧情进度。

此路线图是帮助玩家理解空间关系的辅助工具，不代替实际地图设计。真正的箱庭验收仍需走通环路、观察地标、回访旧区，并验证捷径的实际落点与回程距离。

首个物理布局试点也已写入：A3 通往 A5 的主线出口移至东侧残墙高台（约 x=2240、y=410），不再贴着地面最右边界；H03 的入口移到第三街线索附近（约 x=1120），与高台出口分开。F10 导航坐标、入口名称与 A3 目标文字已同步调整。该改动尚未通过 Godot 实机跳跃与交互测试。

A2 从 A3 返回时的出生点也已对齐树冠高路：从原本的东侧地面改为 x=2120、地面以上约 140px，落在主线高台出口前一段平台。该落点与 A2→A3 出口约相隔 120px，不直接重叠；仍待 Godot 实机确认单向平台着陆和输入时序。

结构复核的第二批 A3 调整：C05 通往 A4 的旧水库入口移至抬高的管线栈道（x=1600，约高于地面 115px）；C16 通往 A9 的旧升降机移至东侧高台（x=1980，约高于地面 70px），从 A9 返回 A3 的落点同步到 x=1940。H05 在 A3 的回程门移至 x=1820，与 C10 钟塔落差和 C16 高位升降机分开。F10 出口指引已同步；这些坐标仍待 Godot 实机验证。

A4 交通枢纽也已做灰盒分层：C12 监牢补给隧道在 x=1050 的低位栈台（约高于地面 75px），C07 王墓水道在 x=1320 的中层平台（约高于地面 85px，回程落点 x=1260），C23 王城排水道在 x=1650 的高位管线（约高于地面 105px，回程落点 x=1620）；古老石层调查点移至 x=850，避开 C12 门的交互范围；C06 村庄水闸移至地面 x=2220，与最东侧 H01 井道入口分离。相应出生点与 F10 指引已同步，但跳跃、门焦点和回程手感尚未经过 Godot 实机验证。

## 一、开始测试前：不要清档

**你现在有本地存档，不需要按 F9，也不需要点“新游戏”。**

1. 从 Godot 正常运行项目主场景 res://scenes/boot.tscn。
2. 在标题菜单选择“继续游戏”，进入当前存档所在区域。
3. 按 **F10** 打开“地图测试模式”面板。
4. 先点击“开启地图测试模式（保护正式存档）”。
5. 再选择区域，点击“进入所选区域”。

地图测试模式会在当前运行会话中暂停 WorldState.save_game() 的磁盘写入。测试时对鸣响、接触值、隐藏门和路线标记所做的调试改动只存在内存中。退出时点击“退出测试并恢复磁盘存档”，程序会重新读取本地存档并回到标题菜单。

- 不要在测试模式中点击“新游戏”。
- 不要按 F9 做清理或重置；本轮地图测试不需要重置进度。
- 如果你只是关闭游戏，也不会把地图测试模式中的临时进度写进正式存档。
- 地图测试模式不是存档备份工具；如果要进行正式剧情回归，仍建议提前复制 user://nereis_hero_save.json。

## 自然探索验收：从真正起点开始（优先使用）

新增了“自然探索验收：从 A0 开始（无传送／无作弊解锁）”按钮。它会清空**当前运行内存**中的角色与世界进度，然后从教会手术所 A0 开始；会话内继续保持磁盘存档保护。它不会删除或覆盖 `user://nereis_hero_save.json`。

1. 在任意可操作地图按 F10，先确认正式存档仍可恢复。
2. 点击“自然探索验收：从 A0 开始（无传送／无作弊解锁）”。
3. 从 A0 正常战斗与调查，沿真实出口进入 A1；不要使用“进入所选区域”、灵视条件预设或“全地图连通测试”。
4. 全程只使用正常移动、战斗、NPC／线索交互、灵视能力、机关与场景入口。若某地图无法抵达，记录上一个地图、所走出口、当前鸣响／接触状态和 Output 中的 `[NEREIS][MAP]` 日志，不要通过传送绕过。
5. 可以按 F10 查看面板，但不要点击状态预设或传送按钮。测试结束时点击“退出测试并恢复磁盘存档”，回到标题菜单后用“继续游戏”确认正式存档恢复到测试前的位置。

该模式的目的不是证明地图可传送，而是验证**从 A0 出发的真实探索链**。面板会显示“自然探索实走地图：n/21”，只在目标场景实际加载后才计数；Output 也会打印 `[NEREIS][MAP][NATURAL_TEST] Visited ...`。地图测试面板本身仍存在，因此必须遵守上述操作约束。调试会话期间所有 `save_game()` 磁盘写入都会被拦截。计数是场景到达记录，不等于该地图的所有捷径、隐藏线索或回程已验收。


### 新增：Debug 全图逐步指引（30 步）

F10 面板现在包含 30 步“自然探索路线指引”，覆盖从 A0 逃脱、主线 A0–A12、正式隐藏区 H01–H08、两条 A11 深层入口、三条箱庭回环与存档恢复。H09 是临时候选，不计入正式验收。

1. 点击“自然探索验收：从 A0 开始（无传送／无作弊解锁）”。
2. 游戏开始后按 F10 打开面板，滚动到“自然探索路线指引”。
3. 每张主地图的 HUD 现在会显示 `A1｜边境村庄` 这样的区域编号；A1 村庄 HUD 也已标注 A1。F10 指引会实时读取主角的地图内 X 坐标，并显示“向左走（A）／向右走（D）”、目标出口或线索名称、目标坐标与大致距离。
4. 使用“上一步指引／下一步指引”切换任务文字。指引只告诉你方向，不会自动判定成功；请在真实进入区域、调查线索、打开捷径并实际走通回程后再前进。
5. 指引不会传送、加鸣响、补进度或开门。遇到门尚未显现时，先继续主线、提升正常获得的条件，再回访该地点；不要用预设绕过它。
6. 最后确认自然探索实走地图为 21/21，再使用“退出测试并恢复磁盘存档”。

面板使用滚动区域，较小窗口下请在面板内部滚动。方向坐标是当前灰盒地图的场景内 X 坐标，距离会随主角移动更新；当目标入口有前置条件时，指引会同时显示条件。实走计数只代表场景被实际加载过，不代表每条路线已经通过；请同时按步骤检查门、线索、回程与出生点。

### 自然探索必须覆盖的目标

- 主线：A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12。
- 边境箱庭回环：先抵达 A4，再按实际开启的闸门／回程连接走通 A3 → A4 → A1。
- 中层箱庭回环：从 A6 开启钟塔下落捷径，实际走通 A6 ↔ A3。
- 王国深层回环：从 A8/A9 的合法侧开启对应通路后，走通 A4 ↔ A8 ↔ A9 ↔ A4。
- 正式隐藏区域：H01 井底回声层、H02 倒响钟室、H03 被删去的第三街、H04 水面背后的楼梯、H05 无声钟室、H06 王名抹除廊、H07 镜街、H08 胎宫／原初空腔。H09 崖下实验窟是开发分支中的临时候选，不计入正式地图验收。
- 深层研究区 A11：通过 C15（王墓侧）或 C19（静默侧堂）真实开门进入；两条入口都应符合各自的异常来源、鸣响／接触门槛与剧情事实。
- A13 是世界拓扑中的终局抽象节点，目前没有独立地图场景；通过真实结局路线验收结局场景，不把 A13 当作独立可探索地图。

### 每个新地图都要验收

1. 出口与进入侧正确；进入后不出生在门、敌人或平台碰撞体内。
2. 能在地图内找到主路线和可选高低路线；平台间距能用当前跳跃能力实际通过。
3. 首次进入隐藏区域后存在合理回程；从远端捷径回到旧区时出生点不与门／交互对象重叠。
4. 交互提示只出现在真正可用的对象上；相邻门、NPC、异常入口不会争抢 E 键。
5. 死亡回到本区入口检查点或已激活休息点；已开启的捷径和隐藏门在重生后仍保留。
6. 正式退出测试后，测试中的临时进度不能污染原存档。

## 三、完整地图测试用例

地图测试不是基础移动测试。只要角色能正常移动，就从地图空间、剧情线索和灵视回访开始。

### MAP-01：初始世界空间关系

- 进入 A1，记录能看见或找到的所有出口、封闭门、井口和高层路径。
- 分别前往 A2、A3；确认玩家可以识别不同探索方向，而不是只能沿一条走廊推进。
- 检查可见但暂时不可达的地标是否能被记住，并且后续确实能从另一条路线抵达。
- 通过标准：空间结构能自然引导探索，不需要依赖调试传送或任务箭头。

### MAP-02：主线连续路线

按以下路线逐段实走，不使用传送：

A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12

- 每次进入新区域，检查出生侧是否与入口对应。
- 每段至少原路返回一次；如果设计为单向入口，应能从空间布局看出其意图。
- 通过标准：主线可连续抵达 A12，途中没有需要隐藏区或未解锁捷径才能继续的意外断路。

### MAP-03：三条箱庭回环

**边境环路：** A1 → A2 → A3 → A4 → A1  
**中层环路：** A3 → A5 → A6 → A3  
**王国深层环路：** A4／A7 → A8 → A9 → A4

- 先按正常进度寻找并开启对应的反向门、闸门或升降设施。
- 从环路的两个方向各走一次。
- 观察捷径开启后是否明显减少回程距离，并让玩家重新认识旧区域。
- 通过标准：环路不仅存在于文档中，而且在游戏空间里真实可走、方向正确、落点合理。

### MAP-04：隐藏区域与灵视

**正式验收优先使用“自然探索验收：从 A0 开始”**。不要选择“灵视条件测试”或“全地图连通测试”，否则会改变鸣响值、接触值或门状态，不能证明正常流程成立。

- 按正常路线调查 A2 的“从未移动的钟”，解锁灵视；按 V 激活灵视后再按 E 调查异常。
- H01：A1 村庄井口，鸣响至少 12。
- H02：A2 旧朝圣路，鸣响至少 18。
- H03：A3 城区，鸣响至少 28。
- H04：A4 旧水库，鸣响至少 36、古神接触至少 1。
- H05：A6 修道院，鸣响至少 42、古神接触至少 1。
- H06：A8 旧王墓，鸣响至少 55、古神接触至少 2；还必须调查 A2 的钟与 A8 的王室石碑。
- H07：A9 王城外环，鸣响至少 68、外神接触至少 12、外神共鸣成立，并调查镜街异常。
- H08：A11 深层研究区，鸣响至少 78、古神接触至少 2、外神接触至少 18、外神共鸣成立，并调查 A2 的钟、A3 的第三街与 A4 的古老石层。
- C15：从 A8 进入 A11 的王室竖井；要求鸣响至少 55、古神接触至少 2，并调查 A2 的钟与 A8 的王室石碑。
- C19：从 A10 进入 A11 的静默侧堂；要求鸣响至少 68、外神接触至少 12、外神共鸣成立，并调查 A9 的镜街异常。
- 通过标准：显现、发现、开门、进入是可区分的步骤；所有隐藏地图都有合理的返回路线。数值达到门槛不等于已经验证，仍需实际按 V、E 操作并走回出口。

“灵视条件测试”只用于单独定位入口问题；“全地图连通测试”只用于空间巡检。两者都不能作为自然探索通过的证据。

### MAP-05：全地图空间巡检

选择“全地图连通测试”，然后依次传送到各区域。此预设仅用于检查路线空间和落点，不可作为解锁条件正确性的证明。

每个区域都检查：

1. 出生点是否在安全地面，是否被平台、门或敌人卡住。
2. 区域左右两端、上下层和可见高台是否存在实际路线。
3. 每扇门是否连接到预期区域，入口和出口方向是否一致。
4. 捷径从另一侧开启后，回程是否缩短。
5. 隐藏区是否有合理返回路径，不会把玩家锁在里面。
6. 相邻交互点是否挤在一起，导致提示重叠或抢占 E 输入。
7. 地标、环境线索和区域主题是否服务于教会实验、王国历史、古神遗迹等剧情信息。

### MAP-06：剧情空间关系

- A0：手术设施与逃脱通道是否传达主角是被当作实验对象，而非普通囚犯。
- A1：村庄是否让玩家理解这里是临时庇护地，并能找到后续多方向入口。
- A2–A4：雾林、钟墓、城区、排水系统是否形成可回访的旧世界交通网。
- A5–A8：战场、修道院、监牢、王墓是否逐渐提供相互印证或彼此矛盾的历史证据。
- A9–A12：王城、圣堂、内城是否让玩家逐渐察觉教会与王权的真实关系。
- A11／H01–H08：检查隐藏内容是否改变玩家对既有场景的理解，而不只是提供没有叙事意义的奖励房。H09 临时候选不计入正式地图验收。
