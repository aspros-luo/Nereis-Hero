## 1. 核心结论

A2 不是单纯“地图太短”，而是现有空间骨架尚未转化为足够多的玩家决策。代码已经有五个子区域、两处常规敌人遭遇配置、两处环境线索、一个拾取型路线物品、一个休整点、坑底与回跳台阶、H02 隐藏入口、SC011 条件式共鸣桥，以及 C03/C04 两种不同用途的高位连接。

但目前的内容大多集中在“走到位置—交互/战斗—继续前进”。现有脚本未能证明每个子区域都形成独立的探索过程、不同的战斗节奏或有意义的路线取舍。**不应把平台数量、拓扑连接数量或隐藏门数量直接计为可玩内容。**

## 4. 内容密度缺口分级

### P0：运行可靠性（先于加内容）
1. 复现并修复钟墓坑底落下后的控制/移动异常；当前只能确认代码中有坑底和回跳台阶，不能宣称运行已稳定。
2. 验证 H02 的共鸣 18 + 灵视条件、首次发现入口与稍后返回开启的流程。
3. 验证树冠平台跳跃、SC011 在条件变化时的实体状态、C03 双向高位转场。
4. 验证 C04 锁定/远端开启/回程出生点。
5. 对每项分别记录“静态代码检查”和“实机结果”，不能用前者替代后者。

### P1：路线可玩性
1. 地面主路与树冠路线应构成玩家能理解的选择，而不是地面直行与一串跳台的简单并列。
2. 钟墓外圈、坑底与树冠之间要形成可读的空间关系；不要求强制探索。
3. 树冠层至少应有值得比较的路线选择或有意义的探索支路，但先基于现有平台做可达性审计，再决定是否加平台。
4. C04 的价值是后续捷径与空间记忆，不应额外复制一条与 H02 功能重叠的隐藏出口。

### P2：战斗节奏
1. 先核查猎犬与信徒的接敌距离、地形、视线、战斗空间和战后奖励。
2. 再判断是否需要改变遭遇编排；不要把“增加怪物数量”当作唯一解决方案。
3. 任何新敌人或战斗事件都等空间合同验收后再提出具体实现。

### P3：惊喜、物品与叙事反馈
1. 优先利用已有空间形成发现过程，而非在每个空地上放物品。
2. 环境叙事只通过可交互线索、物品描述和世界内容呈现；不新增旁白解释。
3. 隐藏区域可以影响终局选择，但主线完成不得依赖全收集。
4. 低价值趣味诱饵可以作为可选内容，前提是不会误导主线或破坏现有空间关系。

## 8. 补充发现：目标指引与内容密度的关系

A2 的 HUD 目标文本当前为：

> 聆听两道回声；主路沿右侧树冠高台前往城区，地面的钟墓入口可稍后探索。

这条指引本身符合“隐藏内容不强制”的原则，但会把首次玩家的注意力集中到树冠高路与 C03。若沿途空间缺少主动发现、路线判断或有区别的遭遇，玩家就容易体验成“直奔出口”。**这不是应当通过强制封路解决的问题，而应通过提升主路沿途的可玩性解决。**

### 8.1 不应改变的设计原则
- A2→A3 的主线不依赖 H02。
- 玩家可以暂时错过钟墓坑底，之后再回访。
- 隐藏探索可以影响终局判断，但不能变成所有玩家的通关清单。
- “钟声”与“旧朝圣路”的真相仍保持未定，不以新文案替用户做剧情决定。

### 8.2 应验证的体验问题
- 玩家从 A1 进入后，能否在不看 debug 标记的情况下发现地面线索、坑口和树冠路径？
- HUD 指向树冠后，主路沿途是否仍存在可辨识的可选探索，而非只剩跳台与出口？
- 玩家第一次看见 H02 时若条件不足，是否会理解为“之后可以回来”，而不是“我走错了”？
- 两道回声的共鸣累计与灵视解锁是否能在自然探索顺序下满足 H02 条件？需测试“先看到门、后记录线索”与“先记录线索、后看到门”两种顺序。
- SC011 的共鸣 20 条件是否有足够自然的后续触发机会；不要让它在玩家离开 A2 后才首次变得可用，却没有合理回访动机。

  └─ 主路：攀上树冠 → 路线物品 / SC011（满足条件后）→ C03 进入 A3
