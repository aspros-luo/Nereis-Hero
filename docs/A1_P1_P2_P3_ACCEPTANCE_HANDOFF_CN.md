# A1 P1/P2 实现交付与 P3 验收单

分支：`feature/story-map-progression`  
用途：把 A1 村庄交付到可由作者完整验收的状态。静态合同通过不等于 Godot 实机通过。

## P1 — 村庄空间闭环

- 屋顶高路使用真实单向碰撞平台，不只依赖背景线条。
- 屋顶增加一次性奖励：现有物品目录中的「旧朝圣路程单」，通过现有背包与收集 ID 保存；重复交互只留下空纸夹，不重复发放。
- 防卫前北门 / 排水道保持封闭表现；防卫后北门出现加固门钉与通行缺口，排水道进入独立探索场景。
- H01 交互拆成三步：灵视显现入口 → 首次 E 记录发现 → 第二次 E 永久开启 → 第三次 E 实际进入。发现、开启、进入各自写入已有持久化数据。
- 保留 A2/A3、井口、崖洞与旧排水道返回落点约定；水井/下水道/崖壁的整体新布局仍不擅自重做，等待作者提供设计。

## P2 — 剧情与 NPC 反馈

- 北门防卫反馈同时反映在门体视觉和铁匠状态对白中。
- 酒馆声音调查保持一次性事件；状态和事件触发标记保存。
- 常驻 NPC 在村庄内刷新时按最新事实重算对白；商人只回应实际进入过的 A2/A3，不以解锁路线冒充探索。
- 朝圣骑士、复国军营地与教堂占用仍必须等待正式剧情状态；没有新增猜测性的状态写入点。
- 屋顶路程单是普通探索奖励，不改变秘密、人物命运或结局条件。

### 3. 实机路线回归

- [ ] 新游戏第一次进入 A1：没有复国军营地；教堂室内为空；朝圣骑士未到场。
- [ ] 从西入口沿地面走到北门，再返回；沿途 NPC / POI 提示不会互相抢焦点。
- [ ] 从地面跳上屋顶高路，沿平台走过至少一段，拿到「旧朝圣路程单」，再跳回地面。
- [ ] 退出 A1 / 死亡 / Continue 后，路程单仍在背包，屋顶不重复发奖。
- [ ] 防卫前检查北门与旧排水道：门体不可通行，排水道实体封闭。
- [ ] 完成村庄防卫并回 A1：北门视觉已加固并可通行；铁匠对白变化；旧排水道入口开放。
- [ ] 分别经北门进入 A2、经旧排水道进入 A3；回村后出生点安全，不落在门触发器或无承托位置。
- [ ] H01：激活灵视显现 → E 一次只记录发现 → E 第二次开启 → E 第三次进入；退出/死亡/Continue 后发现与开启状态保留，进入记录只在真正切入后产生。
- [ ] 酒馆声音：首次交互记录一次；离开、回村、再次进入酒馆时值夜人对白变化；重复交互不重复奖励或演出。
- [ ] 疯狂神职人员战败后先离开战斗区域，再实际回 A1：崖洞入口此时出现；未实际回村前不出现。
- [ ] 在 A1 使用休整、死亡恢复、Continue、重复进出 A2/A3；常驻 NPC 不重复生成，状态对白不倒退。
- [ ] 教堂占用、复国军营地、朝圣骑士到场均不因防卫胜利或普通对话自动触发。
