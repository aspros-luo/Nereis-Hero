# 箱庭式互联世界地图设计原则（中文）

> 状态：全局地图设计约束，优先级高于单区布局提案。适用于 `development` 分支后续所有地图施工、隐藏区域与结局地图审查。
> 核心目标：采用《黑暗之魂1》式箱庭互联空间，并结合《黑暗之魂2》从中心据点向多个方向探索的选择结构；不是线性章节地图。

## 1. 不可违背的总原则

**地图必须先成为一个可自由探索、彼此嵌套的世界，再由剧情解释玩家在其中发现的东西。** 开发时可以按区域分批施工，但玩家体验不能被制作顺序绑成单线任务流程。

- **多方向出发：** A1 边境村庄是早期中心据点。玩家在抵达后，应逐渐发现通往森林、废弃城区、地下井道、旧朝圣路等不同方向的入口或线索，而不是只存在唯一正确出口。
- **空间互联：** 区域通过城墙上层、屋顶、井道、排水渠、墓穴、升降梯、维护层、断桥和反向开门互相连接。区域边界是地图实现边界，不应总是世界中的硬边界。
- **有条件的自由：** 玩家可以自行决定先探索哪个可达方向；部分路线由能力、道具、机关状态、鸣响 / 灵视、世界事件或另一侧开启状态限制。限制要可观察、可回忆，不可用无提示的任意锁门制造任务感。
- **捷径是核心奖励：** 打开一扇从另一侧开启的门、启动升降梯、放下吊桥或打开回水闸，应显著缩短回程并重新连接已知空间。
- **垂直与回环优先：** 每个大型区域应有高低层、分岔、环路、视线联系或可见但暂不可达的地标；不能把多张水平走廊用门串起来就算箱庭。
- **同一世界可复用：** 灵视 / 鸣响不是只通向 H01–H08 的钥匙。它可以揭示既有区域的隐藏门、楼梯、平行空间、额外出口或新地标，使回访改变玩家对旧地图的理解。
- **剧情后置：** 先确定空间、连接、探索顺序的可选性、捷径和门槛；再把人物事件、物品描述、敌人布置和碎片叙事放进空间。不要为了塞剧情把地图改造成接任务—跑图—交任务的线性流程。

## 2. 参考结构的正确理解

- 《黑暗之魂1》：借鉴区域互相穿插、垂直层叠、从远端开门、升降梯回到熟悉地点、地标帮助玩家建立心理地图，以及发现近路时产生的空间顿悟。
- 《黑暗之魂2》：借鉴中心据点向多个方向分流。玩家可以先尝试不同道路、挑战不同区域或暂时退回；不同方向有不同风险与门槛。
- 不复制上述游戏的具体地图、地点或剧情。我们要实现自己的王国地理、古老地下交通与鸣响导致的空间错位。

## 3. A1 中心据点与多方向探索

A1 边境村庄必须是一个紧凑但有后续变化的中心据点。它不是一次性新手村，也不应该把所有区域入口一开始全部无条件开放。

| 方向 / 入口 | 初次可见性 | 可能的限制 | 后续空间回报 |
|---|---|---|---|
| A2 雾林与钟墓 | 正常可见、可进入 | 地形与早期敌人压力 | 旧朝圣路、A3 外街与可选墓区 |
| A3 废弃城区方向 | 可从 A2 的山体裂隙 / 旧路逐步抵达 | 需要探索找到真正通路，不用任务标记硬指引 | 连接旧市场、屋顶环路、A4 排水系统与 A5 方向 |
| H01 村庄老井 | 初期可注意到异常痕迹 | 鸣响、灵视与主动调查 | 进入井底回声层，后期连接 A4 并形成捷径 |
| 旧朝圣高路 | 可见或从远处听见线索 | 机关、另一侧开门或后期状态 | 连接 A2 与 A5，减少重复回程 |
| 其他地下入口 | 先显示封闭井口、排水口或年代不符的门 | 道具、机关、鸣响或从另一侧开启 | 在中后期增加回访路线，不应无条件跳过关键空间门槛 |

这张表定义设计意图，不代表当前每条连接都已经实现。施工时必须把“看得见”“能到达”“能打开”“已永久解锁”“已进入”作为不同状态记录。

## 4. 世界地图采用多种门槛，不采用单一钥匙门

每条暂时不可通行的路径，必须属于一种清晰门槛，并给玩家留下能理解的线索：

1. **能力门槛：** 需要已获得的移动或交互能力。现有能力优先复用，不为每个门临时发明新能力。
2. **道具门槛：** 钥匙、徽记、工具或特定物品。道具应在世界中有可信用途，不要让所有门都变成同色钥匙锁。
3. **机关门槛：** 水位、吊桥、升降梯、供电 / 供水、重力结构或从另一侧开启的门。
4. **空间门槛：** 当前可见但无法抵达的高层、深坑、断桥、封闭管道；后续可从另一条路进入。
5. **鸣响 / 灵视门槛：** 先显现异常，再允许玩家调查和永久开启。短暂显现时间不应要求完成长距离平台挑战。
6. **世界状态门槛：** 主线事件、人物状态或某区域的变化可以开启 / 改变连接，但不能让普通探索完全依赖隐藏的剧情标志。
7. **反向解锁门槛：** 入口初次从一侧不可开启，绕行抵达另一侧后开门；这是优先设计的箱庭捷径形式。

不要让所有门槛同时要求鸣响、古神接触、外神接触、道具和剧情旗标。每条路径只使用与其空间 / 叙事主题相关的最少条件，并确保可选路线不会意外绕过主线关键冲突或结局条件。

## 5. 三张互相交织的交通网络

### 地表与高地

A1 → A2 → A3 是早期主要可探索骨架，但不是唯一通道。A3、A5、A6、A9 应通过屋顶、城墙、旧朝圣高路、钟塔维护层形成多高度交通。远景地标应在多个区域反复出现，帮助玩家建立方位。

### 地下旧路

A1 老井、A3 排水口、A4 下水道 / 旧水库、A7 维护层、A8 王室地下道和 A11 深层研究区必须逐步构成网络。地下不是独立关卡集合，而是连接地表与权力建筑的旧交通系统。

### 权力建筑内部

A5 战场、A6 修道院、A7 监牢、A8 王墓、A9 王城外环、A10 大圣堂与 A12 王室内城通过公开路线、服务通道、维护竖井和封锁门相互影响。不同入口应带来不同风险、视角和回程成本，而不是仅仅提供重复门。

## 6. 三条已确定的大型回环（保留并完善）

1. **村庄—森林—城区—下水道—村庄：** A1 → A2 → A3 → A4 → A1。回水闸与检修门分阶段开启，构成早期最重要的空间顿悟。
2. **城区—旧战场—修道院—钟塔—城区：** A3 → A5 → A6，后期开启钟塔回落口回到 A3 上层。它必须缩短回程并改变玩家进入城区的高度。
3. **下水道—王墓—王城—研究区—王墓：** A4 / A7 → A8 → A9 / A10 → A11 → A8。早期入口可以封闭，但空间联系应有可见线索；A11 必须有安全返回路线。

此外保留 A2–A5 旧朝圣高路、A3–A9 旧升降井、A9–A4 王城排水门、A8–A9 王室运送门、A9–A12 内城侧门等连接。所有连接都必须标注首次可见阶段、实际开启条件、是否双向、是否绕过主线，以及解锁后缩短的回程。

## 7. 鸣响 / 灵视：同一地图的第二层，而不是额外关卡菜单

- 普通状态下就要存在异常的物理 / 环境伏笔；高鸣响不能凭空生成毫无前兆的新空间。
- 灵视短暂揭示异常，调查才永久打开通路；显现、开启、进入分别记录并持久化。
- 灵视可以改变旧地图的可读性：显现墙后的楼梯、旧街区的平行层、原本不存在的维护门、被抹去的桥、与其他区域相连的第二出口。
- 已开启路径不能因灵视结束、死亡、切图或读档而重新锁定。
- H01–H08 仍然是八个重要隐藏区域，但不应成为灵视功能的全部用途。
- 不允许隐藏连接意外让玩家跳过 A5 / A6 / A10 等关键冲突；如隐藏区接近主线后段，远端门必须使用正式进程门槛。

## 8. 区域施工与玩家自由度是两回事

开发可以按 M1–M5 分阶段施工，以便控制风险；但施工顺序不是玩家的强制游玩顺序。地图设计验收必须检查玩家是否能在多个合理方向之间选择、回退、记住暂时封闭的路线并在获得新能力 / 道具 / 世界状态后返回探索。

每个大型区域至少回答：

- 玩家从哪些方向进入？哪些入口是早期入口，哪些是后期开启的捷径？
- 从入口能看见哪些暂时不可达的地标、门、平台或深坑？
- 区域内部是否有至少一条环路、上下层关系或路线选择？
- 哪条路更危险但更快，哪条路更安全但更长？
- 从另一侧开启什么之后，回程发生了什么变化？
- 鸣响 / 灵视是否让已知空间出现新路线，而不是只开一个奖励房？
- 玩家能否在没有任务日志指引的情况下，凭地标和环境线索记住方向？
- 新捷径是否意外跳过关键首领、故事事件或结局条件？

小型区域可以只负责一个明确的连接或秘密；大型枢纽 A3、A4、A8、A9 必须具备更高的连接度与多层探索。不是每张地图都必须复杂，但整个世界网络必须复杂且可理解。

## 9. 当前主线与地图拓扑的解释方式

现有 `A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12` 是一条**可靠的首次主线通路 / 制作验收路径**，不是强制玩家逐区按序通关的章节队列。A4 是早期可探索的地下支路；A2–A5、A3–A4、A4–A1、A8–A11、A9–A4 等连接会随着探索和门槛逐步形成。

玩家可先探索多个方向、撞见高风险区域、记住封闭门，再回到中心据点。普通结局无需发现全部隐藏区；真结局证据由可选探索、物品、人物经历和鸣响发现共同组成，不以任务列表逐项派发。

## 10. 实施优先级与验收

1. **先审查现有连接图与场景代码：** 区分“概念连接”“静态接线”“实际可走通”，禁止把它们混为一谈。
2. **从 A1 / A2 / A3 / A4 先做可玩箱庭切片：** 至少验证两个方向可探索、一条回环、一处反向开门捷径，以及一个鸣响复用旧地图的入口。
3. **按同样的标准扩展 A5–A8，再扩展 A9–A12：** 不要求玩家依照制作顺序探索，但区域连接必须随世界逐步开放。
4. **把 H01–H08 作为网络中的隐藏层接入：** 入口、内部路线、返回出口、远端门槛都要分别验收。
5. **最后进行全图与结局路线审计：** 清理临时测试地图、重复场景、死路、错误直达和失效出口；保留有明确结局职责的专用地图。
6. **阻断性问题随时修复：** 启动失败、主角无法移动、关键场景无法进入 / 离开、存档丢失进度不能等到地图完工后再处理。

验收时必须分别记录静态拓扑、代码接线、Godot 实机运行。没有 Godot 实测的路线，不得标记为可玩通过。

## 11. 与其他地图文档的优先级关系

- 本文定义不可违背的箱庭世界设计原则。
- `COMPLETE_WORLD_MAP_ATLAS_CN.md` 定义 14 个主要区域和约 90 个子区划的空间职责。
- `WORLD_NETWORK_TOPOLOGY_CN.md`、`MAP_TOPOLOGY_VALIDATION_AND_HIDDEN_AREAS_CN.md` 记录区域连接与隐藏通路。
- `MAP_CONTENT_COMPLETION_ROADMAP_CN.md` 定义开发阶段和验收门槛；阶段顺序不等于玩家的线性通关顺序。
- `MAP_DESIGN_A3_FORGOTTEN_CITY_CN.md` 等单区设计必须遵循本文，不得把箱庭枢纽简化成一条走廊。

若旧文档将主线顺序描述得像唯一通路，以本文的箱庭原则重新解释；除非发现连接会破坏既定世界观或结局门槛，否则优先补充互联关系，不轻易推翻已定区域身份。

## English summary

The world must be an interconnected, semi-open box-style world inspired by Dark Souls 1, combined with Dark Souls 2's hub-and-branches structure. A1 is an early hub, not a quest lobby. Players choose among multiple explorable directions; abilities, items, mechanisms, Resonance, world states and reverse-side shortcuts gradually open paths. Resonance must reveal new routes within familiar maps, not merely unlock separate secret stages. Build the map network first, then populate it with fragmented narrative. Development milestones are not a mandatory linear player route.
