# Nereis Hero — Game Design

## Core fantasy

A mortal hero enters a familiar village and slowly discovers that the horror is not an external monster but the way people justify what they do to survive.

## Pillars

1. Weighty 2D Soulslike combat.
2. Cosmic horror revealed through human choices.
3. Exploration that rewards observation rather than checklist completion.
4. Narrative consequences that alter the world instead of only changing dialogue.
5. A restrained scope suitable for a focused solo-developed game.

## Hero perspective

The player controls the Hero. Mite/Nereis is not the player avatar. Her presence is discovered through memories, rumors, symbols, dreams, and eventually direct encounters.

## First vertical slice

Village outskirts -> combat tutorial -> first NPC -> hidden event -> mini-boss -> first meaningful choice.
