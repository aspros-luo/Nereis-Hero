# Nereis Hero：以 Hallownest 为参照的全地图重构

> 目标：先把完整世界的空间骨架做出来，再填充敌人、剧情和奖励。
> 参照：Hollow Knight 的宏观区域相对位置、枢纽、多入口、垂直层和能力回访节奏。
> 边界：不导入原作地图像素、房间几何、美术、名称或关卡内容；本项目继续使用自己的世界观与 A0-A13/H01-H08 标识。

## 工作原则

1. 不是把 14 张长条地图接起来，而是先搭建一张连续的空间网络。
2. 每个 A 区域先按“入口、主路、上层、下层、支路、回环、出口”确定空间结构，再布置敌人。
3. 关键枢纽至少有三种高度层和两条跨层路线；部分连接从远端开启后形成回环。
4. 先让玩家看见暂时到不了的路、门、建筑或深坑；稍后从别的高度/能力/捷径到达。
5. 隐藏区域只丰富剧情、道具和终局条件，不作为通关主线的硬门槛。
6. 不用大量敌人或纯粹加长跑图时间制造探索感。空场景也必须有路线发现和地形反馈。
7. 每次地图改动都必须检查平台碰撞、跳跃可达性、门交互范围、两端出生点、死亡恢复和镜头边界；静态拓扑通过不等于实机验收。

| Forgotten Crossroads：中央多向枢纽 | A3 废弃城区 + A9 王城外环 | 至少三向连接、上下层出口、回访交汇点 |
| Greenpath：弯曲、分层的自然区域 | A2 雾林/钟墓/朝圣路 | 地面、树冠、坑底、沟壑下层、远景承诺 |
| Fungal Wastes：分支和垂直落差 | A5 旧战场 + A7 监牢井道 | 可选危险分支、下落路线、跨区回环 |
| Fog Canyon：危险的连接区 | A11 古神遗迹的外围连接 | 有条件的横向通道，不让每条路线都能直接通过 |

| White Palace / Godhome：独立的高难可选空间 | A13 与隐藏终局支路 | 不打断主线空间；可选挑战/真相分支 |

## 第一阶段施工顺序

### 1. 全局地图骨架
- 保留 A0-A13、H01-H08、C01-C24 作为稳定 ID。
- 以 tools/hallownest_reference_layout.json 为宏观空间参照，将本项目区域布置为有上下关系的网络。
- 明确中央枢纽、左右外围、地下层、最深层和可选终局空间。
- 输出一张本项目自己的全局地图布局，不复制原作图像。

### 2. 每区灰盒结构
- 先关闭敌人，按空间职责搭建可走地形和真实碰撞。
- 每个区域至少一条主路、两条用途不同的支路、一个暂时不可达的可见目标、一个回环/捷径。
- 用真实跳跃和坠落路线代替只靠门连接的伪探索。
- 不允许只靠背景线条暗示一条实际不存在的道路。

### 3. 可玩性验收
- 使用主角从入口开始完整走图，记录每个可达/不可达平台。
- 对每个能力门验证“首次看见—获得能力—回访—通过—获得反馈”闭环。
- 对每个捷径验证开启前后的路径长度和回环是否真实成立。
- 主线可通关；隐藏区可错过；所有关键出生点都落在有碰撞支撑的安全位置。
