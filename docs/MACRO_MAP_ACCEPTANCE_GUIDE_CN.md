# 宏观地图验收指南

> 目标：下一轮直接在 Godot 中检查 A0–A13 与 H01–H08 的场景落点、跨区连接、隐藏路线回程和实际移动，不必先完成复杂剧情。

## 如何进入

1. 从 `development` 拉取最新代码。
2. 用 Godot 4.6.1 或兼容的 Godot 4.x 打开项目，等待导入完成。
3. 运行项目，进入标题菜单。
4. 选择 **“宏观地图验收 / World Map Test”**。
5. 点击任意区域按钮直接进入。测试页包括 14 个主区域 A0–A13 和 8 个隐藏区域 H01–H08。

## 测试操作

- 移动：方向键或 A/D。
- 跳跃：Space（以项目当前 Input Map 为准）。
- 交互：靠近门、检查点或交互物后按 E。
- 返回地图选择页：**F6**。
- 返回标题菜单：在地图选择页点击“返回标题菜单”。

测试模式会临时预置跨区与隐藏路线所需的部分进程标记，目的是快速检查门、出生点与回程；它**不代表**正常剧情条件已经通过验证。场景切换时会在 Output 中输出 `[NEREIS][MAP][NATURAL_TEST]` 访问记录。

## 存档安全

验收模式会启用 `WorldState.debug_map_test_mode`，`save_game()` 在该模式下不写入正式存档。退出验收页返回标题时会重新读取现有存档；若原本没有存档，则恢复为新游戏默认状态。不要把测试模式中预置的状态当成正式剧情进度。

## 建议验收顺序

1. **先测主路线：** A0 → A1 → A2 → A3 → A5 → A6 → A7 → A8 → A9 → A10 → A12 → A13。
2. **再测旁路：** A3 ↔ A4、A9 的升降机/排水连接、A11 的两侧入口。
3. **逐个测隐藏区域：** 从选择页进入 H01–H08，确认至少一个出口能回到预期主区域；观察入口是否重叠、落点是否悬空、门是否在角色无法到达的位置。
4. **记录阻断：** 区域 ID、入口来自哪里、按键后发生什么、角色出生坐标附近截图/视频，以及 Output 中的 `[NEREIS][MAP][SPAWN]` 日志。
5. **不要在本轮验收小地图剧情、美术或战斗平衡。** 这次只裁定宏观地图能否走通。
