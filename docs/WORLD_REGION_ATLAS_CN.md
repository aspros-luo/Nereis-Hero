# Nereis-Hero 世界地图总归纳：大区域与剧情地点图谱

> **本文件是当前阶段的地图总纲与剧情填充底图。** 它先按地理和势力归纳大区域，再列出区域中的地点与地点关系。它不是玩家地图，也不要求每个候选地点都成为独立关卡。A0–A13 是现有灰盒宏观区域 ID；下列地点是更贴近剧情策划的地理命名。

## 宏观地图脑图

开始细化任何小地图前，先查看[《世界地图总脑图与空间关系（宏观版）》](WORLD_MAP_BRAINMAP_CN.md)，用于评审六个大区域的相对位置、枢纽职责与主要连接。宏观关系尚未最终锁定时，不应把示例性能力或支线视为强制内容。

## 一、整个世界划分为六个大区域

| 大区域 | 对应现有区域 | 核心作用 |
|---|---|---|
| 1. 边境村庄与荒野 | A1、A2、A5 | 主角的情感起点、村庄袭击、森林/峡谷/墓地探索、边境战争痕迹 |
| 2. 废弃城区与地下水系 | A3、A4 | 第一大型箱式枢纽；屋顶、街巷、下水道、水库和高位排水互通 |
| 3. 教会边陲与圣堂领地 | A0、A6、A7、A10 | 从边陲手术所、修道院、拘押营到大圣堂和教会高层，呈现教会的不同面貌 |
| 4. 王城与王室墓地 | A8、A9、A12 | 王城外围、王城中心、王宫、地下墓室与王室维护路线 |
| 5. 教会秘密研究区与古神遗迹 | A11 | 区分人类实验设施与古神遗留空间，承接核心真相 |
| 6. 深层梦境与终局异象 | A13 | 由角色状态和结局决定形态的终局空间，不是普通行政区域 |

这些大区域并不是六张线性关卡。它们彼此穿插：下水道能绕回村庄或进入王墓；废弃城区连接边境、教会与王城；教会的公开区域与秘密研究区之间存在被隐藏的联系。

## 二、每个大区域里的地点

### 1. 边境村庄与荒野

- **边境村庄**：主街与广场、民居后巷、村口防线、屋顶木栈道、老井。
- **雾林与山间峡谷**：雾林地面、树冠、断桥、峡谷底部、山壁洞穴、旧朝圣高路。
- **钟墓与荒野墓地**：墓地外圈、钟墓坑底、封闭墓室、倒响钟室。
- **边境战场与峡谷堡垒**：战壕、尸骸坡、坍塌城墙、堡垒城墙、瞭望箭楼。

剧情职责：先建立村庄生活与人物关系，再通过森林、墓地和战场逐渐发现教会活动的痕迹。不要在序章一次解释全部真相。

### 2. 废弃城区与地下水系

- **废弃城区**：西侧入口、旧市场街、居民废墟、屋顶连廊、抬高管线、旧礼拜堂、被删去的第三街。
- **下水道与旧水库**：排污入口、沉积大厅、旧下水道、中层水道、旧水库、低位淹水沟、水闸机房。

剧情职责：作为第一座真正的箱式枢纽，允许玩家从屋顶、地面和地下抵达同一片区域。灵视隐藏地点应改变玩家对城区历史的理解，而不只是发放额外奖励。

### 3. 教会边陲与圣堂领地

- **教会边陲手术所**：拘束手术室、观察廊、废弃病房、排污逃脱通道。
- **边陲修道院与钟塔**：下层回廊、修道院庭院、上层廊桥、钟塔中层、钟塔顶、无声窗口。
- **拘押营与忏悔监牢**：押送院、监牢走廊、下层囚室、忏悔井、维护竖井、供给隧道。
- **大圣堂与教会中枢**：朝圣阶梯、大圣堂主堂、侧廊、唱诗席高廊、静默侧礼拜堂、教会内廷/教皇区域。

剧情职责：让玩家看到教会的四张面孔——研究、日常信仰、拘押与惩戒、公开权力。实验室、集中营/拘押营、教会上层等地点不必全部做成独立大地图，可以作为既有区域中的子空间或隐藏分支。

### 4. 王城与王室墓地

- **王城外围与废弃街区**：外环下层街巷、外环广场、废弃住宅区、屋顶步道、王室高位排水道、内城侧门、镜街。
- **王室地下墓室与旧王墓**：王墓入口、王族墓室、中层墓道水渠、深层铭文廊、王室维护井、王名抹除廊。
- **王城中心与王宫**：内城服务街、王室庭院、城墙步道、王座厅上层、王室货运升降井。

剧情职责：王城不仅是最终战场，还应让玩家逐步理解王权、教会和普通人的关系。王室地下墓室同时承担历史揭示与地下交通功能，不应是与王城脱节的独立迷宫。

### 5. 教会秘密研究区与古神遗迹

- 王室维护井出口
- 教会实验层
- 古神遗留层
- 胎宫外缘
- 原初空腔

剧情职责：前段仍能看出人类实验设施的秩序；越深入，空间、声音和物理规律越不再服从人类设计。教会研究区与古神遗迹要有明确的视觉和叙事分界，即使两者在同一宏观地图中。

### 6. 深层梦境与终局异象

- 梦境边界
- 记忆回廊
- 结局专属场域

剧情职责：依“凡人之墓”“永恒乐园”“烈火天罚”等结局改变空间与遭遇。它是状态驱动的终局区域，不应该提前以普通地图形式完整展示。

## 三、连接原则：地图要像一张网，而不是关卡列表

1. **每个大区域至少有两种地理联系**：主路之外，尽可能有地下、上层、隐藏入口或后期开启的回程路线。
2. **小区域之间的连接必须有空间理由**：井连水道、排水道连地下、城墙连屋顶、钟塔落差连旧街、维护井连实验设施。
3. **捷径是玩家对空间的重新理解**：开门、放下梯子、恢复升降机、打通水闸，或发现灵视入口；不是单纯传送。
4. **升降机服务于垂直回环**：上下站要落在真实的小区域中，开启后能减少重复穿越危险区域；升降机损坏不能导致主线软锁。
5. **隐藏地点应与区域主题相关**：墓地隐藏被删去的王名，城区隐藏被抹除的街道，钟塔隐藏倒响，古神深层揭露实验的真正对象。
6. **剧情信息按探索顺序分层**：先给现象，再给互相矛盾的证据，最后让玩家自己拼出真相。

## 四、现在只填“轻量剧情骨架”，不急着写完整对白

为每个地点先回答五件事即可：

- 玩家为什么会来到这里？
- 这里发生过什么，或现在正在发生什么？
- 玩家能看到哪一个关键环境线索？
- 这里与哪个区域存在捷径、升降机或隐藏连接？
- 离开时，玩家对村庄、教会、王权或古神的认知发生了什么变化？

敌人波次、奖励数值、完整支线对白和每个房间的战斗节奏，等这层骨架稳定后再补。
