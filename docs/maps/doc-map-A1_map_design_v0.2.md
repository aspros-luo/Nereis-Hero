## 1. 先澄清：俯瞰草图不是游戏里的摄像机视角

这张图是**关卡设计平面图**，用来表达路线、相对位置、垂直层级和空间关系；它不代表游戏采用 2.5D 俯视玩法。游戏仍是 2D 横向动作玩法。落地时应将图拆成横向剖面/地形层：

- 玩家实际移动空间由地面、平台、墙体、梯子/跳跃连接和落差构成。
- 建筑在场景里作为背景层、可进入建筑内部场景，或前景遮挡层；建筑外观可以从侧面呈现，不要求俯视绘制。
- 草图上的“上方/下方”表示高度层或垂直路线；实际地形图需要明确每条平台的高度、跨度、碰撞和上下通路。
- 俯瞰图中的相邻块不自动等于门或传送点。只有跨区边界或明确的建筑内部切换才需要场景切换；区域内部默认是连续可行走空间。

## 2. A1 的空间布局目标

### 主地面路线
`C01 / A0 西侧入口 → 村庄主街 → C02 / A2 北门`

主街是玩家的导航主轴。拉长村庄的可探索距离，避免入口到北门只需短跑几秒。主街沿线分散布置建筑，建筑之间保留可走地形与可供后续细化的空间，不做连续贴墙的“商店街”。

### 分散的建筑与支路
- 民居分散在主街两侧，错开位置，不集中堆叠。
- 商铺/工作间独立布置在另一段主街或支路末端，形成探索目的地。
- 民居后巷作为可回返支路，可从不同位置接回主街。
- 不在本版本擅自新增 NPC 身份、支线任务或未确认的建筑功能。

### 上层路线
屋顶木栈道是**可选路线**，由分段屋顶、窄平台、跳跃间隙与少量上下连接组成，而不是一整条悬空走廊。它应能提供观察点和探索回报，但不能成为主线必经路线。具体平台高度和跳跃距离待网格地形阶段确认。

### 老井、隐藏层与回村点
- 老井平台是地面上的独立地标。
- `H01` 从老井附近的隐藏入口进入井底回声层；设计门槛沿用既有合同（神识共鸣阈值 12）。
- `C06` 是后期从 A4 方向回到 A1 的连接，落点为老井平台；它与 H01 入口必须分开，不可让回村出生点直接落进隐藏入口或触发区。
- H01 应有清晰的返回路径，除非后续设计明确将某一段设为单向落差。

### 旧排水路线 C24
- C24 在早期只开放为 A1 内的一段低位探索支路/短段，不应一开始就形成到 A3 的完整通路。
- 当 A4 侧的对应连接被打开后，再形成持久的跨区连接。
- C24 不与屋顶木栈道合并成同一条路线。

## 3. 2D 横向游戏的地形实现规则

| 草图符号/概念 | 2D 地形实现 |
|---|---|
| 主街 | 连续地面碰撞 + 分散建筑背景/入口 |
| 建筑之间的间隔 | 可走的地面、坡地、围栏、树木或小型平台；不要用不可见空白代替地形设计 |
| 屋顶路线 | 分段可站立平台；通过跳跃、梯子或明确的上下落差连接 |
| 老井 | 地面井口、井壁/落差、底部承托平台；必要时使用独立纵向延伸空间 |
| H01 隐藏入口 | 可发现的入口/隐藏墙体或环境触发，不用普通传送门图标替代空间关系 |
| C02/C24 等跨区边界 | 只在真实区域边界切换场景；入口出口出生点需与碰撞和相邻地形对齐 |
| 后期回连 | 以可见但初期阻断的门、梯子、升降机构或可开启障碍表现；开启后改变实际行进路线 |

## 4. 建议的空间节奏

主街长段探索 → 分散建筑/后巷支路 → 屋顶可选路线 → 回到主街导航轴 → 老井地标 → H01 低位隐藏探索 → 主街北门离开。

以上是节奏建议，不是强制线性顺序。玩家可以跳过屋顶路线和 H01，且不应因为没探索隐藏区域而被阻止通关。

## 5. 网格细化前必须确认的内容

1. 以项目当前视口与角色碰撞尺寸确定网格单位，草图本身不规定像素尺寸。
2. 每一段地面/平台标出起止 X、高度 Y、碰撞厚度和承托区域。
3. 每个跳跃连接按主角当前实测速度、跳跃力度与重力验证，不使用俯瞰图距离推断可达性。
4. 标出不可通行墙体、单向落差、可开门、隐藏入口与可见不可达目标。
5. 逐一核查 C01、C02、C06、C24、H01 的入口位置、触发范围和出生点。
6. A1 地形通过用户审阅后再修改 Godot 场景；本文与 Canva 图均不表示运行时已经实现。

## 6. 范围与非目标

- 保留既有世界级区域/连接合同，不擅自改变 A0–A13、C01–C24、H01–H08 拓扑。
- 本阶段不安排敌人数量、Boss 战或新剧情内容。
- 本阶段不以新增大量房间为目标，而是先确定一块区域内部的连续地形和路线。
- A5 的旧 22 房间方案不再是后续地形设计的权威模板；旧场景和代码在依赖审计完成前不直接删除。
