# A2 当前设计基线：雾林与钟墓

> 状态：当前实施基线（2026-10-24）
> 分支：feature/story-map-progression
> 本文件优先于 A2 早期灰盒、连续大地图和旧验收方案。历史文件仅提供背景，不得覆盖本基线。

## 1. 设计目标（修订：整体区域图与独立房间图分层）

A2 的区域内部地形图是**空间关系总图**，不是把一张连续地形按轮廓切成六片的裁切模板。红圈标出的 R01–R06 是六段不同主题、可独立游玩的横向关卡。每个房间进入后都应有正常、可读的地面与前进方向；房间主题改变的是地板材质、环境结构、背景与局部机制，不是把整个区域图中的奇形怪状轮廓原样塞进房间。

- **总图负责**：区域相对位置、层级主题、回环、捷径、隐藏通道、跨区出口和六房间之间的连接关系。
- **独立房间蓝图负责**：横向可玩空间、入口/出口高度、连续主地面、局部高低差、跳跃段、支路、可返回路线、碰撞与安全落点。
- **Godot 场景负责**：按房间蓝图实现可在编辑器中直接查看的地形、碰撞、Marker2D、出口触发器与相机边界；主要地形不得依赖运行时脚本临时生成。
- 不要求每个房间复制总图中的所有高度层。房间只实现自己负责的一段空间，但必须通过明确的入口/出口与整体总图保持一致。
- 地形阶段不放敌人或 NPC；先完成可读地形、真实碰撞和回程路线。

### 房间地形统一规则

1. 每个房间默认采用横向探索布局：连续主地面或连续可辨认的主路径占据关卡主体，玩家进入后能判断左右方向与下一目标。
2. 局部高台、断桥、下坠坑、竖井只作为关卡中的局部结构，不得让整个房间变成无支撑的漂浮平台拼图。
3. 不同主题通过地表材质与环境形态区分：R01 土地/树根；R02 粗树枝/树冠/天空背景；R03 石质墓穴/拱门/钟室；R04 地下墓道/坑底石沿；R05 朝圣石路/观察台；R06 裂谷地面/石阶/峡谷背景。
4. 每条下坠路线都必须有安全落点与清楚的继续路线；若设计为暂时单向，必须有可见的回程路径或明确可开启的捷径，不能软锁。
5. 房间蓝图必须标出：入口与出生点、出口与目标方向、主路线、支路、回环/捷径、不可逆落差（若有）、安全落点和相机建议范围。
6. 先审阅六张房间蓝图与整体总图的对应关系，再改 Godot 地形；不得仅凭平台节点数量、简化弹道图或静态拓扑宣称关卡完成。

## 3. 六个房间职责（以横向独立关卡为准）

| ID | 主题与地表 | 关卡职责 | 不允许出现的问题 |
|---|---|---|---|
| R01 | 森林地面、泥土、树根 | A1 入场枢纽；沿地面主路探索，在自然岔路选择树冠或钟墓方向 | 不能只是通往其他房间的狭窄走廊；岔路必须有真实空间 |
| R02 | 粗树枝、树冠、天空/云层背景 | 一段完整横向树冠关卡；连续树枝主路，局部断桥、树干高台和回接路线 | 不得把总图上整片树冠的上下轮廓直接裁成房间；不得用无支撑悬浮平台代替树冠地形 |
| R03 | 石地面、墓室拱门、钟室 | 一段可正常行走的钟墓上环；通过门洞、局部落差和墓室支路连接深层 | 不得因为总图中钟墓是垂直结构，就把整个房间做成无法回返的竖井 |
| R04 | 地下墓道、坑底、石沿 | 承接深层路线；提供安全着陆、可探索的地下横向路径及回到上层的路线 | 不得把下坠终点做成死坑；回程必须由真实可走地形构成 |
| R05 | 朝圣石路、遗迹、观察台 | 一段完整横向高路；主路、观察台、局部断裂和下层绕行构成探索回环 | 不得把整张地图缩小塞入视口；不能只有稀疏悬浮平台或不可返回的落差 |
| R06 | 裂谷地面、石阶、峡谷背景 | 一段完整横向裂谷关卡；局部上中下路线相连，东端 C03 通往 A3 | 不得将整张区域图的竖向裂谷轮廓直接当作整个房间；沟底必须有合理回程 |

**空间关系合同（保持不变）：** A1 北门 → R01；R01 ↔ R02；R01 ↔ R03；R01/R03 可进入 R04 深层；R02/R03 可通过不同高度路线进入 R05；R04 ↔ R06 低位连接；R05 ↔ R06 高位连接；R05 的 C04 → A5；R06 的 C03 → A3；H02 为可选隐藏路线。具体入口/出口高度必须由各房间蓝图和 Marker2D 对齐后确认。

## 5. 正反方裁定

**正方：** 独立房间让地形可以逐图精细设计、局部验收与迭代；入口/出口和落点能对应具体空间，不再让六个设计职责被一张父场景的连续坐标掩盖。

**反方：** 房间切换会增加边界处的镜头重置、出生点、持久状态、跨区出口、死亡恢复和存档恢复风险。单纯切换场景而不做连接合同会制造软锁、重复触发或状态丢失。

**裁定：** 采用独立房间与真实转场；先建立连接合同和共享转场适配，不把每个房间复制成独立的完整游戏根场景，也不通过降低断言来使检查通过。任何关键连接没有可核实落点时先暂停该连接实现，不猜坐标。
