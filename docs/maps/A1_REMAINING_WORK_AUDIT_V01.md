## 必须在 Godot 4.6.1 完成的最终验收

以下内容不能仅靠 GitHub 源码审查判为通过：

1. 在编辑器加载 `scenes/village_hub.tscn`、`scenes/village_backhill.tscn` 及新建的可复用场景，确认资源解析、节点路径、骨骼属性与场景序列化无错误。
2. 实际运行 A1.0 铁匠周边连续地面，确认不会意外跌落；再从 A1.1 进入独立悬崖探索场景，沿连续地面检查探索 POI、左侧返回入口及右侧实体封锁。该路线不应依赖跳台通行。
3. 逐一测试 Hero 的 `west`、`backhill_return`、`well_exit`、`cliff_cave_return`、`city_cut_return`、`north_gate`、`mite_house_return`、`backhill`、`cliff_return` 等出生方向，并确认不会出生在门内、悬空或立刻触发不相关交互。
4. 验证两场景往返、教堂/酒馆室内转场、存档继续、H01 的显现/发现/开启、H09 的锁定/解锁、北门防卫前后、排水支路防卫前后、营地建立前后。
5. 在四种组合下检查村庄状态：未防卫/已防卫 × 营地未建立/已建立；确认外观、交互与对话各自读取正确旗标。
6. 在本地运行三个 Python 合同脚本，并运行 `godot --headless --path . res://tools/a1_scene_smoke_test.tscn`。烟测脚本已改为覆盖新悬崖场景、左右路线合同、未来道路封锁及 H01/H09 状态；必须在当前提交上重新运行确认通过。随后在 Godot 4.6.1 编辑器中检查碰撞、交互焦点、镜头与实际转场。
