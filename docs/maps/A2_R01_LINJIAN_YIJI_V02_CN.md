# A2-R01 林间遗迹 · 地形实现说明 v0.2

> 分支：`feature/story-map-progression`  
> 场景：`scenes/rooms/a2_fog_forest/a2_r01_forest_crossroads.tscn`

## 设计对照

依据「R01·林间遗迹」方案图，将立体探索落实为可玩碰撞，不依赖二段跳。

| 设计点 | 实现 | 坐标摘要 |
|---|---|---|
| ① 树根平台 | `Platform_001` + 攀爬台阶 `Platform_002/003` | 高台顶 y=512，x=120–320 |
| ② 林间支路 | `Platform_004/005/006/016` 下支路闭环 | 下路 y=736–800，可回接主路 |
| ③ 断桥高地 | `Platform_010` + `Platform_012`（中间视觉断口） | 高台 y=512，远景废墟仅装饰 |
| ④ 遗迹回廊 | `Platform_008` 水潭台 + `Platform_009` 中层 | 下层 y=800，中层 y=640 |
| ⑤ 破碎神殿 | `Platform_014` 主甲板 | 顶面 y=480，x=1360–1792；出口 `ExitCanopy` → R02 |

## 分层

- **高层（可远观）**：y ≈ 480–544（树根台、断桥、神殿）
- **中层（主路线）**：y ≈ 640–704（入口地面 → 钟墓拱门 → 东侧主路）
- **下层（支路/坠落）**：y ≈ 736–832（树根支路、水潭回廊、`DropToR04`）

主路落差单级 ≤ 64px，符合当前主角能力。

## 出入口合同（未改语义）

| Marker | 用途 |
|---|---|
| `EntryWest` / `ExitVillage` | A1 村庄往返 |
| `ExitCanopy` / `EntryCanopyReturn` | → R02 树冠 / 返回 |
| `ExitBellTomb` / `EntryTombReturn` | → R03 钟墓上环 / 返回 |
| `DropToR04` | 单向落入 R04 坑底 |

## 验收清单（需实机）

- [ ] 从西侧入口可走到中层主路，不掉出房间
- [ ] 可攀上①树根平台并回落到主路
- [ ] 可进入②下支路并回到主路（闭环）
- [ ] 可经台阶到达③断桥高地两侧
- [ ] 可到达⑤神殿并触发 `ExitCanopy` → R02
- [ ] 可进入钟墓拱门区域触发 `ExitBellTomb` → R03
- [ ] 从④下层水潭附近触发 `DropToR04` 落入 R04
- [ ] 碰撞顶面与 `SurfaceEdge` 可见线一致，无隐形墙卡死
