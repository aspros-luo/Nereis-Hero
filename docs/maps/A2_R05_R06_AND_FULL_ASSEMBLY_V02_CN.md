## 2. R05 旧朝圣高路

### 空间职责
- 由 R02 树冠高路 / R03 钟墓上环进入的高位分支，保留通往 A5 的 C04 高位连接。
- 高位主路分成窄石沿、宽观察台、短落差三个节奏，不重复 R02 的树枝语言。
- 下层绕行线可在落差后继续前进，并回接出口前区域；不能用不可逆落差把玩家困在下层。
- 东端 C04 必须有足够宽的安全站立区；R06 上层连接应与 C04 分开，避免把两个方向压在同一个触发区。
- R03→R05 的高位捷径是回环，不应绕过主线剧情门槛。

### 阻碍与探索
- 窄路是观察和跳跃判断，不做像素级跳跃。
- 宽观察台让玩家能回望钟墓上环，并看见 R06 的裂谷方向。
- 可见但暂不可达的远端石台先作为视觉目标；暂不定义能力门。
- 落下后仍可通过下层平台返回主线附近。

## 3. R06 东侧裂谷

### 空间职责
- 上层快速线连接 R05；中层是主要探索线；沟底提供更深的可选路线。
- R04 从低位接入沟底，R06 中的回程台阶允许玩家回到中层，再决定走上层还是继续东行。
- C03 位于东端，门内要有安全站立区和清楚的行进方向。
- 不把沟底设计成强制单向死路；除非全局合同明确，保留可读的回程路径。
- 上层和中层都能看见沟底，沟底也能通过错层石沿辨认上方出口。

### 阻碍与探索
- 三个高度层各有不同职责，不用密集小平台制造假难度。
- 至少一处宽落脚区作为观察点，沟底回程阶梯必须连续。
- 远端 C03 出口与 R05 的 C04 不合并；它们分别服务不同区域连接。
- 不增加能力门、敌人或 NPC。

## 4. 六房间拼装关系

| 房间 | 职责 | 关键连接 |
|---|---|---|
| R01 林间岔路 | 入口枢纽、地面主路、树冠上行 | A1入口、R02、R03、R04下坠、H02隐藏 |
| R02 树冠与断桥 | 上层探索、断桥、回返 | R01、R05高路 |
| R03 钟墓上环 | 钟墓上层、垂直地标 | R01、R04下坠/回程、R05高位捷径 |
| R04 钟墓坑底 | 安全落点、深层探索、回程石沿 | R03、R06低位路线 |
| R05 旧朝圣高路 | 高位主路、下层绕行、远眺 | R02、R03、R06、C04→A5 |
| R06 东侧裂谷 | 上中下三层、沟底回返 | R04、R05、C03→A3 |

## 5. 拼装验收重点

1. A1 北门必须把玩家送入 R01，而不是 A2 地图中段。
2. R01→R04 与 R03→R04 是落差连接；落点都必须在安全区域，不能只靠图上箭头。
3. R02→R05 与 R03→R05 是两条不同高度的连接，不能共用一个未经核对的落点。
4. R04↔R06 低位连接与 R05↔R06 上层连接要在 R06 中保持高度区分。
5. C04 在 R05，C03 在 R06；保留 H02 为可选隐藏路线，不因拼装图而解锁。
6. 拼装总览是空间关系示意，不代表各房间按同一比例；最终需要以真实场景边界、碰撞和出生点重新校准。
