## 2. 空间结构

### A. R03 下坠入口

- 入口必须落在安全落地区域或可控的缓冲石沿，不得把玩家直接送入致死区域。
- 落下后玩家应能立即辨认主落地区域、上方回程方向和深层探索方向。
- 入口与平台高度、相机边界、出生点仍待与 R03 连接合同核对。

### B. 坑底安全区

- 保留宽阔主落地面，作为玩家停下观察、选择方向和恢复移动节奏的区域。
- 不把出口、狭窄跳跃或隐形门放在落点正下方。
- 主落地面是空间锚点，不等于检查点；除非另有明确决定，不新增存档或检查点语义。

### C. 分层探索与回程

- 利用东西两侧错层石沿形成上、中、下三个高度层。
- 回程路线应当是连续的阶梯式路径；不依赖墙跳、像素级跳跃或尚未定义的能力。
- 当前平台存在需要审查的高度差与水平间距，尤其是上层石沿与中层/下层石沿之间。应先用主角当前跳跃参数计算可达性，再决定保留、移动或新增平台。
- 本轮将 P1 的职责落地为 CryptReturnStep_Mid（270,145，70×12 碰撞）。其他尚未实现的规划节点仍不得写成已实现；整条回程路径仍需实机验证。

### D. 可选探索与阻碍

- 增加一个从主行进路径可以看见的侧向探索目标；第一阶段用软门/地形落差阻挡，不能封死主路线。
- 侧向探索应当有明确收益空间（环境线索或未来道具点位），但本阶段不放置物品、敌人或 NPC。
- 可选路线最终应回接坑底主路，避免变成没有返回意义的死胡同。
- 不引入能力门条件，直到全局能力合同明确。

### E. 通往 R06 的深层出口

- R06 出口应与回程路线分离，让玩家能选择继续深入或回头。
- 入口必须有足够宽的安全落脚面，出口方向和门槛位置应能映射到独立房间连接合同。
- 当前场景尚无已核实的 R04→R06 转场节点；蓝图上的箭头只代表设计意图。

## 3. 现存风险

1. 当前 10 个平台根节点（含新增回程阶梯）的存在不能证明路径连通；部分平台水平距离/高差仍需按实际主角运动包络检查。
2. R04 当前作为连续大地图的装配件，父场景位置为 (850,655)。独立房间化时必须重新确定本地边界、地板、相机边界和入口出生点。
3. Canva 原始 R01–R03 蓝图的尺度与当前场景存在差异；R04 不应继续使用与 Godot 局部坐标脱节的示意坐标。
4. 任何路线箭头都不是实际 Area2D 转场或碰撞的证据。

## 4. 设计验收条件（尚未通过）

- [ ] 从 R03 入口落下后必定落在安全区。
- [ ] 落点附近无软锁、无致死落差。
- [ ] 主落地区域可到达深层出口的安全入口。
- [ ] 坑底至少有一条连续、无需特殊能力的回程路线回到 R03 侧高层。
- [ ] 所有平台间距/高度符合当前主角跳跃包络；无法到达的平台需调整，不以降低验证标准解决。
- [ ] 可选侧室可见但不阻断主路线，且存在可理解的返回路线。
- [ ] 图纸上的平台、门和落点逐项映射到 Godot 编辑器可见节点。
- [ ] Godot 4.6.1 编辑器和实机验收完成后，才可将状态改为通过。
