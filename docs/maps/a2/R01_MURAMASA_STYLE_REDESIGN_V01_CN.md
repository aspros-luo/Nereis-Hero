# A2-R01《林间遗迹》：横向探索式地图重构 v1

> 分支：`feature/story-map-progression`  
> 状态：第一版设计合同 + 主角下穿平台操作已提交；场景地形尚未按本规格重建，必须在 Godot 中完成节点级改造并实机验收后才能标记完成。  
> 设计参照：借鉴《胧村正：妖刀传》的横向推进节奏、手绘层次与少量明确岔路；不复刻其素材或具体关卡。

## 1. 这次重构要解决什么

旧 R01 叠加了太多不同高度的平台、重复树干跳台、下层支路和隐藏触发器，路线意图不够清晰，维护成本不断上升。v1 不再用更多平台修补旧路线，而是把可玩空间收敛成“连续主路 + 一个上层可选支路 + 一个下穿平台进入的下层秘密路线”。

## 2. R01 v1 的空间合同

```text
左侧 A1 入口 ─────── 林间主路 / 遗迹前庭 ───────── 右侧钟墓出口（R03）
                         │
                         └─【下+跳跃】穿过薄平台
                                  ↓
                           瀑布背后的低路 ──→ R04

主路中后段：一处可读的树根斜坡 / 高枝入口 ──→ R02 树冠
```

- **主路**：从左至右可连续步行/少量普通跳跃通行。主路不依赖二段跳，不允许玩家走到中层后无故坠落死亡。
- **树冠支路 R02**：仅保留一段清晰的树根坡和少量平台，远处先看见树冠/断桥目标；不做连续楼梯式跳台。此路线是可选探索，不阻断主路。
- **钟墓出口 R03**：放在主路自然延伸处，门与可站立地面有充分重叠，不放在平台尽头。
- **秘密下层 R04**：主路旁有一处视觉上可辨识但不强制发现的薄平台/枯枝盖板。站在其上按“下 + 跳跃”穿过，落入瀑布背后的安全低路；普通向前走不会触发转场。
- **死亡边界**：只处理真正的房间外坠落；R04 的入口由明确的可下穿平台与落点构成，不再把普通地形缺口伪装成隐藏路线。

## 3. 视觉原则

1. 玩法碰撞只服务于行走、跳跃、下穿和路线选择；树木、遗迹、雾、瀑布和前景根系优先用非碰撞视觉节点表现。
2. 使用编辑器可见的 `Polygon2D`、`Line2D`、`Parallax2D`（若项目当前层级支持）与背景装饰节点形成手绘层次；不得在脚本初始化时生成地形。
3. 地面轮廓清楚、主路对比度高；前景可遮挡环境，但不能长期遮住角色、落脚点或出口。
4. 不以增加平台数量制造内容。探索深度来自可选路线、隐藏道具、环境叙事和之后加入的敌人与事件。

## 4. 下穿平台输入规则

已在 `scripts/player/hero.gd` 加入第一版操作：

- `↓ + Space` 或 `S + Space`：从当前承托角色的物理地形节点下穿。
- 单独 `Space` / `↑`：维持原有跳跃行为。
- 下穿只对当前承托角色的 `PhysicsBody2D` 临时添加碰撞例外，短暂后恢复碰撞；不全局关闭地形碰撞。
- 角色未站在地面、处于攻击/闪避等动作时，不执行下穿。

**重要限制：**当前逻辑适用于“每个可下穿地形由独立物理节点承载”的场景结构。如果多个平台共用同一个 `StaticBody2D`，碰撞例外会暂时穿过该节点的全部碰撞形状。因此，R01 的薄平台应使用独立的 `StaticBody2D`，并且只包含自身的碰撞形状。

## 5. Godot 实施顺序

1. 先清理 R01 的可玩碰撞：一条主路、一个通往 R02 的上行支路、一处独立下穿平台、一个安全低路落点。
2. 保留现有房间合同要求的 `Terrain/RoomMarkers`、入口/出口门、`Drop_R01_to_R04`（如重构后不再需要独立 Area2D 转场，则必须同步调整 runtime 与校验合同，不能留下双重触发）。
3. 删除重复台阶和无意义碰撞体；装饰节点不承担角色碰撞。
4. 本地运行验收：主路左右通行、普通跳跃、下+跳跃下穿、低路安全落地、R04 转场、R02/R03 往返出生点。
5. 通过前不得声称 R01 已完成；下穿平台在所有其他房间默认不自动启用，避免意外改变现有路线。
