## 0. 本地启动前检查

- [ ] 切到 `feature/story-map-progression`，确认工作区没有未保存的个人改动。
- [ ] 用 Godot 4.6.1 打开项目根目录，等待文件扫描与 SVG 导入结束。
- [ ] 在文件系统面板直接打开 `scenes/rooms/a2_fog_forest/a2_r01_forest_crossroads.tscn`。
- [ ] 确认编辑器中能看到 `TerrainFill`、`TerrainPlatforms`、`TerrainDetails`、`Ground_West`、`Platform_001..014`、`RoomMarkers`；地形与碰撞不是只靠运行时脚本生成。
- [ ] 在 TileSet 编辑器确认纹理 `a2_forest_terrain_atlas.svg` 已成功导入，尺寸 256×128，切片尺寸 32×32，8 列×4 行；若显示空白、错误纹理或切片错位，停止并先修复资源导入。

## 1. 启动与进入 R01

- [ ] 从项目正常启动流程进入 A1 村庄，再由北门进入 A2。
- [ ] 画面左上角显示房间标识 `A2 · R01`（这是当前验收辅助标签）。
- [ ] 主角出现在西侧入口附近，未出生在平台内部、地底或边界外。
- [ ] Output 没有 `MARKER_MISSING`、`DROP_ANCHOR_INVALID`、`EXIT_ANCHOR_INVALID`、解析错误或资源加载错误。
- [ ] 能正常移动、跳跃、落地、攻击；地形可见部分与实际碰撞边缘一致。

## 2. R01 地形和移动

主角当前源代码基准：水平速度 260 px/s、起跳速度 -520 px/s、重力 1400 px/s²，并包含一次额外空中跳跃。它们只是代码参数，不是已测得的实机结果。R01 主线不得依赖额外空中跳跃。

- [ ] 从西侧入口沿主路前进，无需二段跳即可抵达中央可探索地形。
- [ ] 地表没有明显的视觉悬空、碰撞墙挡路、可见地面却掉落、或角色被卡进碰撞体。
- [ ] 测试短跳与长跳：可见的普通跳跃目标应可达；不能从下方无意穿过实体平台。
- [ ] 检查中央钟墓入口：角色能站在入口外的平台上，按提示进入；不能被入口装饰误挡。
- [ ] 检查树冠高路：可看见的路径与可行走平台一致；从 R01 出发的跳跃不要求空中额外跳。
- [ ] 检查隐藏壁龛：隐藏入口的视觉提示、碰撞封印和实际通路一致；未满足条件时不能穿墙，解锁后不能残留阻挡碰撞。
- [ ] 检查西/东边界：不会从房间侧面走出世界，也不会因为边界墙遮住正常入口。

## 3. R01 → R04 下坠触发

当前触发由运行时脚本依据编辑器中的 `DropToR04` Marker2D 创建 Area2D；R01 锚点为 (672, 780)，触发区宽 48、高 120。该触发只接受向下运动的 Hero。

- [ ] 在缺口左侧正常走动、起跳、落地，不会误切到 R04。
- [ ] 从缺口上方跳过时，不会因为横向擦过触发区而误切房间。
- [ ] 主动从缺口下坠时，触发一次切换到 R04。
- [ ] R04 落点落在 `EntryTombDropR01` 对应的安全地形上，没有立即二次坠落或卡墙。
- [ ] 从 R04 返回后，R01 落点是 `EntryTombReturn`，不是固定西入口。

## 4. R01 ↔ R02 / R03 房间切换

- [ ] 树冠出口进入 R02；R02 返回落在 R01 的 `EntryCanopyReturn`。
- [ ] 钟墓出口进入 R03；R03 返回落在 R01 的 `EntryTombReturn`。
- [ ] 每次切换只触发一次，不会连续闪屏、双重加载或遗留上一房间的 Hero/UI。
- [ ] 返回后玩家朝向、站立位置和碰撞不把角色放在平台边缘之外。

## 7. 验收判定

- **PASS**：所有第 0–4 节项目通过；第 5 节在相应完整流程中通过；没有阻断探索的碰撞/传送错误。
- **FAIL**：任何主路线无法到达、掉落无法返回、普通跳跃误触发切房、返回点错误、碰撞与视觉不一致，或运行时错误。
- **不能判定**：只通过静态 Python 检查，或没有实际启动 Godot 4.6.1。

建议验收顺序：先只测 R01 → R04，再测 R01 ↔ R02/R03，最后验证 C03/C04/H02。每次只修一个可复现问题，然后重跑对应路径。
