# A2-R01《胧村正》方向原型 v0.1

分支：`feature/story-map-progression`

## 目的

这是一份独立的试验场景，不覆盖现有 `a2_r01_room.tscn`，先验证更容易维护的地图方向：

- 主路线是一条连续、易读的横向地面。
- 视觉纵深主要由远景树林、遗迹剪影、雾带和前景树根表达。
- 高处只保留少量有意义的可选平台，不再把主路线做成密集跳台迷宫。
- 固定地形全部由场景内可见节点构成；不允许运行时脚本生成地形。

## 场景

`scenes/rooms/a2_fog_forest/runtime/a2_r01_muramasa_prototype.tscn`

在 Godot 编辑器中单独打开该场景，可在场景树中直接查看 `Polygon2D`、`StaticBody2D`、`CollisionPolygon2D` 和 `Marker2D`。

## 下落操作

主角现有输入实现已经识别 **按住下方向键（↓ / S）并按跳跃键（Space / ↑）**。原型中的三个高处平台各自使用独立的 `StaticBody2D`，其 `CollisionPolygon2D` 设置了 `one_way_collision = true`。主角下落逻辑会临时忽略当前承托主角的物理实体，因此可以从高处平台落到主路线，而不是永久关闭整层碰撞。

注意：现有主角脚本依靠当前地面碰撞实体进行临时穿透。若把多个可穿透平台合并到同一个物理实体，下落时会忽略整个实体，因此每个需要独立下落的平台必须保持独立的物理实体。

## 原型范围与未完成项

- 原型主路线目前保持连续，因此 `DropToR04` 的瀑布下坠转场尚未接入可实际落下的井口；不要把它当作已完成的 R01→R04 路线。
