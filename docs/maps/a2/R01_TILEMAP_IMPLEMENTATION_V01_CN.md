## 2. 编辑器中可见的 TileMapLayer

场景：`scenes/rooms/a2_fog_forest/a2_r01_forest_crossroads.tscn`

| 节点 | 作用 | 当前格子数 | 碰撞策略 |
|---|---|---:|---|
| `TerrainFill` | 西侧、中央低地、东侧地块的地表与土层填充 | 859 | 禁用 TileMapLayer 碰撞，交由独立碰撞多边形负责 |
| `TerrainPlatforms` | 悬空石台、树根台阶和高位树冠路线 | 53 | 独立 CollisionPolygon2D 负责 |
| `TerrainDetails` | 苔藓、细根、石纹与植被点缀 | 28 | 不参与碰撞 |

共享 TileSet：`resources/tilesets/a2_forest_terrain_tileset.tres`  
原创可编辑 Atlas：`assets/art/tiles/a2_forest_terrain_atlas.svg`  
Atlas 单格：32 × 32 px，8 列 × 4 行。前 3 行为苔面、土层、石面；第 4 行为透明装饰。

**职责原则：** TileMapLayer 负责显示和编辑；StaticBody2D 下的 CollisionPolygon2D / 边界 CollisionShape2D 负责真实碰撞。不要同时给 TileMapLayer 打开同一批地形的碰撞，避免双重碰撞。

## 3. 地面与墙体轮廓

### G0 — 西侧入口根台（`Ground_West`）

CollisionPolygon2D 顶部轮廓（依次连接）：

```text
(0,640) → (320,640) → (320,672) → (512,672)
→ (512,736) → (640,736) → (640,1200) → (0,1200)
```

地形分三段缓降：入口 y=640；根阶平台 y=672；下层西台 y=736。西侧边界墙中心 x=0，尺寸 28 × 1200。

### G1 — 中央塌陷根桥下方（`Platform_001`）

顶部轮廓：

```text
(704,800) → (800,800) → (800,768)
→ (896,768) → (896,704) → (1120,704)
```

地块向下封闭至 y=1200。它将下落空间与东侧高台区分开，台阶不是等距复制的平台。

### G2 — 东侧古树基台（`Platform_002`）

顶部从 (1216,640) 延伸至 (1792,640)，地块向下封闭至 y=1200。东侧边界墙中心 x=1792，尺寸 28 × 1200。

## 6. 本轮工程变更

- 把原本一整条 y=650 平地替换为分层地表、悬空根阶和东侧树冠高路。
- 增加三个编辑器可见 TileMapLayer、共享 32 px TileSet 与原创 SVG atlas。
- 碰撞与视觉层解耦，所有主体地形使用编辑器可见 CollisionPolygon2D。
- 将运行时 floor_y 调整为 640，与西侧入口地表对齐。
- 把 R01 → R04 下坠入口收窄至 (672,780) 的实际落井，更新运行时连接及连接合同。
- 将钟墓黑色洞口提升到 TileMap 填充层之上，避免被地表图块遮挡。
- 更新静态几何验收脚本，使其识别 R01 TileMapLayer 的序列化格子数据，而不再套用旧的矩形平台估算模型。

## 7. 本地 Godot 4.6.1 验收清单

1. 打开 `scenes/rooms/a2_fog_forest/runtime/a2_r01_room.tscn`，确认底层 `AuthoredRoom` 展开后能看到三个 TileMapLayer、地形碰撞多边形、两侧边界和所有 RoomMarkers。
2. 确认 SVG atlas 被正常导入、三个 TileMapLayer 显示格子；检查没有紫色缺失纹理或资源解析错误。
3. 从 A1 进入，检查主角脚底与西侧地面贴合；沿根阶探索，确认平台没有穿透。
4. 不使用二段跳，从西侧台阶到树冠长台并能触发 R02 入口。
5. 跳过 x=640–704 的落井，确认不会误切场景；主动落入时进入 R04，且出生点位于地面上方而不是碰撞体内。
6. 从 R03、R02 返回 R01，分别落在正确的地形高度，不进入地面或悬空。
7. 打开 Debug / Visible Collision Shapes 检查多边形边界与图块轮廓一致。
