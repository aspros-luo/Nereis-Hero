## 1. 场景构成

实际地形场景：

`scenes/rooms/a2_fog_forest/a2_r01_forest_crossroads.tscn`

主美术资源：

`assets/art/levels/a2_r01_forest_ruins_illustration.svg`

运行时包装场景：

`scenes/rooms/a2_fog_forest/runtime/a2_r01_room.tscn`

旧入口兼容场景：

`scenes/ash_forest.tscn`

R01 美术是 1792 × 1200 的原创分层 SVG 插画，经 Godot `Sprite2D` 显示。插画负责树冠、粗根、苔藓石壁、远景废墟、中央遗迹、纯装饰断桥、瀑布和水潭；可站立面使用独立 `StaticBody2D / CollisionShape2D`，在 Scene 树中可逐个选中和修改。游戏不在运行时通过脚本生成地形。

## 2. 地形构图与体验目标

- **左侧入口**：位于主地面 y=640，巨树根系与冠层压住左上画面。
- **① 树根高台**：西侧可俯瞰平台，位于 y=512；通过下方根阶连接。
- **② 下层岔路**：位于入口下方 y=768，提供可选探索与向上返回路线；不是必须经过的主路。
- **③ 中央遗迹高台**：中央石拱平台 y=512；通过中层阶台抵达。远处断桥只服务视觉叙事，不能作为碰撞面。
- **④ 瀑布水潭支路**：底部平台 y=800；从主路落下进入，再经 y=736 回返台回到主路。
- **⑤ 右侧神殿高台**：顶部 y=480，是通往 R02 的出口落脚面。

主路沿西侧地面前进，经中央中层路径到东侧高台，再逐级上升至⑤；主路设计不以二段跳为前提。落井是独立选择，不是强制主路径。当前碰撞的最终可达性、跳跃余量和实际落点仍须在游戏中验证。

## 6. 本地验收命令

在项目根目录执行：

```bash
GODOT="/Users/aspros/Downloads/Godot.app/Contents/MacOS/Godot"
"$GODOT" --headless --path . --editor --quit
"$GODOT" --path . res://scenes/rooms/a2_fog_forest/runtime/a2_r01_room.tscn
```

第一条用于触发项目资源导入/编辑器解析；第二条进入运行时检查。请重点观察：
1. SVG 是否正常显示，是否出现紫色缺失纹理、SVG 解析错误或美术缩放异常。
2. 玩家是否能从入口到⑤，且主路不依赖空中二段跳。
3. ①与③是否可以按预期到达；②和④是否是可选择的下层分支，并且有可用的回返路线。
4. 穿过断桥视觉区域是否会落下（断桥本身应无碰撞），落井只在主动坠落时进入 R04。
5. 从 R02/R03 返回时是否落在地面上，而不是出现在悬空/地形内部。

只有完成上述场景导入、碰撞和跨区切换测试之后，才能将 R01 标记为实机通过。
