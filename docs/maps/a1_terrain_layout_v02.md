# A1 边境村庄｜区域内部地形图 v0.2

![A1 边境村庄地形图 v0.2](./a1_terrain_layout_v02.svg)

## 本轮修订目标

把 v0.1 的抽象路线框图推进到可用于下一步侧视地形剖面设计的布局草案。本图表达的是 **2D 横版平台地图的相对布局**，不是 2.5D 或俯视角游戏画面。图上方位仅用于说明建筑、支路、井道和出口的相对关系。

## A1 的空间骨架

- **C01 西入口 → A1-S01 主街 → C02 北门**：建立最清晰的初始导航轴；C02 仍受村庄防卫进度控制，开放后双向回访。
- **A1-S02 民居后巷**：从主街侧向偏入、可原路返回。沿路分散建筑与互动点，不把 NPC 聚集在一个小区域，也不让后巷成为第二条平行主街。
- **A1-S03 屋顶木栈道**：改为多个独立屋顶段，通过跳跃和有限的上下行连接起来。段与段之间保留空隙和高度差，不画成一条悬空直线；地面玩家能看见部分上层探索目标。
- **A1-S04 老井平台**：作为稳定地面和安全交互点。C06 从 A4 回村时落在平台的安全边缘，不能和井口、H01 隐藏入口或危险落差重叠。
- **A1-S05 / H01 井底回声层**：井道是可辨认的垂直空间；隐藏入口放在井底侧壁，不与井口混同。沿用既有门槛：共振视界有效且神识共鸣达到 12；进入后可以返回 A1。
- **C24 旧排水低位支路**：与屋顶路线完全分离。初始只允许探索一段短低位通道，不能提前连通 A3；只有 A4 侧按既有连接合同打开后，才形成持久跨区连接。

## 侧视地形落实规则

1. 主街使用连续的地面碰撞，不因 S01/S02/S04 的逻辑标签而制造传送门。
2. 屋顶平台必须依附建筑轮廓或木结构支撑；每次上下层切换都要有可验证的跳跃、台阶或攀爬路径，不能依赖“看起来相连”。
3. 建筑立面与可站立屋顶分离：不可站立的屋檐只做背景/装饰碰撞；可站立木栈道才设置平台碰撞。
4. 井道必须有明确的落下空间、井壁和底部承托；H01 入口需要可发现但不显眼的视觉提示，且不能成为误触发的 C06 出生点。
5. C24 低位路线要检查站姿/碰撞高度、通行宽度、掉落后回返能力以及未解锁端点的阻挡状态。
6. 场景边界、镜头边界和实际可走边界必须分别定义；不能用镜头边缘代替实体墙，也不能让玩家从边界外绕过门锁。
