# 地形设计重整说明

## 决策
从本次地图设计阶段开始，以“区域内部地形图”为正式关卡设计依据，而不是以先前预先切分的房间数量作为目标。

## A5 旧 22 房间方案
- tools/a5_room_design_contract.json 与 tools/a5_room_assembly_contract.json 中的 A5-R01 至 A5-R22 方案，标记为旧版地形草案，不再作为新地形设计的权威来源。
- 不因该设计判断而立即删除场景、脚本、验收器或连接实现；这些文件可能仍被运行时代码引用，直接删除会造成回归。
- 已通过的 A5 runtime acceptance（465 PASS / 0 FAIL）只证明现有自动化检查通过，不代表该 22 房间布局符合新的关卡设计目标。
- A5 的正式重设计应先产出区域内部地形图，确定连续空间、主路、支路、竖向穿插、隐藏区、能力门、捷径和跨区出口，再决定哪些旧场景可复用、合并、替换或退役。

## 新工作顺序
1. 先把 A1 画成区域内部地形图，并根据现有拓扑合同核对入口、出口、屋顶、老井、H01 与旧排水路线。
2. A1 布局确认后，再按同一规范推进 A2 及后续区域。
3. A5 旧房间实现暂时冻结：不继续增加房间或扩张现有房间合同，除非修复阻塞性运行问题。
4. 每张地形图先审查布局，再细化网格/平台/碰撞，最后做 Godot 运行验收。

## 设计边界
世界级 A0–A13、C01–C24、H01–H08 拓扑保持不变，除非单独审查并确认需要调整。此重整只改变区域内部地形设计方法，不擅自改变跨区域连接契约。
