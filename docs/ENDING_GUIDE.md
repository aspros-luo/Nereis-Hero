# Nereis Hero 结局攻略

> 当前开发契约：结局由主角的鸣响、隐藏真相锚点道具和探索进度决定。与蜜忒发生身体结合不再是任何结局的必要条件。

## 结局判定（原型阈值）

判定代码集中在 scripts/core/ending_evaluator.gd：

| 结局 | 条件 |
|---|---|
| 凡人之墓 | 未同时满足任一宇宙结局的鸣响、证据和探索门槛 |
| 永恒乐园 | 鸣响 ≥ 68，外神接触度 ≥ 6，至少进入 1 处隐藏区域，且未满足烈火天罚条件 |
| 烈火天罚 | 鸣响 ≥ 68，收集至少 3 个独立真相锚点来源，并进入至少 2 处隐藏区域 |

结局判定不读取 physical_union_complete、mite_connection_missed、蜜忒互动数量或 outer_god_resonance。

## 一、凡人之墓

这是以人类政治冲突为主的结局。英雄击败教会最高权威与国王，帮助复国军剔除教会对王国的直接控制。胜利确实发生了，但复国军在后续岁月里逐渐复制旧制度的腐化，成为新的统治机器。

测试方向：鸣响保持在 68 以下；或者鸣响较高，但没有通过探索取得通向宇宙结局所需的外神接触证据。与蜜忒的关系可以发展，也可以错过，不影响候选结局。

## 二、永恒乐园

英雄的鸣响成为外神能够回应的信号。玩家接触到外神残留，却没有收集足够的真相锚点与深层探索记录来保全自我，英雄因此成为容器，世界被拖入永恒梦境。

条件：
- hero_resonance >= 68
- outer_exposure >= 6
- 至少进入 1 处隐藏区域
- 未满足烈火天罚的完整抵抗条件

不要求与蜜忒发生身体结合。结局演出应依据实际记录的人物关系调整语境，不得在进入结局时伪造 physical_union_complete。

## 三、烈火天罚

英雄同样成为强烈的鸣响信号，但他找到了多条看似无关的真相线索，并深入探索隐藏区域。三件以上的真相锚点让他保留足够的自我，能够抵抗外神完成降临。

条件：
- hero_resonance >= 68
- hidden_artifact_pieces >= 3
- entered_hidden_regions.size() >= 2

四类真相锚点：远古研究 ancient_lab、墓地钟声 graveyard_bell、复国军档案 rebel_order、记忆回响 memory_echo。三类已足够，第四类用于补全信息。该结局仍然是悲剧，并不意味着英雄能毫无代价地拯救蜜忒或城市。

## 四、三结局与两部作品的关系

《Nereis-Hero》的凡人之墓并非整个世界的最终答案。复国军在之后逐渐腐化；《Nereis-Lullaby》将以蜜忒为主要视角，描写英雄在新秩序中的后续选择、逐渐堕落，以及他最终抛下蜜忒的可能命运。蜜忒可能只理解其中一部分，但她身后的外神并不在意人类政权的更替，会继续寻找下一个容器。

## 五、当前测试按键

- ESC：暂停菜单
- F / E：进入蜜忒房间（可选剧情场景，不是结局门槛）
- F1：按当前鸣响、道具和探索状态进入结局候选
- F2：永恒乐园导演测试
- F4：远古研究病房
- F5：村庄防卫
- F6：蜜忒共鸣
- F7：教会最终 Boss
- F8：烈火天罚导演测试
- F9：删除存档并重新开始

导演测试快捷键不代表最终玩家界面。
