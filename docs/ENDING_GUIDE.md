# Nereis Hero 结局攻略

> **权威设计规则：** [结局条件设计基准 V2](./ENDING_CONDITION_DESIGN_CN.md)。本文旧阈值仅记录当前原型实现，不再作为最终剧情契约。
>
> 结局判断依据玩家实际探索路径、关键道具取得 / 持有 / 使用状态，以及特殊剧情和事件的真实完成记录。蜜忒关系可以影响部分道具或剧情的获取途径，但不直接决定结局；身体结合不是任何结局的必要条件。

## 三个结局的路线意图

| 结局 | 设计意图 | 典型条件缺口 |
|---|---|---|
| 凡人之墓 | 玩家以正常主线为主，未发现 / 进入关键隐藏地图，因此未取得触发宇宙特殊剧情所需的关键道具 | 缺少隐藏路径、关键道具和特殊剧情链 |
| 永恒乐园 | 玩家已探索并取得部分关键道具、触发部分特殊剧情，但未完成更深层探索或完整抵抗链 | 例如没有取得第三根脐带，或缺少后续关键事件 |
| 烈火天罚 | 玩家完成深层隐藏探索、关键道具与指定事件链，具备抵抗外神的条件 | 必须核实指定路径、道具状态、特殊剧情与协同事件全部完成 |

以上为路线设计意图，不是已经完成实现的条件清单。具体道具 ID、要求是“取得 / 当前持有 / 已使用”中的哪一种，以及各事件的正式标识，须以结局条件映射表和实际脚本为准。不可把地图拓扑连通、看见入口或进入某场景直接当成完成探索。

## 烈火天罚：朝圣骑士与遗物条件链

烈火天罚的一个明确设计实例，要求完整完成以下链条，而不是只满足抽象的探索 / 道具数量：

1. 初遇朝圣骑士；
2. 进入隐藏地图禁忌森林，再次遇到他并完成合作；
3. 获得他的回复酒；
4. 在王墓与他共同击败指定教会怪物，并获得他的徽章；
5. 取得金正遗物徽章、染血笔记、复仇女神赐福的火种；
6. 完成第三根脐带相关道具的四次规定使用；
7. 以上必要条件全部满足后，才可进入烈火天罚候选。

这份清单是设计要求，当前实现状态须经源码审计确认。尤其“四次使用”具体指同一道具四次还是四个独立对象 / 仪式，必须在实现前确认；不能擅自猜测。任何一个必要事件或物品缺失，都应阻止烈火天罚误触发。

## 蜜忒关系如何影响结局

- 与蜜忒的交流 / 关系发展可以成为特定道具或特殊剧情的获取前置条件。
- 如果道具只能经由某段关系内容取得，玩家会因是否取得该道具而间接影响结局；这不等于关系值本身决定结局。
- 结局演出可以按真实发生过的关系事件调整台词和人物语境，不得假定玩家一定认识蜜忒或发生过亲密关系。
- 不得为了结局判定伪造关系标记或 `physical_union_complete`。

## 旧版原型逻辑（仅供追溯）

当前 `scripts/core/ending_evaluator.gd` 仍使用旧阈值：

- `hero_resonance >= 68`；
- 烈火天罚：`hidden_artifact_pieces >= 3` 且进入至少 2 处隐藏区域；
- 永恒乐园：存在 `anomaly_observer_reaction`，且进入至少 1 处隐藏区域（未满足烈火天罚时）；
- 其他情况为凡人之墓。

这套原型没有显式检查第三根脐带、道具是否使用 / 仍在背包、与朝圣骑士协同击败教会怪物、森林深处邪教仪式头目战或其他特殊剧情是否完成。旧原型曾用于较早的结局验证，但尚不满足 V2 设计基准；在完成映射与验收前，不得宣称最终结局条件已实现。
