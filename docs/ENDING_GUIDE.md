# Nereis Hero 结局攻略

> 当前版本：development
> 这份攻略以当前已经落地的剧情状态机为准。三个结局的核心判定不是好感度，而是是否发生身体结合，以及是否取得隐藏抵抗锚点。

## 结局判定

| 结局 | 条件 |
|---|---|
| 凡人之墓 | 没有发生身体结合 |
| 永恒乐园 | 发生身体结合，但隐藏抵抗锚点未觉醒 |
| 烈火天罚 | 发生身体结合，并取得至少 3 类隐藏线索 |

隐藏线索一共有 4 类：

1. 远古研究：ancient_lab
2. 墓地钟声：graveyard_bell
3. 复国军档案：rebel_order
4. 记忆回响：memory_echo

当前门槛是 4 类中至少 3 类。

## 一、凡人之墓

这是最适合第一次通关的“普通路线”。

从序章进入村庄后，不要把蜜忒的关系推进到房间休息的身体结合阶段。

可以正常调查村庄、墓地、酒馆、教会和复国军，也可以推进政治主线。关键只有一点：不要在蜜忒关系完成前进入蜜忒房间并在床边触发结合。

当前版本在没有 physical_union_complete 时，结局判定一定会落到“凡人之墓”。

当前验收方式：回到村庄后按 F1。

没有身体结合 → church_final_demo.tscn。

最终演示顺序：大祭司（人类） → 远古神肉身 → 国王。

主题是：教会被推翻了，但王国并没有真正获救。

## 二、永恒乐园

这个结局需要让英雄和蜜忒真正靠近，但不要完成隐藏抵抗锚点。

### 1. 完成蜜忒四段自然互动

依次取得：

- mite_first_meeting
- mite_meal
- mite_stay_a_while
- mite_return

蜜忒的互动有地点间隔限制。完成一段后，离开村庄，再回来，下一段才会出现。

推荐：村庄 → 墓地/酒馆 → 回村 → 再去墓地/酒馆 → 回村。

注意：不要在 mite_stay_a_while 之前进入教会。当前逻辑会在你过早进入教会时把蜜忒的关系窗口标记为错过。

### 2. 进入蜜忒房间

村庄里走到房门前，看到进入提示后按 F 或 E。

当前版本已经改为“玩家主动进入”，不会再因为接触角色自动进屋。

### 3. 在床边休息

当四段蜜忒互动已经完成后，在房间里的床边休息。

当前自然流程会触发 AFTER THE LAST SONG → SOMETHING ANSWERS，并记录身体结合、远古残留苏醒、Outer God 共鸣。

### 4. 不要收集 3 个隐藏来源

隐藏来源少于 3 类，结局候选就是“永恒乐园”。

回到村庄后按 F1 即可进入当前版本的结局演示。

核心演示：教会变形 → 国王变形 → 蜜忒 → 永恒花园。

主题是：两个人终于成为一体，但也因此失去了“彼此分离的自由”。

## 三、烈火天罚

这是隐藏线最多的路线，也是目前最接近“真结局 / 真相路线”的版本。

核心条件：身体结合 + 4 类隐藏来源中至少 3 类。

### 最简单的 3/4 收集法

推荐先走最短路线，不必四条全部跑完。

#### 第一件：墓地

村庄 → 墓地。

击败两只 Bell Wraith 后，调查 THE WEATHERED STONE。

当前会记录 graveyard_bell。

#### 第二件：复国军营地

村庄 → Restoration Camp。

调查 UNSENT ORDER。

当前会记录 rebel_order。

#### 第三件：远古研究病房

村庄 → 教会 → 隐藏研究入口。

进入 ANCIENT RESEARCH WARD。

调查任意关键实验线索即可记录 ancient_lab。最明显的三个是 BLACK VIAL、SEALED HAIR、VESSEL LEDGER。

到这里已经是 3 / 4，隐藏抵抗锚点会被唤醒。

#### 第四件：记忆回响（可选）

酒馆或教会的路线调查可以进入对应 Route Scene。

与路线中的 Memory Echo 互动会记录 memory_echo。

它是第四件，不拿也可以。

## 四、烈火天罚完整顺序

完成 3/4 隐藏线后：

1. 完成蜜忒四段互动。
2. 回到蜜忒房间。
3. 在床边触发身体结合。
4. 返回村庄。
5. 当前结局候选变为烈火天罚。
6. 按 F1 进入最终演示。

最终演示：教会最终权威 → 100 名教徒 → 蜜忒 → 教会/异变部队 → 城市焚毁。

100 名教徒本身没有隐藏设定，就是导演式舞台保留节目。

蜜忒不是传统三连击 Boss。

如果玩家不操作，她会在等待窗口结束后自己扑向英雄的武器。

这一段不是“打赢了 Boss”，而是她短暂取回自我，然后选择让英雄杀死自己。

最后城市爆炸。

## 五、三结局推荐体验顺序

### 第一周目：凡人之墓

正常推进，但不要和蜜忒发展到身体结合。先感受教会、复国军、王国政治、大祭司、国王。这是世界观的“人类答案”。

### 第二周目：永恒乐园

主动完成蜜忒四段互动，进入房间，在床边休息，不要刻意收集 3 个隐藏来源。这是“爱情答案”。

### 第三周目：烈火天罚

蜜忒四段全部完成，同时调查墓地、复国军营地、远古研究病房，然后回蜜忒房间完成结合。这是“真相答案”。

如果有时间，再把第四个 Memory Echo 也拿齐，完整观察四条隐藏线之间的关系。

## 六、当前测试按键

### 普通游戏

- ESC：暂停菜单
- F / E：进入蜜忒房间
- E / SPACE / ENTER / J / 鼠标左键 / 右键：快速结束底部叙事框

### 导演测试

- F1：按照当前状态进入结局候选
- F2：永恒乐园导演测试
- F4：远古研究病房
- F5：村庄防卫
- F6：蜜忒共鸣
- F7：教会最终 Boss
- F8：烈火天罚导演测试
- F9：删除存档并重新开始

> 导演测试用于验收，不代表最终玩家界面。

## 七、语言

当前游戏语言：

- 简体中文
- 繁体中文
- English
- 日本語

语言切换作用于标题菜单、暂停菜单、HUD、区域名、目标、交互提示、角色对白、旁白、剧情演示、结局文本、场景文字。

语言设置写入存档，新游戏不会强制恢复成简体中文。
