# Nereis Hero — 世界线索与小人物叙事基线（中文）

> 状态：叙事设计基线；记录已确认设定与制作方法。未明确标记为“已确认”的具体事件、人物、物品文案均为待设计内容，不得视为正史。
> 分支：`feature/story-map-progression`
> 用途：让跨对话的剧情设计保持一致；统筹世界级真相、玩家可发现的证据、区域线索、物品文本与结局条件。

## 1. 核心叙事原则

**小人物不负责讲解世界观；他们只做自己会做的事、留下自己会留下的痕迹。玩家通过跨地点、跨时间的证据自行拼出真相。**

- 先让人物的日常困境成立，再让其中出现不协调的细节。
- 物品、纸条、工作记录、行为轨迹与环境变化可以表达信息；避免用百科式文本直说世界真相。
- 第一遍阅读应有一个普通、合理但不完整的解释；获得后续证据后，旧线索才显露新的含义。
- 不是每条线索都必须与主线、古神或外神有关。小人物可以有自己的目标、误解、利益和结局。
- 不要让所有 NPC 都成为同一阴谋的工具，也不要让每件物品都暗示神祇。
- 不要求每名角色掌握超出其身份、经历和信息来源的知识。角色可以误解、隐瞒、偏见或只知道事情的一小部分。
- 最有力的反转应来自玩家重新理解此前见过的事实，而非最后由角色一次性解释所有谜底。
- 不把含糊写成无意义：线索可以隐晦，但在后续证据出现后应能够回溯、验证或形成合理解释。

## 2. 已确认的世界观边界

### 2.1 古神

- 古神是这个星球原本存在的旧日支配者，现已长眠。
- 教会发现了古神的尸体或遗骸，并研究其血液、毛发、皮肤等材料，涉及人体变异与武器研发等方向。
- 教会内部存在不同学派，但仍属于同一个教会组织。
- 掌权派希望利用古神力量巩固权力、震慑周边敌人；学术派希望获取更先进的知识。
- 两派可能因研究所需的资源、保护和权力而合作，但对研究成果的用途存在分歧。
- 学术派成员未必知道材料的真实来源、全部用途或研究后果。不可把每个教会成员写成全知者。

### 2.2 外神

- 外神来自星球之外，与古神性质、立场不同。
- 外神是活动且不可理解的存在；人类无法把握其想法。不得擅自把外神写成有清晰人类式目标的征服者、毁灭者或入侵者。
- 外神只是一时兴起想来这个星球看看，但目前暂时无法来到这里。
- 蜜忒是外神找来的代言人，但她像纯洁的羔羊，自己感知不到外神；她不是明知故犯的邪恶操纵者。
- 外神通过精神影响蜜忒周围的人。部分人接触未知知识、窥见一点神识后，开始研究让外神降临的仪式；他们把自己不理解的现象当成神迹，并形成另一种类似中世纪宗教的信仰。
- 外神阵营包括蜜忒、村庄以及邪教核心人物，但阵营成员的认知并不一致。邪教核心人物知道得较多，也不等于掌握真相。
- 不可把教会研究古神直接写成教会研究外神，也不可擅自断言古神与外神之间已有确定联系。

### 2.3 王国衰败

- 王国正在走向衰败，但衰败的具体原因尚未定案。
- 不可擅自把衰败归因于外神、长期战争、王位继承或教会阴谋；这些只能作为待讨论假设。
- 衰败不意味着王国所有军事力量都很弱。王都、禁卫或核心地区仍可强大；地方失序、势力冲突、资源分散与道路废弃等，可在后续设计中作为候选解释，但尚非既定正史。

## 3. 三个结局：不可混淆的事实

### 3.1 凡人之墓

- 玩家没有探究到真正的世界真相。
- 结局本质是一场权力交替；统治者更换不代表玩家理解了古神或外神。
- 该路线的线索可以涉及政治、地方权力与制度矛盾，但不能让玩家仅靠主线就完整掌握宇宙真相。

### 3.2 永恒乐园

- 这是知晓全部真相的结局。
- 相关人物心甘情愿地完成外神的“恶趣味”，可类比《EVA》人类补完计划。
- 外神仍未真正降临；世界被意识化，星球或王国失去原有的物质形态/物质存在。
- 不得把它描述为外神已经降临，也不得将其简化为传统意义上的胜利结局。

### 3.3 烈火天罚

- 已确定的条件包括：杀死 100 名教徒，并杀死蜜忒。
- 游戏后期，玩家探索到部分外神真相后，会取得相关物品/道具；玩家可以选择将其交付给蜜忒或使用，由此决定走向永恒乐园或烈火天罚。
- 物品选择与“杀死 100 名教徒并杀死蜜忒”的条件需要在后续流程表中协调，不能擅自让物品选择取代既定条件；具体先后顺序尚未定案。
- 烈火天罚不是笼统的“外神降临失败”：外神已准备降临，但蜜忒作为媒介被杀，降临过程因此被烈火打断；外神失去这次降临所需的媒介。
- 王国覆灭，所有人牺牲。这不代表主角杀死、消灭或真正理解了外神；只是此次降临被中断。
- 永恒乐园与烈火天罚在后期关键选择上方向相反，但两者都不应被简单写成“善结局/恶结局”。

## 4. 线索设计的层次

| 层次 | 玩家看到什么 | 设计目标 | 避免的问题 |
|---|---|---|---|
| 生活痕迹 | 行囊、账单、工作工具、私人物件、未完成的日常事务 | 先让人物像真实的人 | 每件物品都承担主线说明 |
| 局部异常 | 不合常理的记录、被改动的路线、材料调拨异常、某人突然改变习惯 | 让玩家产生疑问 | 直接点明幕后真相 |
| 独立证据 | 来自不同人物、地点和年代的记录或实物 | 让不同线索互相印证 | 所有证据都来自同一位解释者 |
| 跨区关联 | 教会记录与遗迹实物、传闻与旧路、人物轨迹与制度记录相互照应 | 让玩家主动建立联系 | 把古神和外神强行并成一条线 |
| 真相重释 | 玩家掌握新知识后回想旧物品、旧行为 | 形成“事实未变、理解改变”的效果 | 最后用长篇旁白解释一切 |

## 5. 线索的知识权限

设计每条线索时，必须区分以下四件事：

1. **真实发生了什么**：作者侧的事实记录。
2. **人物知道什么**：仅限其身份、经历和接触到的信息。
3. **人物以为发生了什么**：可能正确、错误或只对了一部分。
4. **玩家此时能推断什么**：依据当前可见证据所能作出的合理判断。

这四者不可混写。人物可以只知道货物被调走，却不知道货物的真实来源；他可以抱怨研究材料被拿去锻造武器，却不理解材料为什么特殊。后续遗迹中的独立证据才可能让玩家意识到这些材料与古神遗骸有关。

## 6. 教会纸条示例（仅为写法示范，不是正式物品）

> “又改了调拨单。
> 好不容易才取得的材料，他们居然打算全部送去锻造坊。
> 我问过一次用途。得到的答复是：不需要知道。
> ……既然如此，还要我们这些人做什么？”

此类文本的目的不是直接告诉玩家“权威派用古神毛发和皮肤锻造武器”，而是呈现学术派的工作受挫、资源争执和信息被封锁。真实材料来源应由其他独立证据支持。正式文本仍需根据人物身份、地点、时代和证据链进一步编写。

## 7. 设计顺序：先搭全局骨架，再从小处落地

不建议一开始就把全世界所有物品文案写完，也不建议完全不看全局、直接随机写 R01 的小故事。采用两层工作法：

### 第一层：全局线索骨架（先做，保持简洁）

为每条核心真相记录：
- 真实事实；
- 哪些人/组织知道或误解它；
- 玩家最早可能接触到的间接痕迹；
- 哪些区域或遗迹提供独立证据；
- 哪些证据只支持局部推断，哪些组合起来才足以接近真相；
- 它与三个结局的关系；
- 不能提前泄露的内容。

这一步只列“证据类型、来源和依赖关系”，不提前写满所有文本。

### 第二层：区域小人物叙事（从 A2/R01 开始）

每个小故事先定义人物自己的生活与动机，再决定其留下的物品、行为或事件。随后检查它是否自然地连接到全局线索骨架；如果没有，也可以保留为独立的世界生活细节。

每个线索建议记录：
- 线索 ID / 区域 / 载体；
- 人物或事件的真实背景；
- 留下痕迹的人知道什么、不知道什么；
- 玩家首次发现时的合理解释；
- 后续哪些证据会改变其含义；
- 与古神、外神、王国或个人生活的关联类别；
- 对结局理解的贡献；
- 首次可见时间与可能错过条件；
- 是否已确认正史、是否只是候选；
- 最终物品文案（最后填写）。

## 8. 制作时的硬性检查

- 不因“神秘感”而把文本写成毫无可验证信息的谜语。
- 不用单条早期线索直接揭露完整真相。
- 不要求所有玩家都发现隐藏线索；主线应能在不掌握完整真相时继续推进。
- 不让每个小人物都知道世界级事实。
- 不把所有异常都归因于外神，也不把教会古神研究与外神仪式混为一谈。
- 不把尚未决定的王国衰败原因、NPC结局、事件因果写成既定事实。
- 先设计事实和证据关系，再写物品文案；先确认文案背后的真实事件，再放入场景。
- 场景物品若进入游戏实现，必须使用场景中可见的已编辑节点，不得在运行时生成固定地形或固定物品节点。

## 11. 全局叙事与线索骨架 v0.2（多线并行 / 隐藏真相）

> 状态：结构性设计基线。此版本调整的是叙事组织方法，不新增已确认的世界事件、教派名称、NPC 身份或物品。除明确标记为“已确认”的内容外，均为候选方向。

### 11.1 总原则：世界不是围绕两位神运转的谜题

全世界的叙事由多条可以独立成立、偶尔交叉的故事组成。古神与外神是隐藏深层真相的一部分，不是所有人物、区域、信仰和事件的共同答案。

- 玩家在普通探索中首先接触到的是人的生活、利益、誓言、恐惧、误判与选择，而不是“神祇线索”。
- 一条故事即使最终没有连接古神或外神，也可以完整、有分量，并产生自己的后果。
- 不预设所有信仰属于同一体系，不预设所有骑士、门徒或教派成员彼此认识，也不预设他们最终会合流。
- 不要因为某个人物有神秘背景，就把他的每次行动都写成伏笔。人物可以有普通动机，也可以做出与主线无关的选择。
- 神祇相关的隐藏线应通过隐蔽区域、独立实物、跨地区记录和可验证的行为后果逐步显现；普通对话和早期物品不应频繁直呼古神、外神、媒介或降临仪式。
- 隐晦不等于随机。玩家在取得足够证据后，应能回溯并验证关联；但单条早期线索不应暴露完整答案。

### 11.2 并行故事类别（设计框架，不是既定阵营）

| 类别 | 可能承载的故事 | 设计约束 |
|---|---|---|
| 个人利益与生存 | 交易、欺骗、欠债、临时合作、背叛、逃亡 | 金正的行为由利益、风险与筹码驱动；不必强行关联神祇，也不能事后翻案为“其实一直是好人” |
| 信仰、誓约与朝圣 | 朝圣、守誓、教派习俗、信念冲突、失去信仰 | 不同信仰可以独立存在；信徒可能只知道日常教义，不知道任何隐藏真相 |
| 王国与地方秩序 | 征召、税赋、地方势力、道路废弃、军政命令落差 | 描写具体后果，不擅自决定王国衰败的根本原因 |
| 地区历史与普通人的旧事 | 迁徙、旧战场、失踪者、工匠记录、家庭遗物、废弃设施 | 每个地区可以拥有不依赖主线的历史与人物故事 |
| 制度与组织内部矛盾 | 资源争夺、职位冲突、命令被隐瞒、理念分歧 | 同一组织内部也有不同认知与利益；组织成员不自动全知或同心 |
| 人际关系与道德选择 | 互助、嫉妒、承诺、亏欠、怯懦、勇气、牺牲 | 角色应有自己的目标与后果，不只是递送线索的工具 |
| 古神遗骸与教会研究（隐藏深层线） | 样本、研究、材料调拨、军备与遗迹证据 | 不让普通教会成员普遍知晓材料来源；不与外神仪式合并 |
| 外神影响与仪式（隐藏深层线） | 无法解释的念头、行为趋同、局部仪式痕迹、彼此矛盾的记录 | 早期呈现应有普通解释；不让蜜忒自知身份，不把外神写成人类式反派 |
| 三结局与玩家认知 | 政治层面的权力更替、完整真相、打断降临的悲剧选择 | 结局所需的理解层级与行为条件必须区分，未定流程不能自行补全 |

上述类别不是封闭分类，也不要求每个区域全部覆盖。某个角色可以只属于个人故事，也可以在特定节点与一条或多条世界故事相交；交叉必须由事件、动机或证据支持，而不是靠相似符号强行连接。

### 11.3 隐藏真相的呈现规则

**古神遗骸、教会研究与武器研发（作者侧已确认）**
- 教会发现了本星球古神的尸体/遗骸，并研究其血液、毛发、皮肤等材料。
- 教会内部的掌权派与学术派有不同诉求，但仍属于同一个组织。
- 早期玩家看到的应首先是资源调拨、工作冲突、保密要求或武器生产等局部事实。
- 研究人员、运输者、仓储者和锻造者只知道各自接触到的部分。材料编号、保存条件、交付记录和隐藏遗迹中的实物可以在后续形成独立印证。
- 不得仅凭教会符号或某句含糊文字，就认定某个普通角色参与了古神研究。

**外神、蜜忒、精神影响与降临仪式（作者侧已确认）**
- 外神来自星球之外，活动且不可理解；它只是暂时无法来到这个星球。
- 蜜忒是外神找来的代言人，但她自身并未意识到外神的存在或影响。
- 外神影响蜜忒周围的人；部分人把接触到的未知知识误认为神迹，并研究让外神降临的仪式。不同参与者的认知并不一致。
- 早期痕迹应能被理解为习俗、互助、个人执念、偶然巧合或不完整的宗教实践；只有多处证据累积后，玩家才可能怀疑存在共同影响。
- 不要把所有门徒、骑士或信仰者都归入这条隐藏线。也不要仅凭某人祈祷、佩戴护符或使用相似图案，就认定其受外神影响。
- 不把外神写成有明确征服、毁灭或入侵计划的传统反派；不把古神研究与外神仪式视为同一计划。

### 11.4 人物、信仰与组织的归属规则

每个重要角色分别记录以下字段，不能互相替代：

1. **公开身份**：玩家最初能合理看见的身份，例如旅人、骑士、门徒、工匠、商人或逃兵。
2. **实际归属**：角色是否属于某个组织或信仰；如果尚未决定，明确标记为待设计。
3. **个人动机**：他为什么行动，与公开身份是否一致。
4. **真实知识范围**：他确实知道什么，以及通过什么途径知道。
5. **个人理解与误解**：他认为事情是什么，可能与事实不符。
6. **对玩家的呈现**：首次见面时玩家能观察到什么，哪些内容要通过行动和后续证据才会显现。
7. **故事关联**：角色的个人故事是否与其他线相交；允许答案为“没有直接关联”。

应用规则：
- 金正可以在未来被设计为某种信仰、组织或个人关系中的参与者，但目前不能仅凭本骨架为他指定门徒、骑士或秘密阵营身份。先让他的利益逻辑成立，再决定是否需要组织背景。
- 外来朝圣骑士的正义感、朝圣经历和迷路等特征应先作为独立人物故事成立；他的目的地、所属信仰及最终命运仍未定案。
- 新增某种信仰或骑士组织前，先定义其日常实践、成员差异、社会功能与内部矛盾；不要只为隐藏主线临时创建一个组织。
- “信仰者”“组织成员”“知晓异常的人”“主动参与仪式的人”是不同状态，不可默认重合。

### 11.5 王国衰败与地方故事

**已确认事实**
- 王国正在衰败，但具体原因尚未定案。
- 王都、禁卫或核心地区仍可能保有强大力量；地方失序不等于整个国家毫无力量。
- “凡人之墓”可以只完成政治权力交替，不要求玩家掌握宇宙真相。

**可独立发展的故事方向（均为候选，不是既定事件）**
- 同一道法令在中央与边地被不同执行；
- 道路、桥梁、驿站或据点因资源和人手问题逐渐失去功能；
- 地方居民、士兵、商人和官员对同一件事有不同解释；
- 某人选择留下、逃走、投靠或拒绝服役，原因来自个人经历；
- 地方冲突可能由利益、误会、制度或偶发事件引发，不必全部追溯到神祇。

这些方向用于建立王国衰败的可见生活，不可直接用来断定衰败根因。

### 11.6 核心 NPC 的个人轨迹与交叉点

- **蜜忒**：日常生活应可信且不被过度曝光；她的重要性应在回看时显现，不由她主动讲解隐藏真相。
- **金正**：利益优先、机会主义，可能帮助、利用或背叛主角；其行动顺序、来源、具体归属与最终命运仍待设计。
- **外来朝圣骑士**：正义感强、真诚、豪迈、容易迷路；是同行于破败世界的人，不是世界观百科全书。姓名、朝圣目的地、所属信仰与最终命运仍待设计。
- 其他候选核心 NPC 与地区 NPC 应先有独立生活、欲望、矛盾和选择，再判断是否需要与世界级线索交叉。

每个角色至少要有一条不依赖隐藏真相也成立的个人动机。若角色的每次出现都在推进古神、外神或结局线，应重新检查其人物是否被工具化。

### 11.7 三结局的知识与行为边界

| 路线 | 玩家理解层级 | 设计方向 | 不可混淆的事实 |
|---|---|---|---|
| 凡人之墓 | 未发现真正世界真相 | 权力、制度、个人利益与局部事件足以支撑政治更替 | 更换统治者不等于理解古神或外神 |
| 永恒乐园 | 知晓全部真相 | 深层证据逐步汇合；后期相关道具/物品可交付给蜜忒，进入相应选择 | 外神仍未真正降临；世界走向意识化与物质形态消失 |
| 烈火天罚 | 探索到部分外神真相并作出相反选择 | 后期相关道具/物品可被使用；流程必须同时保留杀死 100 名教徒与杀死蜜忒的既定条件 | 蜜忒作为媒介被杀，打断正在准备的此次降临；王国覆灭、所有人牺牲；外神未被消灭 |

后期道具的具体身份、来源、获得条件、用途，以及物品选择与击杀条件的先后关系，仍待单独流程设计；不得在此自行补全。

### 11.8 跨线关联与证据强度

- 线与线之间可以互不相干、偶然相交、共享同一历史背景，或存在可验证的因果关系；必须标注具体属于哪一种。
- 相似符号、相似祈祷、相近年代或相似人物性格，都不能单独证明两条线存在联系。
- 可靠关联应有可核对的共同点，例如同一材料编号、可信的人物行程、相互吻合的年代、独特实物特征或明确的行为后果。
- 允许玩家形成错误假设；后续证据应能支持修正，而不是由某个 NPC 突然宣布唯一答案。
- 线索可以错过，隐藏线可以不被所有玩家发现；主线不得要求玩家收集所有隐藏证据才能继续。
- 每条重要线索记录：作者侧事实、留痕者知识、首次合理解释、后续独立印证、可能的错误推断、最晚揭示节点、结局相关性、正史/候选状态。

### 11.9 下一步工作顺序

1. 先核对已有核心 NPC 与世界观文档，避免重复创造或覆盖既有设计。
2. 为金正、外来朝圣骑士及其他已存在角色整理“独立个人故事—公开身份—真实归属（若已确定）—知识边界—可能交叉点”，未定内容继续标记为待设计。
3. 建立少量彼此独立的地区/人物故事样本，再检查它们是否需要与世界级线索交叉。
4. 将古神研究和外神影响保留为低可见度的隐藏深层线，不把神祇名词或直接解释放入早期普通线索。
5. 最后才以 A2/R01 做小规模试点：优先让地点、人物和生活痕迹本身成立，再决定哪些痕迹值得成为可选的隐藏关联。
6. 在事实、人物知识范围和证据链稳定后，才批量写物品描述与场景事件；当前不改场景与代码。
