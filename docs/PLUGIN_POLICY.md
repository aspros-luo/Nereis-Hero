# Nereis-Hero Plugin Policy

## Purpose

Use Godot plugins and community tools where they improve production efficiency without replacing core game design.

## Rules

### Allowed
- Editor productivity tools
- Dialogue authoring tools
- Debug and profiling tools
- Animation and workflow helpers

### Evaluation Required
- Map tools
- Timeline tools
- State machine helpers

### Avoid
- Complete RPG frameworks
- Black-box combat systems
- Plugins that lock core architecture

## Principle

Plugin benefit must exceed maintenance complexity.

Nereis-Hero keeps ownership of:
- combat feel
- player controller
- world state
- lore system
- ending logic
