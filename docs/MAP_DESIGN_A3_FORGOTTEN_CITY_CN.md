# 地图空间设计批次 M1-A：废弃城区 A3（中文）

> 状态：A3 屋顶平台、第三街假墙地标与 A1 排水回路已写入共享灰盒脚本；静态审查完成，Godot 实机尚未验收。地图宽 2600、地面 Y=540，主角移动速度 260、跳跃初速度 -520、重力 1400，并有一次额外空中跳跃。任何高差与跨度仍须在 Godot 实机确认。

## 区域目标

A3 不应是一条从左门走到右门的废墟走廊。它应像一座被“删去第三条街”的旧城：玩家先穿过仍然可信的主街，看到不可能成立的街区布局，再从高处俯瞰断裂的城市网格，最后从下水道或隐藏街区的边缘返回主路线。

## 三条路线

- **主路线：旧城门 → 市集断层 → III 街路牌 → 倒塌的市政拱廊 → 战场方向出口。** 主路线必须始终可由地面通行，不得强迫玩家使用尚未稳定的抓钩或 Debug 能力。
- **上层可选路线：市集屋顶 → III 街路牌背面 → 观测阳台。** 让玩家从高处发现路牌正面写着“第三街”，背面却有被凿除的门牌槽；上层路线在中段回落到主街，形成小回路。
- **下层支路：排水格栅 → 可疑旧石墙 → A4 方向下水道门。** 视觉上将新修铁管压在旧石构上，突出“教会设施建立在更古老遗迹之上”。A4 是可选探索，不得取代 A3 的战场方向主出口。
- **跨区替代入口：A1 旧排水通路 → A3 市场外街。** 村庄防卫完成后开放；A3 可从排水门返回 A1，也可继续前往 A2、A4 或 A5。

## 空间节奏与锚点

1. **入口缓冲段（X 约 120–430）**：低矮建筑轮廓、断裂路灯和少量遮挡；给玩家辨识主街，不在出生点附近堆平台或交互物。
2. **市集断层（X 约 430–900）**：一组错层屋顶，先低后高再落回地面。平台之间的水平距离和高度必须按主角实际跳跃能力校准；地面路线保持连续。
3. **III 街路牌（X 约 850–1050）**：现有路牌地标保留并强化为视线中心。路牌前方的街道被完整墙面截断，墙侧留有被封死的拱门痕迹；不要把视觉墙当作可穿越碰撞墙放到主路线中央。
4. **倒塌市政拱廊（X 约 1150–1600）**：用较宽的地面区作为空间呼吸点；上层路线从拱廊边缘绕过，再通过短落差回到主路线。这里可安排第一处安全观察点，不放强制战斗。
5. **排水格栅与旧石墙（X 约 1550–1900）**：支路入口靠近但不覆盖主路线；入口门与主路出口之间保留足够的交互焦点间距，避免返回出生点直接抢焦点。
6. **远端断街（X 约 1900–2380）**：建筑轮廓逐渐错位，地面主路继续可通；远景显示本应相接的两条街道在透视上互相矛盾。主线出口保持在当前出口接线所需的安全区域，不为构图移动既有门坐标。

## 环境叙事物件（先用灰盒绘制，不要求最终美术）

- 路牌正面：III STREET；背面：三道被凿除的门牌槽。
- 两扇朝向街内打开的门，但门后只有完整旧砖墙；不要用碰撞阻挡主路。
- 一段教会新式排水管穿过古老石构，管箍年代明显更新。
- 市政墙上被刮去的地图，留下两条街道的编号，却没有第三条。
- 地面雨痕朝向墙内延伸，终止于无法容纳道路的实体墙面。

## 路线与碰撞约束

- 主线入口、主线出口和 A4 支路必须可由地面路线到达；屋顶路线是奖励而非通关门槛。
- 不新增会覆盖门、共鸣源或主角出生点的实体平台。
- 所有新增平台须同时校验角色胶囊碰撞高度、落地宽度、与相邻平台的实际水平距离；仅凭跳跃公式不能替代实机测试。
- F5 调试覆盖可能生成测试墙与抓钩锚点；验收自然几何时先关闭 F5。
- 回到 A3 的支路出生点不得落在入口门的交互范围内。已有 _spawn_x_for_side 特殊出生点必须保留，除非同时更新拓扑测试。
