## P1 — 前期主线

1. 新游戏入口继续由启动菜单进入 A0 序章。
2. A0 完成守卫遭遇后进入 A1；A1 的村庄防守事件与 A2 入口保持独立的进度门槛。
3. A2 的主路、树冠高路、C03 高位到达平台和返回出生点保留空间合同。
4. 整图实测时不得通过地图测试菜单或直接切场景来替代自然流程；应使用一个全新存档连续推进。

## P2 — 主线、跨区连接和空间合同

1. 以拓扑账本中的 24 条 C 连接作为统一清单，不将地图拆成互不相连的分段验收。

4. 静态报告中列出的区域数、子区域、区域内边和电梯合同，是数据覆盖数，不等于玩家已在引擎内完成通关。

### 运行时预期

1. A8 中的可选入口将进入独立的王墓内殿。
2. 守墓者使用两阶段战斗；阶段二应在生命值降至 120 时切换。
3. 玩家死亡后应回到内殿检查点，守墓者重置；此遭遇不应误写入旧战斗演示使用的全局 Boss 胜利旗标。
4. 击败守墓者后，`defeated_royal_tomb_guardian` 写入持久化成就列表，重新进入/继续存档时不应再次生成守墓者。
5. 胜利后生成回程门，返回 A8 的 `boss_return` 出生侧（x=1700），避开附近门触发区。
6. A8→A9 的主线出口始终可用，不要求先击败守墓者。

## 一次性整图连续验收顺序

这份序列是一条完整的全地图验收，不按 A2→A3 或 A3→A5 分段截断：

1. 清空旧测试进度或建立全新存档，从启动菜单进入 A0。
2. 完成 A0 事件 → A1 村庄 → 村庄防守事件 → A2。
3. 沿自然主路连续通过 A3、A4、A5、A6、A7、A8、A9、A10、A11、A12，最后抵达 A13；每次切图核对日志中的 source、target、spawn_side 与实际出生位置。
4. 在自然推进过程中测试所有可达的 C 边；对标记为双向的连接完成正向和反向返回，验证锁定边在条件未满足时不能进入。
5. 探索 H01–H08 和 11 条局部灵视路线；对每条隐藏路线测试首次开启、离开后重进、反向回程以及存档继续，再返回主线。
6. 在 A8 进入 OB01，分别验证 Boss 阶段一、阶段二、玩家死亡重置、击败后成就持久化、胜利后回程门与 A8 安全出生点。
7. 在休息点保存后退出并使用 Continue；验证场景、出生方向、隐藏路线状态、Boss 胜利状态和剧情旗标一致。
8. 完成 A13 的实际终局路径；逐个验证可达结局条件，不以单次抵达 A13 代替结局验收。
9. 结束时检查没有软锁、无法交互的门、切图后立即重新触发的门、悬空出生点、丢失的存档状态或无法返回主线的支路。
