# Nereis Hero — 探索体验改造方案（中文）

> 状态：设计基线；不是“已经实现”的功能清单。
> 目标：将当前通过静态/自动化验收的灰盒地图，从“可通行的连接集合”升级为具有《空洞骑士》式发现、回访、分层路线与环境叙事的探索地图。
> 范围：A0–A13、H01–H08 与既有 C01–C24；保留主线可通关、隐藏内容可选的原则。

## 1. 当前问题诊断

现有自动化检查主要证明场景、连接、出生点、碰撞与持久化契约成立；这些不能代表探索体验已经成立。当前灰盒实现仍有以下体验缺口：

1. **通行不等于探索**：平台存在，但不少平台只是从一端走向另一端的跳台，尚未形成“主路、支路、上层、下层、回环”各有意义的空间关系。
2. **秘密主要表现为交互点**：灵视异常入口有显现/开启/保存机制，但这不等于玩家能通过环境观察发现墙后空间、假地面、可破坏结构、上下层暗道。
3. **区域奖励密度不足**：当前共享灰盒的拾取布置只覆盖少数区域；大部分区域没有足够的非战斗探索反馈。
4. **缺少远景承诺与回访兑现**：玩家需要先看见一个暂时无法抵达的地点，并在稍后从另一层、能力或捷径抵达它。
5. **环境叙事还没有形成路线**：异常物、铭文与路线没有系统地形成“看到线索—提出猜测—寻找入口—发现空间—获得解释/道具”的闭环。

## 2. 探索设计的硬规则

- 每个主区域至少具备：一条易读主路线、两条有区别的可选路线、一个可观察但暂时不可达的目标、一个能改变玩家对该区域理解的秘密或环境叙事点。
- 每条可选路线必须有明确用途：获得道具/能力线索、开捷径、揭示故事、抵达观景点、提供不同高度/风险/回程路线；不允许只为拉长路程而加平台。
- 每个大型区域至少有一次“先看到结果，之后才知道如何抵达”的空间承诺。
- 每个主区域至少形成一个小回环或层间重新汇合；至少一部分回环在打开门/落桥/启动升降机后才成立。
- 隐藏区域只提供可选的剧情、道具、世界观证据或终局变量；不作为完成主线的硬门槛。
- 不能把所有秘密都做成同一个灵视门。入口表现应由空间语义决定：裂墙、塌陷地面、反向水流、钟声错位、墙后气流、异常投影、可移动机关、可下潜/坠落的路线等。
- 不以“多放敌人”替代探索；敌人关闭时，地图也应该值得探索。
- 不能让所有奖励都直接标出名称或以 HUD 提示答案。优先使用视觉/声音/地形线索；调查提示应克制。
- 主路线可读但不强迫玩家清空支路。隐藏路线必须能被玩家错过，错过后仍能通关。

## 3. 地图空间语法

每个区域设计时明确标注以下路线角色，避免只堆平台：

- **主路**：清晰、连续、可读；首次探索能自然推进。
- **高位路线**：可俯瞰主路、越过障碍或从另一端开门；应有高差与回到主路的出口。
- **低位路线**：坑底、排水道、树根、废墟夹层等；不能只是主路下方的空洞。
- **秘密空间**：入口藏在地形或环境异常里；奖励以故事、独特物品或捷径为主。
- **能力回访点**：玩家先看见但无法抵达；获得移动/感知能力后回访。入口和奖励都要清晰可验证。
- **捷径/环路**：从远端开启，改变地图结构，节省回程；开启前后路线体验必须不同。
- **地标/观景点**：让玩家看见远处的区域、塔、深井或建筑，帮助构建空间记忆。
- **环境叙事点**：用位置、痕迹、建筑关系、遗留物与异常变化传递信息，而不是只放一段说明文本。

## 4. A0–A13 探索目标矩阵

| 区域 | 主要空间体验 | 必须设计的探索内容 |
|---|---|---|
| A0 手术所/逃脱通道 | 从室内到室外的垂直逃脱 | 可回望的封闭手术间、错误方向的通风道、一个不影响逃脱的早期隐秘记录；教学秘密但不把序章变成迷宫 |
| A1 边境村庄 | 作为持续回访的生活型枢纽 | 屋顶/地窖/井口/后院层次；村庄状态变化后重新开放的路线；远处能看见但暂时无法进入的井下结构 |
| A2 雾林/钟墓/朝圣路 | 第一张真正的探索地图 | 地面森林、树冠高路、钟墓坑底、沟壑下层与高桥至少三种路线；先看见的钟墓深处；高路与低路重新汇合；隐藏入口不能只依赖单个显眼交互标记 |
| A3 废弃城区 | 街道与屋顶双层空间 | 第三街缺口、屋顶回环、地面市场/残墙、下水道入口；通过另一端或高度变化重新进入此前看过的街区 |
| A4 下水道/沉积大厅/水库 | 多层水道枢纽 | 上层管道、中层古石廊、低位淹水沟与水库底层；不同高度连接不同区域；可开启的水闸改变可走路线 |
| A5 战场/堡垒 | 横向战场与高墙并行 | 战壕主路、城墙高路、塌陷区域和堡垒内部回路；从高处看见被封闭的战场遗迹 |
| A6 修道院/钟塔 | 建筑内部垂直探索 | 地面回廊、夹层、钟塔外壁与落差捷径；钟声异常是空间线索，不只是门前提示；登塔后可从不同高度返回 |
| A7 监牢/忏悔井/维护竖井 | 牢房迷宫与垂直井道 | 牢房之间的非直线通道、维修栈道、井底与高位出口；至少一个能从另一侧打开的牢门/捷径 |
| A8 王墓/王室地下道 | 地面墓室与上层墓廊交错 | 石棺间通路、上层铭文廊、中层水道、封闭墓室；探索顺序影响玩家如何理解被抹除的王名 |
| A9 王城外环/废弃街区 | 屋顶、街面、排水层三层枢纽 | 屋顶回环、街面安全路线、排水道；从街面看到的倒影/灯光在上层得到解释 |
| A10 大圣堂/内廷 | 正规朝圣路线与侧翼路线并行 | 朝圣阶梯、侧礼拜堂、唱诗席高廊、服务夹层；至少一条路线绕过主厅并从内部打开捷径 |
| A11 古神遗迹/研究区 | 观察、误导与深层结构 | 观测平台、研究设施、早于设施存在的遗迹、可选深层入口；空间本身说明教会是在研究而非创造某物 |
| A12 王室内城/王座区 | 正面大道与侧墙秘密通路 | 王室大道、城墙上层、内廷侧路；可选证据影响终局理解，但不锁死主线 |
| A13 深层梦境/终局异象 | 规则逐渐失效的单向探索 | 视觉上让路线关系变得不可靠，但仍保证可读的前进方向；可选支路揭示终局代价；保留既定终局门槛与无普通回程规则 |

## 5. H01–H08 隐藏区域职责

隐藏区域必须在“发现方式、空间结构、奖励用途”上互不重复：

- **H01 井底回声层**：垂直下潜与分层回程；玩家先发现井深不合理，再寻找下行路径。
- **H02 倒响钟室**：声音先于来源；用声音方向/节奏引导玩家找到错位空间。
- **H03 被删去的第三街**：城区几何缺口；从街牌、屋顶缺口和两侧建筑关系推断入口。
- **H04 水面背后的楼梯**：水面/倒影与真实高差不一致；通过视觉误导发现另一层。
- **H05 无声钟室**：钟塔侧窗与无影区域；利用高位窗、外壁路线与室内回路。
- **H06 王名抹除廊**：王墓中的铭文证据链；空间探索服务于被抹去的历史。
- **H07 镜街**：反向雨水、倒影先行与镜像街道；低位水线和高位灯桥形成双路线。
- **H08 胎宫/原初空腔**：呼吸墙与有机结构；作为可选深层空间，提供世界观与终局证据，不替代主线通关条件。

## 6. 能力门与回访节奏

能力门不能只是“颜色不同的锁”。每个能力门必须在首次出现时展示可理解的阻碍，并让玩家能记住位置。

建议逐步建立以下类别（具体绑定到现有主角能力前先审计 hero.gd 与存档系统）：

1. **跨越类**：远距离跳跃、空中调整或后续移动能力，用于高处断桥/宽沟。
2. **下潜/坠落类**：通过可控落差进入下层，或安全穿越特殊地面。
3. **破障类**：破坏明显脆弱的墙、封板或旧木障；不是所有墙都能破。
4. **感知类**：辨识不可能的影子、反向水流、错误回声或被抹去的建筑边界。
5. **机关类**：拉杆、配重、升降平台、排水闸改变区域状态。

每种类别首次出现时，都应至少提供一个无需新能力也能理解的安全示例；真正的回访点在更远处重复该视觉语法。不要为探索强行增加五套新能力，优先复用已经实现的能力和交互系统。

## 7. 发现闭环与奖励标准

每个探索支路必须完整回答：

1. **线索**：玩家通过视线、声音、地形、环境痕迹或物品关系注意到异常。
2. **猜测**：玩家能提出合理假设（“上面应该有路”“这面墙后有空间”“井不可能只有这么深”）。
3. **尝试**：玩家能试跳、绕行、调查或使用已学能力；失败不应无提示地浪费大量时间。
4. **发现**：进入新空间、打开回环、改变地形状态或获得新的环境解释。
5. **回报**：至少一种有意义的结果：独特物品、能力线索、永久捷径、世界观证据、终局变量或新的观景/路线认知。
6. **记忆**：入口、回程或地标让玩家之后能够再次定位；已发现/已开启状态必须持久化。

## 8. 实施顺序

### E0 — 探索审计
- 逐区域审计实际生成的碰撞、平台、出口、异常入口、拾取物、地标和上下层关系。
- 将“真实可走路线”和“仅在拓扑/文档中声明的路线”分开。
- 先不加敌人；建立每个区域的主路/支路/回环/回访点清单。

### E1 — A2 垂直切片
- 作为首张探索地图，完成树冠高路、钟墓下层、东部沟壑下穿、高桥回环和一个环境发现秘密。
- 确保玩家可以在不进入隐藏区域的情况下继续主线。
- 通过真实主角移动检查跳跃距离、落点、路线可读性和回程。

### E2 — A1/A3/A4 枢纽与回访
- A1 作为可重复返回的村庄，必须有状态变化和可逐步进入的空间。
- A3 完成街面/屋顶/下水道层；A4 完成三层水道与水闸变化。
- 让 C24、C05、C06 等连接真正改变探索路线，而不只是场景切换。

### E3 — 其余主区域按空间语法铺开
- 先建空间，再放奖励与环境叙事；最后才放敌人。
- 每完成一个区域，都用主角完整走一遍入口到出口及所有可选回路。

### E4 — 隐藏区域与终局变量
- 每个 H 区有独特发现方式与独立奖励职责。
- 验证隐藏区域完全可选，且探索记录持久化、回程正确。

## 9. 验收指标（不是单纯统计平台数）

- 每个主区域至少 3 条有意义的路线选择（主路 + 至少两种可选路径/层）。
- 每个主区域至少 1 个可见的暂不可达目标或远景承诺。
- 每个大型枢纽至少 1 个打开后明显改变回程的捷径/回环。
- 每个隐藏区域至少 1 个与其他隐藏区域不同的发现语法。
- 每个支路至少有一个可说明的奖励用途；禁止纯粹为延长通行时间而新增路线。
- 玩家在没有敌人压力时，也能通过观察、移动、回访和发现完成一段有趣的探索。
- 静态/自动化验收之外，必须有人工全程路线验收；不能用平台数或连接数替代。

## 10. 下一步执行要求

先以 A2 为探索垂直切片，但不能只修 A2 的单个房间：A2 的布局要为后续能力回访、与 A3/A5 的高位连接、钟墓低层和东部沟壑下层提供完整空间样板。完成后再把成熟的空间语法复制到其他区域，而不是重复复制同一组跳台。
