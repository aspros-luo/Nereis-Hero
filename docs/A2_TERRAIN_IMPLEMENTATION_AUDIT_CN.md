- 本轮不生成敌人；等地形和移动路线验收后再布置遭遇。

## 当前尚未证明的事项

代码与静态检查不能证明实际跳跃距离、角色碰撞边界、镜头手感、坑底返回成功率或场景切换无软锁。必须在 Godot 4.6.1 中验收以下路线：

1. 从 A1 进入 A2，再原路返回 A1。
2. 沿地面到钟墓塌陷，落入坑底，在坑底休整点激活后，从东侧台阶回到地表。
3. 从地表进入树冠高路，抵达 C03 出口并进入 A3；再从 A3 返回 A2，确认出生在高位承托平台。
4. 从 A5 开启 C04 后进入 A2，确认出生于旧朝圣高路；再回到 A5。
5. 探索可选平台与钟墓分层区域，确认不存在无支撑出生、卡墙或无法返回的软锁。
6. 确认 A2 未生成敌人，且地形调试标记不会替代真实碰撞和可交互出口。
