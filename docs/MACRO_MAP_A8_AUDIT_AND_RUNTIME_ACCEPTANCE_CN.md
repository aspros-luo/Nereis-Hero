## 1. 宏观地图基线

## 2. A8 已接线内容

- 22 个已配置的平台矩形，包含多层墓廊和西侧高位落脚点。
- C13：A7 维护竖井 ↔ A8 王墓入口平台，高位双向连接。
- C14：A8 王墓 ↔ A9 外环地面主门，双向；可选 Boss 不会关闭该主线出口。
- C07：A8 侧开启的中层水道回环；A4 的低位 C12 与高位 C23 保持不同路线层。
- C15：A8 → A11 的独立灵视 / 鸣响 / 古神接触 / 异常来源门槛。
- H06：独立的王名抹除廊入口，不与 C15 共用状态。
- 可选 Boss 内殿：`scenes/royal_tomb_boss.tscn` / `scripts/levels/royal_tomb_boss.gd`。A8 x=1540 入口仅在专属胜利旗标不存在时生成；胜利记录 `defeated_royal_tomb_guardian`，回程使用 A8 的 `boss_return` 出生侧 x=1700。
- Boss 场景独立管理战斗、两阶段 HUD、死亡后遭遇重置、胜利后返回门；Continue 能恢复 `royal_tomb_boss` 场景。
- Boss 不修改 C13/C14/C07/C15，不提供结局必需事实，也不把 H09 临时候选遗物接入结局条件。
- `tools/validate_graybox_scene_wiring.py` 现检查 Boss 场景存在、A8 可选门、主线 C14 仍开放、胜利旗标、死亡重置、回程出生点和 Continue 映射。
