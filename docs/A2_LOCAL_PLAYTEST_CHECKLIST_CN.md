# A2 雾林与钟墓：本地实机验收清单

> **架构状态已过期（2026-10-24）：** 本清单中的“六个房间是同一张 A2 大地图的装配组件，不应要求玩家在这些场景边界切图”等指引已被当前设计基线取代。当前目标要求 A1 进入 R01，房间之间存在真实转场。此文件仅可作为地形碰撞观察项的历史参考；开始新验收前请以 docs/maps/A2_DESIGN_BASELINE_CN.md 为准。


> 目标：在 Godot 4.6.1 中验证 A2 六个手工节点场景组成的连续地图。此清单是待执行的实机检查，不代表已在云端或本地运行通过。

## 0. 开始前

- [ ] 拉取 `feature/story-map-progression` 最新提交。
- [ ] 使用 Godot 4.6.1 打开项目，等待资源导入结束。
- [ ] 运行项目主入口，不要直接把某个 A2 房间当作独立关卡启动。
- [ ] 如果项目启动报错，先记录第一条 parser/resource 错误和对应文件行号，不要继续测试后续路线。

## 1. 从村庄进入 A2

1. 从 A1 正常推进到村庄防守完成，按正式路线前往北门。
2. 进入 A2 后确认主角落在西侧地面，而不是半空、地板下方或门触发区里。
3. 沿地面走到树根岔路，检查主角与碰撞、平台视觉是否一致。
4. 确认休整点“旧朝圣圣龛”位于连续地面上；站稳后按 E，确认生命/体力恢复和存档提示。跳跃时或离开平台时不应触发休整。

**通过标准：** A1 → A2 正常转场；主角落地可控；没有重复转场、出生点卡门或地面悬空。

## 2. 六个场景的节点地形

按路线逐段检查；六个房间是同一张 A2 大地图的装配组件，不应要求玩家在这些场景边界切图。

- [ ] **R01 林间入口与树根岔路：** 起步地形、树根台阶、树冠支路的碰撞和可见石面重合。
- [ ] **R02 树冠与断裂桥：** 上下层之间能正常跳跃；落地后不会穿过平台或卡在石面边缘。
- [ ] **R03 钟墓上层：** 能从地表进入钟墓上环；上环与相邻路线有实际落脚点，不是只能看见却无法到达的装饰。
- [ ] **R04 钟墓坑底：** 从坑口中间落下时能通过回程石沿之间的开口到达坑底；坑底有实体承托；能利用错层台阶返回地表。
- [ ] **R05 旧朝圣高路：** 高路连续可走；C04 门在对应高台附近，不应在未开启时出现可用的跨区捷径。
- [ ] **R06 东侧沟壑：** 低位路线与树冠高路能区分；C03 远端落点有实际平台承托，跨越沟壑后没有落在地面碰撞下方。

**重点观察：** 跳上平台后停留 2–3 秒，确认不会缓慢下沉；从平台边缘走下/跳下，确认碰撞不会把角色弹飞或夹住。

## 3. C03 树冠主路线（A2 ↔ A3）

1. 沿树冠高路走到 A2 东侧出口。
2. 通过 C03 进入 A3，确认出生在西侧高位平台，不在门触发区内。
3. 从 A3 原路返回 A2。
4. 确认回到 A2 东侧高位落点，主角脚底与平台顶面齐平，并且能立即继续移动。

**通过标准：** 双向转场各执行一次；无连续自动触发、落地穿模或必须反向跳回门口的情况。

## 4. C04 旧朝圣高路捷径

C04 依赖正式流程解锁。如果当前存档尚未开启，请先按正常流程从 A5 开启，不要直接改世界状态来代替第一次验收。

- [ ] A5 开启 C04 后返回 A2，确认 A2 侧门出现且状态持久。
- [ ] 从 A2 进入 A5，确认 A5 落在对应高台。
- [ ] 从 A5 返回 A2，确认落点位于旧朝圣高路平台，远离门触发区。
- [ ] 关闭并重新启动游戏/读取存档，再确认已开启的 C04 状态仍保留。

## 5. 休整点、死亡与复位

死亡恢复由区域控制器统一拥有；主角脚本不应同时启动第二套死亡淡出/传送。

1. 在旧朝圣圣龛处站稳并按 E，确认休整点成功记录当前坐标。
2. 临时启用 A2 的遭遇测试（仅在本地 Inspector 临时修改，不要提交此临时设置），让敌人击败主角。
3. 观察死亡过程：延迟期间输入应锁定，主角不应操作、连续重生或切换到别的区域。
4. 复位后确认主角回到本区域最近一次休整点，生命/体力恢复，角色状态恢复可操作。
5. 再次走动并复位，确认检查点坐标没有被旧场景或死亡前的空中位置覆盖。
6. 测完后恢复遭遇开关原值，避免把战斗重新加入尚未验收完成的灰盒地图。

**通过标准：** 一次死亡只发生一次复位；不会出现双重淡入淡出、复位后角色仍处于 DEAD 状态、输入永久锁定或回到其他区域坐标。

## 6. 返回与回环

- [ ] 从 A2 返回 A1，确认出生点在村庄北门附近但不与门/POI 交互区重叠。
- [ ] 再从 A1 进入 A2，确认进入侧被正确重置，不沿用上次离开时的错误方向。
- [ ] 至少完成一条“地表 → 树冠 → C03 → 返回 A2 → 钟墓坑底 → 回到地表”的连续探索路线。
- [ ] 确认探索钟墓或死亡后，C03/C04 的解锁状态和休整点状态没有被意外清空。
