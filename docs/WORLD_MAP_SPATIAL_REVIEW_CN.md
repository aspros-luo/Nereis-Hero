# 宏观地图空间布局与连接审查（第二轮）

> 状态：宏观结构评审稿 v2。本文是设计数据审查，不代表 Godot 实机验收。目标是在进入小地图与剧情设计前，明确相对方位、垂直层次、枢纽职责，以及 C01–C24 的连接合同。

## 1. 本轮裁定

**保留现有 14 个宏观区域、24 条跨区连接，不因 A3 的原始连接度高就删除连接。** 静态连接数不等于玩家体验：A3 的多条连接是后期开启的捷径；它应教会玩家理解多层城区，而不是强迫所有旅行都经过城区。

- A3 是高连接度的早中期枢纽，但不是早期万能枢纽。C10、C16、C24 都有明确解锁条件，首次抵达时应保持关闭。
- A4 是受门槛控制的地下交汇点。首次从 A3 进入后，必须能在 A4 内打开检查闸/检修口返回；C05 的初始单向状态不能造成软锁。
- A8 负责王室历史、垂直墓道与地下交通；A9 负责后期地表导航、王城封锁和屋顶/排水路线。C07 与 C23 位于不同高度，不得合并成抽象的地下传送门。
- A11 是叙事深层，不是交通枢纽。两个入口分别来自王室维护体系与教会静默侧礼拜堂；进入时应控制信息释放节奏。
- A13 保持终局单向入口。C21、C22 不得变成普通快捷旅行环路。
- 本轮不新增能力锁。钩爪只是讨论例子，不是地图需求；新能力必须等宏观地图稳定后再决定。

### 方位解释

- **西北地表：A1、A2。** 村庄是情感与补给锚点；雾林、钟墓和旧朝圣路构成自然地形的高低层。林冠、断桥或高路应能框出城区/堡垒的远景轮廓。
- **西侧至中央：A5、A3。** A5 以城墙、战壕和高位堡垒表现边境战争；A3 是路线认知中心，不是必须占据世界几何中心的坐标。
- **中央地下：A4。** A4 应位于 A3 下方并向王室方向延展。入口、检修平台、水位与闸门要呈现可信高差。
- **南部势力纵深：A6、A7、A10。** 从修道院公开仪式，经拘押与维护设施，逐步接近大圣堂权力中心；A10 可在视觉上高于 A9 部分屋顶，但不必形成笔直走廊。
- **东部：A8、A9、A12。** A8 是王室墓地/地下交通节点；A9 是地表外环；A12 是内城与王座终点。地面、屋顶和地下层必须互相解释。
- **跨区域深层：A11、A13。** A11 的人类实验层贴近王室维护井与教会设施；越深入古神遗迹，空间逻辑越不稳定。A13 是终局层，不占普通地表方位。

方位允许整体旋转或拉伸，但水道不能在视觉上无故逆坡，维护井不能跨越没有解释的远距离，邻区可见地标也不能互相矛盾。

### 连接审查结论

- **没有必须删除的宏观连接。** 主要风险在开放顺序、空间高度与玩家认知，不在边数本身。
- C05 是关键软锁风险：初始从 A3 单向进入 A4，必须能在 A4 内操作检查闸，才形成回程。
- C07、C12、C23 是三条功能不同的地下路线，需以高度、材质、流向和落点区分。
- C03、C09、C10、C16、C17 共同建立高处路线语言，但入口和回程落点不可挤在同一平面位置。
- C15/C19 是 A11 的两个秘密入口。它们允许玩家从不同势力设施进入同一深层，但信息揭露要受控。
- C21/C22 是终局入口，不是普通双向捷径。

**本轮不削减 A3 连接。** 后续地图图例应区分：初始开放、抵达另一侧后可开启、结局/状态门控。只看最终拓扑会高估玩家早期可自由到达的范围。

## 5. 分层拓扑一致性

现有设计数据包含 76 个小区域、71 条区域内连接和 8 部升降机合同。数量齐全不代表可玩路线完成。进入小地图前需满足：

1. 每条跨区连接都映射到明确的源小区域和目标小区域。
2. 每部升降机两端都是已存在的小区域，并对应一条解锁条件一致的区域内升降机连接。
3. 升降机改善垂直回环，不得成为唯一主线出口；锁定时仍有可理解的推进路径。
4. 每条单向连接注明是否可从目标端返回、是否有替代路线以及开放时机。
5. 隐藏区域二次出口遵守“目标区域已到达”的合同，不能凭空开放未知区域。
6. 数据校验只证明结构合同自洽；碰撞、跳跃距离、摄像机边界、死亡恢复、存档与场景切换仍需 Godot 实机验证。
