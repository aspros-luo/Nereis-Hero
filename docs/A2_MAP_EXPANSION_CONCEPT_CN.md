# A2 地图扩展概念方案（待空间审计与落地）

> 状态：空间结构提案，不代表已经修改 Godot 场景或通过运行时验收。  
> 原则：先扩地图拓扑与可探索空间，再安排敌人、物品、线索和机关。A2 → A3、A2 → A5、A2 → H2 三个既有方向全部保留。

## 1. 设计目标

A2 不应是从左到右的一段长走廊，而应是具有多个空间层、分叉、回环和垂直连接的中型探索区域。玩家进入后逐渐建立空间认知，并能选择先探索哪个分区；三个出口分别服务不同探索方向，而不是挤在同一条主路末端。

本方案不规定钟声、旧朝圣者或教会历史的最终真相，相关叙事留待剧情设计确认。

## 2. 推荐的空间结构

将现有五个子区域扩展为至少七个有明确空间职责的分区。以下是逻辑结构示意，不是按比例的地形图：

```text
                         [A5 旧朝圣高路]
                               |
                       (C04 远端解锁捷径)
                               |
             [S05 旧朝圣高路 / 高层西支]
                       /               \
             [S06 倒塌钟楼外壁]----[S04 树冠栈道]----(C03)----[A3]
                    |                    |   \
                    |                    |   [SC011 共鸣桥]
                    |                    |
入口 / [S01 雾林地面]----[S02 钟墓外圈]---+
          |                 |
          |              [S03 钟墓坑底]
          |                 |
          +----[S07 林下回廊]----[H02 倒响钟室]
```

上图表达的是空间关系：地面、坑底、树冠、高路和林下回廊应当相互可辨认，并通过有限的楼梯、落差、攀跳平台或门相连。不是要求每条线都变成平地直通路，也不要求 H02 成为主线必经点。

## 3. 三个连接方向的职责

### A2 → A3：东侧高层出口（C03）

- 保留树冠高路作为主要前进方向，但不要让玩家从入口一眼就能沿一条连续平台直达出口。
- 在到达出口前增加一个空间分叉：继续向东可走 C03；折返或向下可探索钟墓外圈/坑底；更高或更远的支路可通往旧朝圣高路。
- 出口前设置可辨认的地标与安全承托，避免新增垂直路线导致无意坠落或无法返回。
- C03 仍维持原有双向转场语义，实际出生点和碰撞范围需要运行时验证。

### A2 → A5：西北/高层旧朝圣连接（C04）

- 不再把 C04 只当成一扇放在主路末端的门；它应当连接一个独立的高层分区或环路。
- A2 侧可以先看见高路、门或远处结构，但初期不能直接穿过；从 A5 侧解锁后，形成回到 A2 的快捷环路。
- 该高路应与树冠层在空间上有局部交叠或视觉联系，但不能仅靠视觉重叠就让玩家越过锁门、绕过门或从地面误入。
- 高路需有至少一个值得探索的支路或观察点；不以堆放普通道具作为唯一内容。

### A2 → H2：地下/林下隐藏分支

- 保留 H02 作为可选隐藏区域，不提高为主线硬门槛。
- H02 入口不必位于路线最右端；可以从钟墓坑底、林下回廊或钟墓外圈的侧壁进入，让玩家通过环境线索发现入口。
- H02 的条件（共鸣值、Resonance Sight、开启后回返）保持既有设计意图；若现有实现条件不同，先核对代码再决定是否调整。
- H02 应带来独立的探索回报，例如一段可选叙事、影响后续结局的证据或独特物品；具体内容不在本空间方案中擅自定稿。
- 隐藏路线必须有明确返回路径或可解释的单向出口，不能把玩家困在坑底或转场触发区。

## 4. 七个分区的空间职责

| 分区 | 空间职责 | 玩家应做的决定 |
|---|---|---|
| S01 雾林地面 | 入口、初步方向辨识、地面路线 | 先走地面还是尝试向上 |
| S02 钟墓外圈 | 环绕钟墓的中层路径，与树冠/坑底形成交叉视线 | 绕行、攀高或下探 |
| S03 钟墓坑底 | 垂直落差与可返回的风险支路 | 是否下落、如何安全返回 |
| S04 树冠栈道 | 主推进路线，但不是唯一可探索路线 | 继续前往 A3，还是折返探索分支 |
| S05 旧朝圣高路 | 通向 C04/A5 的高层环路与后期开捷径 | 记住被锁路线，之后从另一侧开启 |
| S06 倒塌钟楼外壁 | 连接高路与树冠层的垂直中继空间 | 选择上层路线或回到中层 |
| S07 林下回廊 | 将地面、坑底与 H02 隐藏入口连接起来的低层支路 | 是否追踪线索进入隐藏区域 |

以上七区是空间职责，不要求每区都成为独立场景文件；可以在现有 A2 场景中通过平台、墙体、遮挡、门、地形和出生点实现。

## 5. 扩建时必须守住的约束

1. 不删除 C03、C04、H02 的既有连接身份和关键解锁语义。
2. 不把 H02 变成通关 A2 或前往 A3/A5 的必要条件。
3. 不靠单纯拉长横向距离制造“变大”；必须增加可选路线、垂直空间、回环或可观察到但暂时不可达的路线。
4. 新增路径不得制造无承托坠落、无法跳回、出生点落入门触发器、或从普通地面绕过单向/锁定连接的问题。
5. 现有 A2 的敌人、线索、物品、圣龛和 SC011 先作为可迁移内容，不在空间布局未定前大批新增内容。
6. 保留地图空间与剧情真相的分离：本文件不决定钟声和旧朝圣路线背后的叙事答案。
7. A0–A12 既有总体地图决策不因本方案自动改动；本次只提出 A2 内部扩建及其三个边界连接的空间组织。

## 6. 落地前的审计顺序

1. 从当前 `greybox_world_region.gd` 和 `world_map_topology.json` 提取 A2 全部平台、地形、门、生成点、子区域与触发范围，建立现状坐标图。
2. 在坐标图上标出 S01–S07 的目标边界，以及 C03/C04/H02 的实际入口和出口。
3. 找出需要新增的平台/地面、打通的垂直连接、需要遮挡的直达视线，以及需要保留的锁门。
4. 先改地形与连接，再检查空间验证器；随后用 Godot 实际运行验证跳跃、坠落恢复、门交互、转场和回环。
5. 只有空间路线验收通过后，再为每个分区分配战斗、环境互动、物品和叙事反馈，避免先填内容再因地图重做而返工。
