# 宏观地图美术优化：第一阶段

## 目标

在不改变箱式地图路线、平台碰撞、出口位置、鸣响条件与剧情状态的前提下，先让 A2–A13、H01–H08 的灰盒区域具备可辨识的环境纵深和材质层次。当前阶段采用 Godot 原生绘制，不依赖新贴图或外部插件，便于快速迭代且不引入资源缺失风险。

## 已写入游戏的改动

- 远景轮廓层：根据区域类型绘制树冠／有机骨脊、城市屋顶、堡垒齿墙、哥特尖塔、墓室墙体或水库拱廊。
- 低对比雾带：用区域主色做少量横向雾层，增加前后空间感，不覆盖可站立平台。
- 地面材质：加入断续石板缝、稀疏碎石和地面边缘高光，减少“整条纯色矩形”的灰盒感。
- 轻量动态氛围：新增独立的区域粒子层，尘埃／孢子缓慢漂浮，旧战场灰烬下坠，镜街雨丝向天空回落；粒子布局确定，不引入随机闪烁。
- 终局异象 A13：增加断裂圆环、悬浮阶梯碎片与中央碑体，视觉上与正常城镇／教会建筑脱离。
- 区域色彩：继续沿用区域独立的背景、平台和氛围色，不改变碰撞与可玩几何。
- 静态验证：tools/validate_graybox_scene_wiring.py 已增加对共享环境层调用与方法存在性的检查。

## 美术规则

1. **先保证读图，再增加细节。** 可站立平台顶边与出口互动点必须高于装饰层的视觉优先级。
2. **区域轮廓要服务地理。** 森林以树冠和有机形态为主；城区以屋顶、断墙为主；教会以尖塔、拱券为主；地下空间以厚重墙体、管道或骨脊为主。
3. **灵视不是普通高亮。** 隐藏路径后续应使用更冷、更不自然的轮廓、倒影或错位，而不是把所有可交互物都涂亮。
4. **不改拓扑来解决美术问题。** 平台坐标、出口与出生点、门槛条件在这一阶段保持不动；若美术遮挡影响辨识，应调整绘制顺序或装饰密度。
5. **保持性能可控。** 当前装饰由少量确定性矢量图元组成，不使用每帧随机生成，不引入纹理加载。

## 下一轮美术顺序

1. 用户试玩确认共享轮廓层没有遮挡平台、敌人、出口提示或 HUD。
2. 优先为 A2 雾林、A3 被遗忘城区、A4 旧水库、A6 修道院建立更鲜明的区域剪影语言。
3. 再为 A9 雨中外环、A10 大圣堂、A11 深层研究区、H07 镜街和 H08 原初空腔增加专属的灵视视觉状态。
4. 最后处理主角与敌人的明暗分离、互动提示对比度和环境动画；避免一次性替换全部美术资源。
