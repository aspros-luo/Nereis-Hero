# M1 箱庭灰盒首轮实现记录

## 目标

把箱庭地图原则从文档推进到真实游戏代码：玩家完成村庄防卫后，可以选择不同方向；城区内部有上层支路；下水道既有安全地面路线，也有抬高的管线路线。

## 已写入代码

### A1 村庄 — 旧排水通路

- 文件：`scripts/levels/village_hub.gd`
- 新增 `city_cut` 交互点与排水拱门灰盒。
- 防卫战完成前显示封闭状态；完成后可由该入口进入 A3。
- 使用现有持久成就 `village_defense_survived` 作为开门条件，不新增重复状态。

### A2 雾林 — 树冠路线

- 文件：`scripts/levels/greybox_world_region.gd`
- 新增连续的树冠平台序列，连接原有中段平台并重新落回既有平台。
- 地面路线保留为安全路径；树冠路线是可选的风险 / 速度选择。

### A3 遗忘之城 — 多向连接、屋顶环路与鸣响捷径

- 文件：`scripts/levels/greybox_world_region.gd`、`scripts/world/resonance_local_route.gd`
- 增加 A3 返回 A1 的排水出口与独立出生侧映射。
- 保留 A2 回程、A4 下水道和 A5 战场方向的既有出口。
- 新增可跳跃屋顶平台序列，并强化第三街假墙地标。
- 新增同地图局部路线：鸣响达到 28 且启动灵视时显现一段屋顶桥；靠近后按 E 固定路线，之后在灵视结束、死亡与切图后仍由持久世界状态保留。该路线不切换到隐藏场景，也不绕过主线事件。

### A4 沉积大厅 — 管线栈道

- 文件：`scripts/levels/greybox_world_region.gd`
- 保留地面主路线，增加抬高的平台序列作为可选路线。
- 新路线不是必经跳跃段，不要求玩家放弃安全地面路径。
