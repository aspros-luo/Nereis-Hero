# 主角系统 / Protagonist System

## 核心规则

> **玩家只直接看到 HP 与体力。其他数值全部隐藏。**

正式 HUD 不显示：
- 共鸣 / 鸣响
- 人性
- 记忆
- 蜜忒关系
- 教会倾向
- 古神接触
- 外神接触
- 异常负荷
- 武器等级
- 技能等级
- 路线进度

Boss 战允许显示 Boss HP。

F3 等开发调试界面可以显示内部状态，但这些信息不是正式游戏 UI。

## 共鸣 / 鸣响

“灵视”不再作为正式系统名称。

代码内部使用 `hero_resonance`，中文叙事暂定优先使用 **共鸣**；如果后续整体文本更偏诗性，可以统一替换为 **鸣响**。

它不是：
- SAN
- MP
- 可主动消耗的资源
- 等级
- 技能树

它代表主角的身体、认知与异常力量之间已经发生了多少回应。

主角之所以能够容纳异常力量，并不是因为“学会了魔法”，而是：

> 教会的实验意外让他的身体具备了容纳、理解、改造异常力量的条件。

因此成长循环是：

**探索 → 接触异常 → 身体回应 → 理解痕迹 → 战技异变**

## 三条成长轴

### 能力

回答：

> 我能不能到那里？

二段跳、空中冲刺、墙壁移动、特殊环境适应等能力服务关卡探索。

### 武器

回答：

> 我如何杀死它？

当前只建立两种核心武器：

**长剑**
- 中远距离
- 正面压制
- 空间控制
- 多目标与硬直

**短刃**
- 近身
- 更快
- 空中与背后机会
- 更适合连续位移与收尾

两把武器不是等级关系。不能设计成“短刃就是长剑的低伤高速版”。

### 共鸣

回答：

> 我究竟能看见、理解并影响什么？

共鸣通过世界反馈表达，而不是数值弹窗：
- 看见原本不存在的东西
- 发现伪装后的敌人
- 遗物开始回应
- 原有战技改变
- 武器开始攻击更深层的存在
- 敌人与 NPC 的反应发生变化

## 异变战技

主角先掌握人的技术。

异常接触之后，人的技术开始变形。

例如：

**拔刀斩 → 血色拔刀斩 → 深渊拔刀斩 → 未知形态**

玩家看不到技能树，也不会看到“共鸣 +10”。

玩家只会通过动作、声音、敌人反应发现：

> “这已经不是原来的拔刀斩。”

### 血色拔刀斩

森林异变、异端仪式、古神痕迹等共同构成理解条件。

它可以：
- 几乎取消蓄力
- 扩大斩击范围
- 提高破坏力
- 产生血色异常表现
- 以生命 / 体力 / 异常负荷承担代价

### 深渊拔刀斩

更深的路线和接触才能理解。

它可以：
- 斩开现实层
- 命中隐藏实体
- 产生空间撕裂
- 对普通敌人产生无法解释的附带效果

它不是“血色拔刀斩 + 20%”。

系统先决定**形态**，再决定动作、代价和效果。

## 隐藏状态

内部允许存在：

- `hero_resonance`
- `hero_humanity`
- `ancient_exposure`
- `outer_exposure`
- 特殊遗物事实
- 蜜忒关系事实
- 路线事实
- `abnormal_load`

这些变量只服务系统和存档。

## 反对意见与解决方案

### 反对：全部隐藏会不会让玩家完全不知道自己成长了？

会，如果成长只发生在后台。

所以规则是：

> **隐藏数值，不隐藏结果。**

例如：
- 以前无法触碰的祭坛突然回应；
- 以前只有空气的角落出现轮廓；
- 拔刀斩动作突然缩短；
- 某个 Boss 开始对武器产生异常反应；
- 玩家进入一处区域时，远处出现过去没有的建筑。

玩家不需要知道“共鸣 42”，但必须知道：

> “我和这个世界的关系已经变了。”

### 反对：同一个技能因隐藏条件变化，玩家会不会不知道为什么？

因此每一次重要异变都需要至少一个**可观察前兆**。

玩家可以在之前的探索中看到：
- 同类血迹
- 同一声音
- 同一种符号
- 同一种敌人行为
- 同一类遗物反应

真正获得战技时只是完成理解，而不是随机抽奖。

## 当前实现边界

第一阶段只建立：
1. 双武器运行时状态；
2. 隐藏共鸣；
3. 古神 / 外神接触；
4. 人性读取；
5. 异常负荷；
6. 异变战技条件判断；
7. 战技形态记录；
8. 正式 HUD 只保留 HP / 体力；
9. 不引入 SAN；
10. 不引入技能树。

后续再做具体战技和探索能力。

## 不做的事情

- 不做 SAN 条
- 不做共鸣条
- 不做数值飘字
- 不做“升级获得技能”
- 不做传统元素附魔表
- 不做武器耐久维修税
- 不做可见恋爱值
- 不做路线百分比


## 当前实现 / Current implementation

### 武器动作

- **长剑**：3 段连击，起手较慢、范围更大，第三击是明显的重击收尾。
- **短刃**：4 段连击，起手快、贴身命中范围较小，单击伤害较低，但整套连击更快、体力开销略低，第四击有独立收尾表现。
- 切换键：Q。攻击、闪避、受击期间不允许切换，避免动作状态中途换武器导致判定错乱。
- 命中框尺寸随武器与连击段变化，不再让短刃沿用长剑的大范围命中框。

### 第一项异变战技：血色拔刀斩

- 触发条件：古神残留觉醒时记录隐藏的共鸣与古神接触；条件满足后自动理解该战技。
- 按键：L。
- 代价：8 HP、26 体力，并增加隐藏异常负荷。
- 表现：红色长距离斩击与更强的命中反馈。
- 它不是 MP 消耗，也不显示异常负荷数值。当前版本记录异常负荷，但尚未为异常负荷添加持续惩罚或崩溃阈值；后续应通过可观察的武器/动作反馈逐步设计，而不是突然弹出数值条。

### 正式 HUD 与调试

- 正式 HUD 只显示生命与体力；Boss 战可额外显示 Boss 生命。
- 人性条及其背景均隐藏，状态面板缩短，避免留下一块空白区域。
- 调试面板默认关闭，只能通过 F3 显示；内部隐藏数值仍可在调试模式查看。
- 操作提示包含 Q 武器切换与 L 拔刀战技（习得后）。
