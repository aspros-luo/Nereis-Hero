# Nereis Hero — Protagonist System / 主角系统

## 设计结论

主角系统遵循一个核心原则：

> **玩家只直接看到生命与体力。其他成长数值全部隐藏。**

The player should not see Resonance, Humanity, memory, relationship progress, ancient-god exposure, Outer-God exposure, abnormal load, weapon level, or technique requirements as numeric UI.

玩家通过以下反馈理解成长：
- 世界中原本看不见的东西开始出现。
- 原本无法理解的遗物产生反应。
- 已掌握的战技在特定条件下发生异变。
- 武器动作、攻击距离、风险和声音发生变化。
- NPC、环境、敌人和 Boss 对主角的反应改变。
- 同一个基础战技在不同路线中可能产生不同形态。

## 共鸣 / 鸣响

暂定系统名：
- **共鸣**：强调主角身体与异常力量发生同步。
- **鸣响**：更诗意、更贴近《蜜忒之歌》的世界观。

当前代码内部统一使用 hero_resonance，玩家界面不显示该值。

共鸣不是：
- MP
- SAN
- Insight 等级
- 可以主动消耗的资源
- 技能树等级

它代表主角与非人力量之间已经发生了多少程度的“回应”。

主角不是突然学会魔法。

> **教会的实验让他的身体具备了容纳、理解、改造异常力量的条件。**

因此，玩家看到的不是“升级获得技能”，而是：

探索 → 接触异常 → 身体回应 → 理解痕迹 → 战技异变

## 三条成长轴

### 1. 能力
改变“我能去哪里”。

例如：
- 二段跳
- 空中冲刺
- 墙壁移动
- 特殊攀爬
- 更深区域的环境适应

能力主要服务探索与关卡结构。

### 2. 武器
改变“我怎么杀”。

当前核心武器控制在两种：

**长剑**
- 更远攻击距离
- 更好的空间控制
- 更强的正面压制
- 更适合多目标与硬直

**短刃**
- 更快
- 更贴身
- 更适合空中、背后与机会攻击
- 单次攻击威力不应简单超过长剑

两把武器不是“弱武器 → 强武器”的升级关系，而是解决不同战斗问题。

当前切换键暂定 Q，后续根据完整战斗手感调整。

### 3. 共鸣
改变“我能看见并影响什么”。

共鸣不显示数字。

它通过世界和战技反馈表达：
- 隐藏实体显形
- 伪装被剥离
- 遗物产生回应
- 原有战技出现非人形态
- 某些敌人开始对主角产生特殊反应
- 武器可以攻击更深层的存在

## 异变战技

异变战技不是传统技能树。

主角首先掌握的是**人的技术**，然后技术在异常接触下发生变化。

例如：

拔刀斩 → 血色拔刀斩 → 深渊拔刀斩 → 未知形态

玩家不会看到这条树。

玩家只会发现：

> “我的拔刀斩好像已经不是原来的拔刀斩了。”

### 血色拔刀斩

基础条件来自：
- 森林异变
- 古神/异端仪式痕迹
- 主角已经产生一定程度的共鸣

效果方向：
- 缩短或取消传统蓄力
- 攻击范围扩大
- 伤害提高
- 产生血色异常表现
- 使用代价转移到生命、体力或异常负荷

它不是单纯“攻击力 +20”。

### 深渊拔刀斩

更深路线才可能理解。

可能要求：
- 更高共鸣
- 更深的外神接触
- 特定遗物/事件
- 更低的人性状态

效果可以进一步改变：
- 斩击穿透现实层
- 攻击隐藏目标
- 形成空间撕裂
- 对普通敌人产生无法解释的附带效果

## 隐藏条件

内部允许存在：
- hero_resonance
- hero_humanity
- ancient_exposure
- outer_exposure
- 特殊遗物数量/类型
- 蜜忒关系事实
- 路线事实

但是这些都不进入正常 HUD。

它们共同决定：

> **主角最终理解了什么，以及同一个战技最终变成什么。**

不要使用简单的伤害公开公式，例如：

伤害 = 基础伤害 + 共鸣 × 10

系统应该先决定“异变形态”，再决定该形态的动作、代价、效果。

## 异常负荷

暂定使用 abnormal_load 表示非人力量对主角身体的压力。

它不采用传统武器耐久度设计。

正常武器不会因为普通攻击而损坏。

异常战技可能让：
- 武器出现裂纹
- 手臂出现异常纹路
- 攻击产生不稳定声音
- 某些异常战技暂时无法使用

后续是否让异常负荷形成可恢复的战斗资源，需要在完整战斗系统测试后决定。

## 路线差异

同一个基础战技可以因为路线不同而产生不同结果。

### 凡人之墓
- 人性保持较高
- 异常接触较少
- 蜜忒关系较浅
- 可以获得较浅层的血色拔刀斩
- 无法进入更深的外神相关区域

### 永恒乐园
- 与蜜忒发生深度联系
- 外神接触极深
- 主角成为容器
- 可以理解更深层的异常力量

### 烈火天罚
- 发生肉体结合
- 但主角没有完全被控制
- 异常力量与人性发生剧烈冲突
- 可以出现非常强的混合型异变战技
- 代价也显著提高

因此路线不是：

好结局 = 好技能 / 坏结局 = 坏技能

而是：

> **不同的人生选择，会让同一个人变成不同的“武器”。**

## UI 原则

正常游戏界面只保留：
- HP
- 体力
- Boss HP（Boss 战需要）

隐藏：
- 共鸣
- 人性
- 记忆
- 蜜忒关系
- 教会倾向
- 外神接触
- 古神接触
- 异常负荷
- 技能等级
- 技能数值
- 路线进度

F3 等开发调试界面可以继续显示内部状态，但不能被当成正式游戏 UI。

## 当前代码基础

HeroSystem 已作为 Hero 的运行时子系统加入：
- 双武器状态
- 隐藏共鸣
- 古神/外神接触
- 人性读取
- 异常负荷
- 异变战技条件判断
- 技能形态记录

WorldState 负责持久化这些隐藏状态。

后续战斗系统将在这个基础上继续扩展，而不是重新建立另一套成长系统。
