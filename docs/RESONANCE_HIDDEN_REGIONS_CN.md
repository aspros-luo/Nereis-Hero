# 鸣响 / 灵视隐藏地图设计（中文）

> 版本：Resonance Hidden Regions Draft 0.1  
> 分支：development  
> 状态：地图与交互设计；尚未接入正式关卡。  
> 设计目标：玩家在鸣响较高、主动激活灵视并留意环境异常时，能够重新探索已去过的地图，发现此前不可见的空间并将其永久开启。  
> 关联文档：[完整世界地图区划](./COMPLETE_WORLD_MAP_ATLAS_CN.md)、[世界地图静态验证报告](./WORLD_MAP_VALIDATION_REPORT_CN.md)。

## 1. 核心设计：同一张地图，第二层现实

隐藏地图不应是地图菜单里直接显示的“可选关卡”。它们附着在玩家已经走过的区域里：一堵看似普通的墙、一个没有回声的钟室、一面映出不存在楼梯的水面，或者一道影子与实体方向相反的门。

玩家第一次经过时，可以注意到异常，但无法立即确定它意味着什么。之后鸣响增长、学会并激活灵视，旧地点会出现新的细节。玩家必须回到那里，用新获得的感知重新审视此前熟悉的环境。

**玩家体验循环：**

1. 留下伏笔：初次经过时，场景就存在不协调的细节，不能等到高鸣响时才凭空生成。
2. 获得能力 / 提高鸣响：主角的 resonance_sight 已属于既有能力体系；hero_resonance 是隐藏的 0–100 鸣响值。
3. 重新经过：灵视激活时，在阈值满足的情况下显现异常轮廓、声音或隐藏路径。
4. 主动确认：玩家靠近显现锚点并按 E 调查 / 共鸣，永久开启入口或把异常路径固定下来。
5. 进入与记录：进入后才在世界地图上留下未命名的特殊标记；地图名称可以由后续探索获得，不立刻公开区域真相。
6. 返回与连接：隐藏地图至少要有一个返回已知区域的安全出口；有些深层隐藏地图会在主线抵达远端后，打开第二出口成为捷径。

这套机制复用既有 hero_resonance、ancient_exposure、outer_exposure、resonance_sight_active 和 resonance_hidden_target.gd，不增加另一项独立的“秘密地图点数”。

## 2. 四种状态必须区分

| 状态 | 玩家能看到什么 | 存档 / 进度行为 |
|---|---|---|
| **留有痕迹** | 背景中有不协调细节，但没有明确交互提示 | 不需要特殊存档 |
| **显现（Reveal）** | 灵视激活且阈值达标时，异常轮廓短暂浮现 | 是临时感知状态，灵视结束后可再次显现 |
| **发现并开启（Discovered / Opened）** | 玩家主动调查后，入口固定开启或显现成可用路径 | 必须永久保存；鸣响下降、死亡或切图都不能重锁 |
| **进入记录（Entered）** | 玩家实际进入隐藏子区后，世界地图留下特殊标记 | 进入状态与开启状态分开保存，方便地图绘制与回访 |

**失败保护：** 当前灵视一次持续 4.5 秒，消耗 10 点体力，冷却 6 秒。不能要求玩家在这 4.5 秒里穿过长距离、完成高难度平台跳跃或解完整谜题。显现窗口内只要求看见异常并接近调查点；错过后可再次激活。成功调查后，入口永久开启。

## 3. 鸣响阈值与接触度

以下数值是**首轮灰盒测试用的暂定值**，不是最终平衡。它们用于定义设计顺序，之后应根据鸣响增长速度与地图首次到达时间校准。

| 层级 | 暂定鸣响值 | 感知变化 | 内容倾向 |
|---|---:|---|---|
| 静默 | 0–11 | 只呈现细微环境伏笔 | 不出现可用交互提示 |
| 初次共鸣 | 12–17 | 可在短促灵视窗口内显现最浅层异常 | 村庄旧井等边境秘密 |
| 回声 | 18–27 | 能分辨异常声源和局部错位结构 | 墓钟、旧礼拜结构 |
| 重影 | 28–41 | 看见被抹去的门、缺失的墙面或另一条街 | 废弃城区、水库 |
| 深鸣 | 42–54 | 异常空间可以稳定显现，接触残留更有意义 | 监牢与制度性封存区域 |
| 逆响 | 55–67 | 熟悉建筑会显出另一种年代 / 结构 | 王墓和王室地下道 |
| 高鸣 | 68–77 | 可辨识与外神影响相关的静默区和非自然影子 | 大圣堂隐藏侧堂 |
| 极鸣 | 78–100 | 观察者、空间边界与记忆不再可靠 | 深层研究区的高危隐藏部分 |

使用额外接触条件时，要按主题使用，而不是让每个隐藏入口都机械地同时要求三项数值：

- ancient_exposure：适用于旧王朝、古代石层、被改造的遗迹。
- outer_exposure：适用于蜜忒、外神影响和空间失真相关的路线。
- hero_resonance：决定主角能否感知异常。
- resonance_sight_active：决定当下是否正在主动观察。

鸣响高并不代表主角理解了真相。灵视只让他看见更多证据；这些证据可能彼此冲突，甚至让同一地点显现互相矛盾的结构。

## 4. 八处隐藏地图

八处隐藏地图分散在已经规划的主要区域中。它们不是额外的八个主线大区，而是对现有地图的深层扩展。前六处以探索、装备、环境叙事和捷径为主；后两处更靠近外神与终局线索。

| ID / 锚点 | 隐藏地图名称 | 测试阈值（鸣响 / 接触） | 初次线索 | 地图与路线价值 |
|---|---|---|---|---|
| H01 / A1 村庄老井 | **井底回声层** | 12 / 古神接触 ≥ 1 | 水井里的滴水声总比水滴落下晚半拍 | 小型垂直地图；深处有通往 A4 的铁门，初次从这侧无法开门 |
| H02 / A2 钟墓 | **倒响钟室** | 18 / 古神接触 ≥ 1 | 墓园的钟声先响，钟锤后动；附近墓碑日期互相矛盾 | 短型调查地图；提供一条钟塔维护路径的早期远景线索 |
| H03 / A3 废弃城区 | **被删去的第三街** | 28 / 古神接触 ≥ 1 | 市场街牌写着第三街，但城区里只有第一街与第二街 | 隐藏的平行街区；另一出口通向 A9 的旧服务门，但该门在 A9 主路线开启前保持锁闭 |
| H04 / A4 旧水库 | **水面背后的楼梯** | 36 / 古神接触 ≥ 1 | 水面反射出一段现实中并不存在的干燥阶梯 | 以水位与反射为核心的小型空间谜题；通向 A8 的门要在王墓侧开启后才能形成捷径 |
| H05 / A7 监牢 | **无号牢房** | 42 / 古神接触 ≥ 1 | 光源照不到的墙面上，出现一扇有门把手的牢门影子 | 监牢的被删改层；提供与隔离区 / 研究运输相关的独立证据 |
| H06 / A8 旧王墓 | **墓室背面** | 55 / 古神接触 ≥ 2 | 墓室浮雕在灵视下显露出与正面完全相反的石刻布局 | 中大型隐藏区；打开王室地下道的替代出口，连回 A9 的已知地标 |
| H07 / A10 大圣堂 | **无声侧堂** | 68 / 外神接触 ≥ 12 | 教会合唱在一处侧廊里完全消失，人物的口型却仍在移动 | 可选高风险路线；揭示仪式空间与深层通道的冲突，提供通往 A11 的替代入口 |
| H08 / A11 深层研究区 | **观察者回廊** | 78 / 古神接触 ≥ 2、外神接触 ≥ 12 | 墙上的观测记录在不同视角下指向不同的观察对象 | 高危隐藏区；汇聚几条相互矛盾的证据，可能通往 A13 的边界，但不直接讲完真相 |

### 规模与内容预算

- H01–H02：约 5–12 分钟的短型秘密，重视早期发现感。
- H03–H05：约 10–20 分钟，至少包括一次探索决策、一个有辨识度的环境机制和一项有意义的奖励 / 证据。
- H06–H08：约 15–25 分钟，可包含危险遭遇、捷径或高价值隐藏叙事。
- 这些时长是内容规划值，不是要求玩家必须停留的时间；同一隐藏区域不应用重复战斗凑时长。

## 6. 八处隐藏地图的制作要求

### H01 — 井底回声层

玩家已经多次经过村庄老井。高鸣响时，井壁上的暗色水迹会构成不可能的台阶轮廓。短暂激活灵视后，玩家靠近井沿的异样砖块并互动，井内隐藏平台固定显现。

- 不要求在灵视的 4.5 秒内走完整段竖井。
- 井底是一小段下行路线与返回平台。
- 通向 A4 的铁门从另一侧开，防止刚到村庄就跳过 A2–A3。
- 第一次进入后，地图只记一枚未命名符号；第二次返回仍可走已开启路径。

### H02 — 倒响钟室

这处区域不是普通墓穴的延伸，而是被两种年代结构夹住的钟室。玩家可从钟墓上层听到先于钟锤动作的钟声。

- 可选，不设为主线条件。
- 入口出现后可以进入小型空间谜题；不要求玩家解读完整墓葬历史。
- 奖励是地方故事证据或装备，而非直接解锁真结局。
- 与 A5 的钟塔路线只在玩家后来抵达 A5 后形成交通连接。

### H03 — 被删去的第三街

城市里有街牌、地图残片或商人称呼“第三街”，但空间中缺失整条街。高鸣响时，屋顶阴影与地面巷道短暂重合，揭示墙体其实存在一条平行的空间层。

- 入口可以在 A3 的旧市场附近。
- 隐藏街区应有独立的上下层关系，而不只是墙后奖励房。
- 接 A9 的服务门被主线状态约束，避免跳过旧战场 / 修道院。
- 这里可以有一组看似互相矛盾的生活痕迹，不能给出完整答案。

### H04 — 水面背后的楼梯

在旧水库里，玩家低鸣响时只看到普通倒影；鸣响达标且主动激活灵视时，反射里出现一段不属于当前水库的楼梯。

- 入口互动后开放一个可重复进入的小型“倒影层”。
- 允许用改变水位、跨越落差或观察反射的方式解谜；不新增主角能力。
- 隐藏层中的王墓侧门早期无法从这一侧开启。
- 真实水位状态和倒影状态必须有明确视觉提示，避免玩家以为是碰撞 bug。

### H05 — 无号牢房

监牢里某些登记编号之间存在缺号。灵视会揭示缺号对应的门影，却不显示谁曾经被关在那里。

- 不以大量重复牢房拉长空间。
- 探索重点是少数有意义的房间、一次路线选择与独立环境证据。
- 出口接入深层研究区维护路，但必须等正常主线已经打开该区域后才可通行。
- 玩家可以完成普通路线而完全不知道这里存在。

### H06 — 墓室背面

旧王墓的浮雕有一个无法从正面解释的反面布局。高鸣响让墙面纹理短暂翻转，露出侧门与另一层墓室。

- 这里负责让王室历史出现裂缝，而不直接揭示全部政治真相。
- 通过后开启 A9 方向的捷径，但不跳过王城主路线的主要门槛。
- 进入与开启状态都需要保存。
- 允许玩家只收获路线和装备，也允许细心玩家从浮雕中推断建筑被改造过。

### H07 — 无声侧堂

教会仪式中的合唱进入侧堂后失去声音，玩家仍然能看见唱诗席在运动。鸣响达到高层且外神接触值足够时，灵视显出一条不在建筑平面上的侧门。

- 这是可选高风险路线，不是必做的“外神知识课”。
- 与 A11 连接的门不应代替 A10 的主线通道；它改变进入角度和信息顺序。
- 同一段教会仪式可以在普通视线和灵视下给出不同证据，但不能让玩家无法判断操作是否成功。

### H08 — 观察者回廊

深层研究区记录了多个互相冲突的观察对象。玩家改变站位时，铭文的方向似乎在追随他。这里是隐藏证据的汇合点，但不能放置一份“世界真相完整说明书”。

- 入口依赖较高鸣响与双重接触值，作为深层可选区域。
- 场景应复用 A11 的古代石层 / 教会结构语汇，但形成不可靠的方向感。
- 返回 A11 的路线始终可靠且可读；异常只影响局部路径与感知。
- 通往 A13 的部分内容需要额外世界状态，不应仅凭鸣响数值跳过结局剧情。

## 7. 发现与存档的工程合同

现有 resonance_hidden_target.gd 已能根据阈值显现目标，但完整隐藏地图还需要持久化状态。进入实现阶段时优先扩展既有 WorldState，而不是添加平行系统。

### 正式接入前必须先打通的能力链

当前源码中，`WorldState.mark_ancient_residue_awakened()` 会将鸣响提高到至少 12、古神接触提高到至少 1，正好接近 H01 的初始阈值；但主线 / 场景调用链中尚未找到 `WorldState.unlock_ability("resonance_sight", ...)` 的常规解锁点，`hero.gd` 在能力未解锁时会拒绝 V 输入。与此同时，`HeroSystem.add_resonance()` 已定义，但在本轮核查的主要场景和 NPC / 交互代码中没有找到正常增量调用。

因此，H01 不能只靠数值表就算“可玩”。实现顺序应先确定一处自然的剧情 / 调查事件来解锁灵视，再接好鸣响与接触成长来源；每个来源都要有稳定 source ID，并保存到 WorldState。H01 通过后才校准后续 H02–H08 的门槛。

建议新增两类记录：

- discovered_hidden_regions：玩家已通过调查固定发现的隐藏区域入口。
- opened_hidden_paths：已经开启的隐藏通路 / 捷径 ID。

可选增加 entered_hidden_regions，用于只在玩家实际进入后才绘制地图标记和揭示区域名称。

每个隐藏入口配置至少包括：

- 唯一 target_id / region_id；
- 所属父区域 ID；
- required_resonance；
- required_ancient_exposure / required_outer_exposure；
- 视觉提示节点与交互位置；
- 成功后需要开启的门 / 路径 ID；
- 反向出口的进程条件；
- 首次发现 / 实际进入时的声音、文本或动画；
- 已发现状态如何存档、读取和复位。

实现时复用已有的输入焦点系统来显示 E 交互，不让附近 NPC 与隐藏入口同时抢占交互焦点。灵视期间只负责感知，调查后再固定开启入口。

## 8. 验收用例

- [ ] 鸣响低于阈值：背景伏笔存在，但没有明确的可用隐藏入口。
- [ ] 鸣响达到阈值但没有激活灵视：入口尚未显现。
- [ ] 灵视激活且条件满足：隐藏目标在短时间窗内出现。
- [ ] 条件不满足：不显现，不出现错误的交互提示。
- [ ] 玩家没有在第一次窗口内调查：再次激活后仍可发现，不产生永久错失。
- [ ] 玩家调查成功：discovered_hidden_regions 持久化。
- [ ] 开启捷径：opened_hidden_paths 持久化。
- [ ] 关闭游戏、重新启动、死亡、切图后，已开启的路不重锁。
- [ ] 从隐藏区出口不会提前跳过必要的世界状态 / 主线门槛。
- [ ] 已有 E 交互系统不会同时给 NPC 和隐藏入口显示两个冲突提示。
- [ ] 高鸣响不会把所有隐藏入口同时自动标在地图上。
- [ ] 普通通关不强制进入 H01–H08；真结局路线也不能只靠高数值而跳过必要故事证据。

## 9. 建议的灰盒顺序

1. 试点 H01：使用现有村庄场景验证灵视 → 发现 → 开启 → 存档 → 回访。
2. 拓扑验证 H02 / H03：确认隐藏区域不会造成从早期地图进入中后期地图的进程破坏。
3. 机关验证 H04：测试水位 / 倒影层切换和返回路径。
4. 状态验证 H05–H06：让隐藏门、侧门和地图标记在死亡 / 切图后保持一致。
5. 叙事验证 H07–H08：检查外神相关路线是否提供线索而非直接解释全部世界真相。
