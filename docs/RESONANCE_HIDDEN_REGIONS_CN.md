# 鸣响 / 灵视隐藏地图设计（中文）

> 版本：Resonance Hidden Regions Draft 0.1  
> 分支：development  
> 状态：H01 与 A2–A4 灰盒已接入代码；尚未在 Godot 4.6.x 实机验收。H02–H08 仍为设计阶段。  
> 设计目标：玩家在鸣响较高、主动激活灵视并留意环境异常时，能够重新探索已去过的地图，发现此前不可见的空间并将其永久开启。  
> 关联文档：[完整世界地图区划](./COMPLETE_WORLD_MAP_ATLAS_CN.md)、[世界地图静态验证报告](./WORLD_MAP_VALIDATION_REPORT_CN.md)。

## 1. 核心设计：同一张地图，第二层现实

隐藏地图不应是地图菜单里直接显示的“可选关卡”。它们附着在玩家已经走过的区域里：一堵看似普通的墙、一个没有回声的钟室、一面映出不存在楼梯的水面，或者一道影子与实体方向相反的门。

玩家第一次经过时，可以注意到异常，但无法立即确定它意味着什么。之后鸣响增长、学会并激活灵视，旧地点会出现新的细节。玩家必须回到那里，用新获得的感知重新审视此前熟悉的环境。

**玩家体验循环：**

1. 留下伏笔：初次经过时，场景就存在不协调的细节，不能等到高鸣响时才凭空生成。
2. 获得能力 / 提高鸣响：主角的 resonance_sight 已属于既有能力体系；hero_resonance 是隐藏的 0–100 鸣响值。
3. 重新经过：灵视激活时，在阈值满足的情况下显现异常轮廓、声音或隐藏路径。
4. 主动确认：玩家靠近显现锚点并按 E 调查 / 共鸣，永久开启入口或把异常路径固定下来。
5. 进入与记录：进入后才在世界地图上留下未命名的特殊标记；地图名称可以由后续探索获得，不立刻公开区域真相。
6. 返回与连接：隐藏地图至少要有一个返回已知区域的安全出口；有些深层隐藏地图会在主线抵达远端后，打开第二出口成为捷径。

这套机制复用既有 hero_resonance、ancient_exposure、outer_exposure、resonance_sight_active 和 resonance_hidden_target.gd，不增加另一项独立的“秘密地图点数”。

## 2. 四种状态必须区分

| 状态 | 玩家能看到什么 | 存档 / 进度行为 |
|---|---|---|
| **留有痕迹** | 背景中有不协调细节，但没有明确交互提示 | 不需要特殊存档 |
| **显现（Reveal）** | 灵视激活且阈值达标时，异常轮廓短暂浮现 | 是临时感知状态，灵视结束后可再次显现 |
| **发现并开启（Discovered / Opened）** | 玩家主动调查后，入口固定开启或显现成可用路径 | 必须永久保存；鸣响下降、死亡或切图都不能重锁 |
| **进入记录（Entered）** | 玩家实际进入隐藏子区后，世界地图留下特殊标记 | 进入状态与开启状态分开保存，方便地图绘制与回访 |

**失败保护：** 当前灵视一次持续 4.5 秒，消耗 10 点体力，冷却 6 秒。不能要求玩家在这 4.5 秒里穿过长距离、完成高难度平台跳跃或解完整谜题。显现窗口内只要求看见异常并接近调查点；错过后可再次激活。成功调查后，入口永久开启。

## 3. 鸣响阈值与接触度

以下数值是**首轮灰盒测试用的暂定值**，不是最终平衡。它们用于定义设计顺序，之后应根据鸣响增长速度与地图首次到达时间校准。

| 层级 | 暂定鸣响值 | 感知变化 | 内容倾向 |
|---|---:|---|---|
| 静默 | 0–11 | 只呈现细微环境伏笔 | 不出现可用交互提示 |
| 初次共鸣 | 12–17 | 可在短促灵视窗口内显现最浅层异常 | 村庄旧井等边境秘密 |
| 回声 | 18–27 | 能分辨异常声源和局部错位结构 | 墓钟、旧礼拜结构 |
| 重影 | 28–41 | 看见被抹去的门、缺失的墙面或另一条街 | 废弃城区、水库 |
| 深鸣 | 42–54 | 异常空间可以稳定显现，接触残留更有意义 | 监牢与制度性封存区域 |
| 逆响 | 55–67 | 熟悉建筑会显出另一种年代 / 结构 | 王墓和王室地下道 |
| 高鸣 | 68–77 | 可辨识与外神影响相关的静默区和非自然影子 | 王城外环的镜街异象 |
| 极鸣 | 78–100 | 观察者、空间边界与记忆不再可靠 | 深层研究区的高危隐藏部分 |

### 3.1 正常流程的鸣响来源合同（规划值，尚未接入运行时）

源码审查后，A2–A4 灰盒已接入 R01–R04 的一次性异常调查组件。R01 会通过现有能力解锁 API 开启 `resonance_sight`；R02–R04 将鸣响提升到各自的目标下限。R05–R08 仍是用于后续区域的**设计合同**，尚未接入运行时。所有来源使用固定 source ID，防止重复奖励。

| 来源 ID | 发生地点 / 事件 | 鸣响变化 | 接触变化 / 解锁 | 支持的门槛 |
|---|---|---:|---|---|
| R01 `anomaly_bell_retiming` | A2：首次确认钟声先于钟锤动作 | 确保鸣响至少为 12（不是额外 +12） | 通过现有能力解锁 API 开启 `resonance_sight`，记录 R01 来源 ID | 首次灵视；回访 A1 的 H01 |

| R04 `anomaly_old_stone_layer` | A4：在沉积大厅辨认旧石构与后世管线的年代冲突，发生在 H04 隐藏楼梯之前 | +8（累计 36） | 若序章未记录古神接触，在此确保接触度至少为 1；已有接触不重复增加 | H04；H08 前置证据 |
| R05 `anomaly_silent_bell_window` | A6：在钟塔主路线一侧发现无声窗口 | +6（累计 42） | 无 | H05 |
| R06 `anomaly_erased_royal_name` | A8：确认王墓铭文被主动抹除 | +13（累计 55） | 确保古神接触度至少为 2；已有接触不重复增加 | H06 |
| R07 `anomaly_mirror_street_echo` | A9：在主路线经过的积水处辨认镜街倒影，调查点与 H07 入口分开 | +13（累计 68） | 仅当外神共鸣剧情事实成立时，已有故事事件将外神接触推进到 12 | H07 |
| R08 `anomaly_observer_reaction` | A11：进入深层研究区后、H08 入口之前，发现观测记录的第二个视点 | +10（累计 78） | 外神接触 +6（累计 18） | H08 |

这套曲线不要求玩家刷数值：主线路径经过的主要异常逐步提高鸣响，玩家再决定是否回访。H01 是早期回访秘密，不依赖蜜忒关系线；H07 / H08 则可以因为玩家错过外神相关关系或前置证据而完全不开放。

使用额外接触条件时，要按主题使用，而不是让每个隐藏入口都机械地同时要求三项数值：

- ancient_exposure：适用于旧王朝、古代石层、被改造的遗迹。
- outer_exposure：适用于蜜忒、外神影响和空间失真相关的路线。
- hero_resonance：决定主角能否感知异常。
- resonance_sight_active：决定当下是否正在主动观察。

鸣响高并不代表主角理解了真相。灵视只让他看见更多证据；这些证据可能彼此冲突，甚至让同一地点显现互相矛盾的结构。

## 4. 八处隐藏地图

八处隐藏地图分散在已经规划的主要区域中。它们不是额外的八个主线大区，而是对现有地图的深层扩展。前六处以探索、装备、环境叙事和捷径为主；后两处更靠近外神与终局线索。

| ID / 锚点 | 隐藏地图名称 | 测试阈值（鸣响 / 接触） | 初次线索 | 地图与路线价值 |
|---|---|---|---|---|
| H01 / A1 村庄老井 | **井底回声层** | 12 / 无额外接触门槛 | 水井里的滴水声总比水滴落下晚半拍 | 小型垂直地图；在 A2 学会灵视后可回访 A1；通往 A4 的铁门需从另一侧开启 |
| H02 / A2 钟墓 | **倒响钟室** | 18 / 无额外接触门槛 | 墓园的钟声先响，钟锤后动；附近墓碑日期互相矛盾 | 短型调查地图；提供一条钟塔维护路径的早期远景线索 |
| H03 / A3 废弃城区 | **被删去的第三街** | 28 / 无额外接触门槛 | 市场街牌写着第三街，但城区里只有第一街与第二街 | 隐藏的平行街区；另一出口通向 A9 的旧服务门，但该门在 A9 主路线开启前保持锁闭 |
| H04 / A4 旧水库 | **水面背后的楼梯** | 36 / 古神接触 ≥ 1 | 水面反射出一段现实中并不存在的干燥阶梯 | 以水位与反射为核心的小型空间谜题；通向 A8 的门要在王墓侧开启后才能形成捷径 |
| H05 / A6 修道院钟塔 | **无声钟室** | 42 / 古神接触 ≥ 1 | 钟塔阴影里出现一扇没有钟声的窗口 | 中型垂直支区；后期开启通往 A3 上层的钟塔维护捷径，不绕过 A5 主线 |
| H06 / A8 旧王墓 | **王名抹除廊** | 55 / 古神接触 ≥ 2，并已记录 `anomaly_bell_retiming` 与 `anomaly_erased_street_sign` | 王墓铭文中的空白并非磨损，灵视下能看出被抹掉的字形 | 中大型隐藏区；打开王室地下道的替代出口，连回 A9 的已知地标 |
| H07 / A9 王城外环 | **镜街：雨幕背后** | 68 / 外神接触 ≥ 12，且已发生外神共鸣剧情事实 | 雨水倒影中出现现实里不存在的街道与门洞 | 小型异象区；奖励探索或独特证据，侧门只有在主线抵达 A12 后才可通行 |
| H08 / A11 深层研究区 | **胎宫 / 原初空腔** | 78 / 古神接触 ≥ 2、外神接触 ≥ 18，并已记录 `anomaly_bell_retiming`、`anomaly_erased_street_sign`、`anomaly_old_stone_layer` | 深层研究墙面仿佛在呼吸，不同时刻的灵视显现不同轮廓 | 大型隐藏区；探索教会研究之前的古老结构，连向 A13 的部分路径仍需剧情状态 |

### 规模与内容预算

- H01–H02：约 5–12 分钟的短型秘密，重视早期发现感。
- H03–H05：约 10–20 分钟，至少包括一次探索决策、一个有辨识度的环境机制和一项有意义的奖励 / 证据。
- H06–H08：约 15–25 分钟，可包含危险遭遇、捷径或高价值隐藏叙事。
- 这些时长是内容规划值，不是要求玩家必须停留的时间；同一隐藏区域不应用重复战斗凑时长。

## 6. 八处隐藏地图的制作要求

### H01 — 井底回声层

玩家已经多次经过村庄老井。高鸣响时，井壁上的暗色水迹会构成不可能的台阶轮廓。短暂激活灵视后，玩家靠近井沿的异样砖块并互动，井内隐藏平台固定显现。

- 不要求在灵视的 4.5 秒内走完整段竖井。
- 井底是一小段下行路线与返回平台。
- 通向 A4 的铁门从另一侧开，防止刚到村庄就跳过 A2–A3。
- 第一次进入后，地图只记一枚未命名符号；第二次返回仍可走已开启路径。

### H02 — 倒响钟室

这处区域不是普通墓穴的延伸，而是被两种年代结构夹住的钟室。玩家可从钟墓上层听到先于钟锤动作的钟声。

- 可选，不设为主线条件。
- 入口出现后可以进入小型空间谜题；不要求玩家解读完整墓葬历史。
- 奖励是地方故事证据或装备，而非直接解锁真结局。
- 与 A5 的钟塔路线只在玩家后来抵达 A5 后形成交通连接。

### H03 — 被删去的第三街

城市里有街牌、地图残片或商人称呼“第三街”，但空间中缺失整条街。高鸣响时，屋顶阴影与地面巷道短暂重合，揭示墙体其实存在一条平行的空间层。

- 入口可以在 A3 的旧市场附近。
- 隐藏街区应有独立的上下层关系，而不只是墙后奖励房。
- 接 A9 的服务门被主线状态约束，避免跳过旧战场 / 修道院。
- 这里可以有一组看似互相矛盾的生活痕迹，不能给出完整答案。

### H04 — 水面背后的楼梯

在旧水库里，玩家低鸣响时只看到普通倒影；鸣响达标且主动激活灵视时，反射里出现一段不属于当前水库的楼梯。

- 入口互动后开放一个可重复进入的小型“倒影层”。
- 允许用改变水位、跨越落差或观察反射的方式解谜；不新增主角能力。
- 隐藏层中的王墓侧门早期无法从这一侧开启。
- 真实水位状态和倒影状态必须有明确视觉提示，避免玩家以为是碰撞 bug。

### H05 — 无声钟室

修道院钟塔的阴影里出现一扇没有钟声的窗口。灵视激活后，窗口框架与墙内的维护平台短暂显现。

- 以垂直路线和旧钟机构为核心，而不是重复钟墓的探索。
- 后期开启后，可以从钟塔维护层回落到 A3 上层，形成第二条跨区域捷径。
- 只能在玩家已经抵达 A6 后进入，不可从隐藏地图反向绕过 A5 主线。
- 这里的年代痕迹应与 A2 钟墓相呼应，但不给出完整解释。

### H06 — 王名抹除廊

旧王墓铭文中有一处空白，周围石面却没有磨损痕迹。灵视下浮现被刮除字形的残线，表明这不是简单风化。

- R06 的王墓调查会确保古神接触度至少为 2。若玩家此前已经获得该接触值，不重复累加；若跳过了序章线索和 A4 支路，也不会被永久锁在阈值之外。
- 入口还要求鸣响达到 55，并记录两个不同的前置异常，奖励真正回访过旧地图的玩家。
- 这里负责让王室历史出现裂缝，而不直接揭示全部政治真相。
- 通过后开启 A9 方向的替代出口，但不跳过王城主路线的主要门槛。
- 进入与开启状态都需要保存。

### H07 — 镜街：雨幕背后

王城外环有一段被拆除的商业街。下雨时，水洼偶尔映出并不存在的门洞与路灯；高鸣响和外神接触使倒影逐渐稳定。

- 保持为小型异象区，不扩建成第二座完整城市。
- 重点是识别真实道路与反射道路之间的差别，以及一条路线为何在水洼中出现。
- 远端侧门在 A12 的主线通道开放前保持锁闭，避免跳过王室内城的关键事件。
- 奖励可以是一个稀有物品、矛盾证据或一段独特声音，而非完整真相。

### H08 — 胎宫 / 原初空腔

深层研究区的墙面仿佛在呼吸，不同时刻的灵视会显现不同的空间轮廓。它可能是研究者对某种古老结构的错误命名，也可能是主角无法稳定感知的空间；文本不为玩家确认唯一答案。

- 入口需要高鸣响、古神与外神接触达到深层阈值，并记录至少三个不同的前置异常 ID。
- 这里的探索应汇总此前的物品、环境与声音证据，不出现一份解释全部世界真相的文档。
- 返回 A11 的路线始终可靠且可读；只有符合剧情状态时，才开放通向 A13 的部分路径。
- 这是大型隐藏区，但不得成为普通主线的必经之路。

## 7. 发现与存档的工程合同

现有 `resonance_hidden_target.gd` 已能根据阈值显现目标，但完整隐藏地图还需要持久化状态。进入实现阶段时优先扩展既有 `WorldState`，而不是添加平行系统。

### 已接入灰盒的链路与剩余工作

当前代码已接通以下首轮链路，但**尚未在 Godot 实机运行验证**：

- **A2 / R01：** 调查 `anomaly_bell_retiming` 后，通过 `WorldState.record_resonance_milestone()` 记录来源、确保鸣响至少为 12，并解锁现有 `resonance_sight`。若序章可选线索已将鸣响提高到 12，则不会再额外增加；若玩家跳过该线索，R01 仍会补到 12。
- **A2 / R02、A3 / R03、A4 / R04：** 一次性调查会分别将鸣响提高到至少 18、28、36。R04 还会确保古神接触度至少为 1，避免玩家错过序章可选线索后无法触发后续古神门槛；已达到该值时不重复增加。
- **H01：** `scripts/world/resonance_secret_gate.gd` 负责临时显现、E 开启、E 进入；入口和进入状态调用 WorldState 的持久化 API。
- **存档：** `discovered_hidden_regions`、`opened_hidden_paths`、`entered_hidden_regions` 已接入存档 / 读取 / reset；旧存档缺少这些字段时默认为空集合。
- **返回路线：** 只有玩家从 A3 正常抵达 A4 后才会生成 A4 侧井门；无论从村庄还是 A4 首次开启，都必须激活灵视并达到鸣响门槛。两侧共用 H01 通路 ID，永久开启状态保持同步。

`WorldState.mark_outer_god_resonance()` 现在会在外神共鸣剧情事实成立时，把 `outer_exposure` 提升到至少 12；即便旧存档已保存该布尔事实、但缺少接触数值，也会在调用时修正。R08 后续可以再将外神接触提升到 18。它仍不能因玩家单纯抵达 A9 而触发。

以下工作仍未完成：

- **R05–R08：** 尚未接入 A6 / A8 / A9 / A11 对应的正式场景和调查点。
- **H02–H08：** 有设计门槛与拓扑定义，但尚未逐一实例化通用入口并实测。
- **入口碰撞 / E 焦点 / 死亡回程 / 继续游戏：** 有代码和验收表，仍须在 Godot 4.6.x 实际跑图确认。

建议新增的永久状态已落实为 WorldState API，而不需要另一套隐藏地图管理器：

- `discovered_hidden_regions`：玩家已经发现并确认的隐藏入口；
- `opened_hidden_paths`：已经永久开启的门 / 通路 ID；
- `entered_hidden_regions`：玩家至少进入过一次的隐藏子区。

每个后续隐藏入口仍需声明固定 `secret_id`、父区域、鸣响 / 接触门槛、前置异常 source ID、远端出口条件与返回路径。入口显现期间复用现有交互焦点系统，避免与附近 NPC 抢占 E 键。

## 8. 验收用例

- [ ] 鸣响低于阈值：背景伏笔存在，但没有明确的可用隐藏入口。
- [ ] 鸣响达到阈值但没有激活灵视：入口尚未显现。
- [ ] 灵视激活且条件满足：隐藏目标在短时间窗内出现。
- [ ] 条件不满足：不显现，不出现错误的交互提示。
- [ ] 玩家没有在第一次窗口内调查：再次激活后仍可发现，不产生永久错失。
- [ ] 玩家调查成功：discovered_hidden_regions 持久化。
- [ ] 开启捷径：opened_hidden_paths 持久化。
- [ ] 关闭游戏、重新启动、死亡、切图后，已开启的路不重锁。
- [ ] 从隐藏区出口不会提前跳过必要的世界状态 / 主线门槛。
- [ ] 已有 E 交互系统不会同时给 NPC 和隐藏入口显示两个冲突提示。
- [ ] 高鸣响不会把所有隐藏入口同时自动标在地图上。
- [ ] 普通通关不强制进入 H01–H08；真结局路线也不能只靠高数值而跳过必要故事证据。

## 9. 建议的灰盒顺序

1. 试点 H01：使用现有村庄场景验证灵视 → 发现 → 开启 → 存档 → 回访。
2. 拓扑验证 H02 / H03：确认隐藏区域不会造成从早期地图进入中后期地图的进程破坏。
3. 机关验证 H04：测试水位 / 倒影层切换和返回路径。
4. 状态验证 H05–H06：让隐藏门、侧门和地图标记在死亡 / 切图后保持一致。
5. 叙事验证 H07–H08：检查外神相关路线是否提供线索而非直接解释全部世界真相。

当前文档定义了隐藏地图的连接规则与设计验收；并未声称这些入口已经在游戏中实现。
