## 6. 验证状态定义

每项工作必须明确区分：
- 文档核对：文档内容 / 链接已检查。
- 源码静态检查：调用关系、节点路径、资源引用等已检查。
- 验证器执行：记录实际执行的命令与输出。

- 本地实机验收：记录实际场景、操作路径和观察结果。

没有执行的步骤一律标记“未验证”。历史 PASS 数字不能作为当前分支通过的证据。
