# 《蜜忒之歌》跨作品剧情设定（中文）

> 状态：跨作品叙事基准 / 2026-11-01 迭代
> 适用项目：Nereis-Hero（动作探索 RPG）、Nereis-Lullaby（以蜜忒为主视角的小说式游戏）
> 本文只记录跨作品共同设定；蜜忒身份与结局世界观的详细权威摘要见 STORY.md 和 DEVELOPER_STORY_MEMORY.md。

## 1. 两种玩法讲述同一个世界

- **Nereis-Hero**：玩家扮演失忆骑士，通过战斗、互联地图、鸣响、灵视、道具描述、NPC 对话和环境线索理解世界。
- **Nereis-Lullaby / 蜜忒之歌**：玩家主要以蜜忒的视角，通过日常、人物关系、心理变化、选择和多周目，经历同一世界里的人如何生活、相爱、误解与被时代吞没。

两作不重复同一段剧情。RPG 提供外部事件和可探索证据；小说式游戏补充人物内心、时间跨度与 RPG 结局之后的后果。

## 2. 蜜忒的共同世界设定

- 蜜忒是普通人类，被外神选为地面代理人，但她对此完全不自知。
- 她天然、纯洁，无法理解或执行外神希望她组织邪教、完成仪式的意图。
- 她身上散发的无形气味 / 影响使部分村民受到影响；村民暗中自行组织邪教并反复尝试仪式，不是蜜忒主动招募或领导。
- 蜜忒前期的纯真与情感真实存在。她的意识只在后期玩家深入古神秘密与外神仪式、接近宇宙结局时才逐渐外神化。
- 外神不具备人类意义上的忠诚、爱情或政治立场；若一个容器计划失败，它仍可能寻找其他容器。外神对人类政治循环保持超越性的漠然。

## 3. 复国军与凡人之墓

在《Nereis-Hero》的凡人之墓结局中，英雄击败教会最高权威与国王，帮助复国军剔除教会对王国的直接控制。这个胜利是真实的：教会的研究机器被打断，旧统治者被推翻，幸存者获得喘息。

但复国军没有解决权力本身的问题。为了稳定王国，它逐渐重建情报体系、军令体系、资源配给与思想审查；最初的紧急措施变成常态，反对者被称为叛徒，教会留下的研究技术被重新包装成“国家安全”或“王国复兴”的必要手段。

腐化不是一夜之间发生，也不是复国军每个人都从一开始就邪恶。它来自“只有我们掌权，才能防止旧灾难重演”的自我辩护。新秩序逐渐成为旧教会的继承者。

## 4. Hero 在后续故事中的命运

《Nereis-Hero》结束时，英雄完成了当下的战斗，但不等于他从此脱离政治与权力。

《Nereis-Lullaby》的跨作主线将描写他在复国军新秩序中的后续选择：他最初认为自己是在保护幸存者、维持和平或阻止王国再次崩溃；随后，他开始容忍自己曾反抗的手段，最终成为新秩序的执行者或沉默的共谋者，并在这个过程中抛下蜜忒。世界由此进入下一轮循环。

不要把这件事写成简单的“英雄突然变坏”：更有力量的因果是，他不断把蜜忒、私人承诺和个体生命放到“更大的责任”之后，直到某天发现自己已经成为曾经憎恨的人。其他分支可以探索不同选择，但这条跨作主线负责把《Nereis-Hero》的政治胜利与《Nereis-Lullaby》的个人悲剧连接起来。

## 5. 三个结局的共同世界观

### 凡人之墓
人类政治冲突暂时获得解决，复国军胜利并逐渐重演腐化循环。蜜忒与外神的真相可能未被主角或玩家完整理解；演出必须依据实际经历，不得假定所有玩家都认识蜜忒或与她发展过同样的关系。

### 永恒乐园
主角在探究古神秘密后吸收部分古神力量。外神通过逐渐外神化的蜜忒进一步神格化主角，借主角自身力量引发类似《EVA》人类补完 / 世界冲击的事件。所有人的无知肉体消失，意识被外神眷养在外神的乐园——这颗星球之中。

### 烈火天罚
星球本身具有意识，并借助主角的力量发动大爆炸，终止外神降临仪式。古神、外神、邪教组织、蜜忒与主角都将不复存在。这不是传统意义上的胜利，而是以彻底毁灭作为代价的星球反抗。

## 6. 跨作品叙事约束

1. 蜜忒是普通人类、外神选中的地面代理人，但她本人不知情；不得写成前期有意识的邪教领袖。
2. 村民邪教由无形气味 / 影响引发的村民自行组织；不得把组织行为归给蜜忒主动策划。
3. 蜜忒前期纯真与情感真实；后期意识外神化不能反向抹去她早期的人性。
4. 《Nereis-Lullaby》以蜜忒为主视角，补充她对 Hero 后续变化的体验，而不是简单重复 RPG 的战斗。
5. 外神寻找其他容器是长期威胁，但蜜忒并非外神唯一可能的代理人。
6. 关系互动可以改变个人剧情与内容可获得路径，但不是好感度系统，也不直接决定《Nereis-Hero》的三个结局。
7. 结局条件中的探索、道具与特殊事件仍以 Nereis-Hero 的 ENDING_CONDITION_DESIGN_CN.md 为准。
