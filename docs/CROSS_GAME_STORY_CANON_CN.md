# 《蜜忒之歌》跨作品剧情设定（中文）

> 状态：跨作品叙事基准 / 2026-10-11  
> 适用项目：Nereis-Hero（动作探索 RPG）、Nereis-Lullaby（以蜜忒为主视角的小说式游戏）

## 1. 两种玩法讲述同一个世界

- **Nereis-Hero**：玩家扮演失忆骑士，通过战斗、箱式互联地图、鸣响、灵视、道具描述与环境线索，理解世界发生了什么。
- **Nereis-Lullaby / 蜜忒之歌**：玩家主要以蜜忒的视角，通过日常、人物关系、心理变化、选择和多周目，经历同一世界里的人如何生活、相爱、误解与被时代吞没。

两作不重复同一段剧情。RPG 提供外部事件和可探索证据；小说式游戏补充人物内心、时间跨度与 RPG 结局之后的后果。

## 2. 复国军与凡人之墓

在《Nereis-Hero》的凡人之墓结局中，英雄击败教会最高权威与国王，帮助复国军剔除教会对王国的直接控制。这个胜利是真实的：教会的研究机器被打断，旧统治者被推翻，幸存者获得喘息。

但复国军没有解决权力本身的问题。为了稳定王国，它逐渐重建情报体系、军令体系、资源配给与思想审查；最初的紧急措施变成常态，反对者被称为叛徒，教会留下的研究技术被重新包装成“国家安全”或“王国复兴”的必要手段。

腐化不是一夜之间发生，也不是复国军每个人都从一开始就邪恶。它来自“只有我们掌权，才能防止旧灾难重演”的自我辩护。新秩序逐渐成为旧教会的继承者。

## 3. Hero 在后续故事中的命运

《Nereis-Hero》结束时，英雄完成了当下的战斗，但不等于他从此脱离政治与权力。

《Nereis-Lullaby》可以描写他在复国军新秩序中的后续选择：他最初可能认为自己是在保护幸存者、维持和平或阻止王国再次崩溃；随后，他开始容忍自己曾反抗的手段，最终成为新秩序的执行者、象征，或沉默的共谋者。

在这个过程中，他可能抛下蜜忒。不要把这件事写成简单的“英雄突然变坏”：更有力量的因果是，他不断把蜜忒、私人承诺和个体生命放到“更大的责任”之后，直到某天发现自己已经成为曾经憎恨的人。

具体表现可由《Nereis-Lullaby》的分支决定；“抛下蜜忒”是重要剧情方向，但不必强行覆盖每条路线。

## 4. 蜜忒与外神

蜜忒早期的纯真、好奇与情感都是真实的。她并不完全理解自己与外神之间的联系，也不应被简单解释成从头到尾都在操纵骑士的反派。

外神不具备人类意义上的忠诚、爱情或政治立场。它不会因为英雄打败教会、复国军建立新国家，或蜜忒被英雄抛下而停止行动。对它而言，人类政权只是短暂环境，蜜忒也不是唯一不可替代的容器。

如果一次容器计划失败，外神会继续寻找下一个适合的容器。这个循环可以通过梦境、重复的歌谣、相似的仪式、被遗忘的实验记录或下一位异常者表现出来；不要用一大段解释性独白把谜底说尽。

## 5. 三结局的统一规则

《Nereis-Hero》的三个结局始终由主角的鸣响、道具与探索决定：

- **凡人之墓**：未满足宇宙结局的鸣响与探索证据门槛。人类在政治上获胜，但腐化循环继续。
- **永恒乐园**：鸣响成为外神能够回应的信号，玩家发现外神残留，却没有收集足够的真相锚点来保全主角的自我。主角成为容器，世界进入永恒梦境。
- **烈火天罚**：鸣响足够强，主角收集至少三类真相锚点并深入探索，保留了抵抗外神的能力，但最终仍要付出毁灭性代价。

与蜜忒发生身体结合可以是重要人物剧情，但不是任何结局的门槛，也不能让没有发展到该关系的玩家无法完成主线。

## 6. 创作约束

1. Hero 不会在 RPG 主线中明确得知蜜忒的真实外神身份。
2. 蜜忒的早期纯真不是骗局。
3. 不要把复国军写成打败教会后立即变成同一种反派；腐化必须经过一段看似合理的治理过程。
4. 《Nereis-Lullaby》以蜜忒为主视角，补充她对 Hero 后续变化的体验，而不是简单重复 RPG 的战斗。
5. 外神寻找新容器是超越人类政治循环的长期威胁。
6. 亲密关系改变情感语境和人物命运，但不决定 RPG 的三个结局。
