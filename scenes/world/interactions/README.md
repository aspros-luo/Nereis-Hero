# Reusable World Interactions

Place reusable interaction scenes here: doors, gates, levers, one-way hatches, and drop-transition triggers.

Keep these scenes generic. Region-specific destination routes and unlock conditions belong to the region's authored instance/configuration, not hard-coded into the reusable interaction scene.

Existing interaction assets under `scenes/world/` remain at their current paths until all references are audited and migrated together.
